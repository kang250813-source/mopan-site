IPTV-JP概述

IPTV-JP 提供日本电视的网络播放列表，支持在电脑或移动设备上通过播放器/客户端进行观看。项目维护方使用自有服务器（示例域名：utako.moe），为减轻带宽压力，仅允许引用 GitHub 仓库，不允许复制与传播直链。新增频道请求不受理，遇到服务器问题请在 Issues 板块反馈。

使用方式

播放列表获取

  • 在项目页面复制 原始播放列表（raw playlist），或选择 Clean List（不含成人/NSFW）。
  • 将链接粘贴到支持 M3U/网络流的播放器或 IPTV 客户端中。

支持的播放器/客户端

VLC、PotPlayer、TiviMate、iSTB 等主流工具均可直接打开播放列表。

Web 端入口

无需本地播放器，可通过网页端访问：

  • https://web.utako.moe
