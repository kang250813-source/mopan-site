IPV4/IPV6 TVBOX 电视直播与点播源收集全指南：ngo5 IPTV

发布于 2025-09-18

IPV4/IPV6 TVBOX 资源概览

ngo5 IPTV是一份整理汇总了IPV4与IPV6环境下可用的电视直播与点播源，并包含常见的影视APP、空壳软件、自带源软件以及相关工具。由于地区与网络限制，部分直播源可能存在卡顿或限地区观看的情况，用户需要根据实际情况测试选择。

直播源与检测工具

  • 部分IPV6源仅限本省可用，部分项目已替换为IPV4源。
  • 建议先添加点播源，系统会自动填充自带的直播源。
  • 可通过 testipv6.com 查询IPV6环境，或使用 iptv-checker 检测源的有效性。
  • 免费电视节目表可参考 epg.pw。

常见点播源

  • 饭太硬：http://www.饭太硬.net/tv
  • OK猫开发：http://ok321.top/ok
  • 王小二：https://9280.kstore.space/wex.json
  • 高天流云、肥猫、安卓哥、盒子迷 等。

点播源常出现失效或被举报，不建议使用收费源。推荐使用“饭太硬”及其主页推荐的资源。

推荐软件

  • TVBOX（Android）
  • 影视APP（FongMi、OK版，Android/手机）
  • 影视仓（Android/手机）
  • TiviMate（Android，需付费解锁高级功能）
  • Kodi（全平台，需额外配置中文与插件）
  • ZyPlayer、CMSPlayer、APTV、Potplayer 等跨平台工具。

部分软件如“TVBOX”无节目单，TiviMate限制扫码输入源，Kodi配置较复杂，用户可根据需求选择。

自带源软件与电视浏览器

  • 油桃TV、小飞电视、小微直播、大吉电视等，部分为官方源，部分为第三方源。
  • BrowseHere、TV Bro 是常见的电视浏览器。
  • GitHub在国内访问受限时，可使用 github.do 或更换DNS。

官方电视直播

  • 央视网、央视影音、央视频
  • 广东荔枝网、江苏荔枝网、广西网络广播电视台
  • 芒果TV、新蓝网（浙江）等地方电视台
  • 可通过“地方+电视直播”关键词在谷歌搜索官方地址。

第三方资源

部分第三方直播源不推荐，如 freeintertv.com、345iptv.com。
更完整的IPTV源整理可见： GitHub – ngo5/IPTV。
