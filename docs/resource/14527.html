　　令铅拒火，须仗修天（今呼为补天石）；如要形坚，岂忘紫背（有紫背天葵，如常食葵菜，只是背紫面青，能坚铅形）；留砒住鼎，全赖宗心（别有宗心草，今呼石竹，不是食者棕恐误。
