Open TV：免费开源的跨平台 IPTV 播放器

Open TV 是一款免费、开源、跨平台的 IPTV 播放器，专为追求极致播放体验的用户打造。它完全重写了底层架构，以实现更高性能、更快启动速度与更稳定的播放效果。这款应用由开发者独立维护超过两年，坚持无广告、无捐赠弹窗的纯净体验。无论你使用 Windows、macOS 还是 Linux，都可以轻松导入自己的 IPTV 频道源，观看、录制、分享你喜爱的直播内容。

🚀 极致性能与自由体验

Open TV 经过全面重写，启动速度与响应速度显著提升。应用占用极低的内存（RAM），能快速加载频道并实现即时搜索。用户可通过电视遥控器直接控制界面，打造家庭级 IPTV 使用体验。

📺 丰富功能，灵活操作

  • 导入任意 IPTV 源：支持 M3U 文件、M3U 链接与 Xtream 登录方式
  • 边看边录制：随时保存精彩节目
  • 多源播放与自定义频道：创建并分享个人频道库
  • 收藏喜爱频道：快速访问常看内容
  • 一键刷新频道源：保证内容实时更新
  • 支持重流（re-stream）：可向手机、电视或好友设备推送频道

🧩 技术依赖与安装说明

Open TV 使用 mpv、ffmpeg 和 yt-dlp 作为核心依赖。

  • macOS 用户可通过 Brew 或 MacPorts 安装
  • Fedora 用户需启用 rpmfusion
  • Debian、Ubuntu 用户推荐使用 backport 以获取最新 yt-dlp
  • Windows 版本自带 mpv，无需额外安装

命令示例：

brew install mpv ffmpeg yt-dlp  # macOS  
sudo apt install mpv ffmpeg yt-dlp  # Debian/Ubuntu

🌍 完全开源与社区支持

Open TV 坚持开源与自由理念，无任何广告弹窗或强制捐赠提示。开发者承诺将项目长期保持免费，并呼吁社区支持以持续更新与优化。
