AiNiee：开源 AI 翻译工具，一键搞定游戏文本、电子书、字幕与文档的长文高质量翻译

发布于 2025-09-02

AiNiee介绍

AiNiee 是一款专注于 AI长文本自动翻译 的开源软件，能够一键处理游戏文本、电子书、字幕、文档等多种格式。它采用先进的 思维链翻译、AI术语表、上下文关联 等技术，确保译文不仅准确，还能保持整体连贯性。用户只需拖拽文件即可完成翻译，操作简洁，效率极高。

AiNiee功能特点

  • 多格式支持：兼容游戏文本（Mtool、Renpy、Translator++等）、Epub/TXT小说、Srt/Vtt/Lrc字幕、Word/PDF/MD文档及I18Next数据。
  • 一键操作：无需复杂配置，拖入文件即可自动识别并翻译。
  • 高速处理：长文本翻译速度快，几分钟内即可完成。
  • 翻译优化：支持上下文智能关联、AI润色、自动排版、术语提取，提升整体翻译质量。
  • 个性化定制：可通过提示词设置角色介绍、背景设定和翻译风格，满足不同场景需求。
  • 免费开源：项目代码完全公开，支持二次开发和自由扩展。

适用人群

  • 游戏开发者与汉化组：需要大批量翻译RPG、SLG等游戏文本。
  • 小说阅读爱好者：快速翻译Epub/TXT电子书，轻松跨语言阅读。
  • 字幕组与影视爱好者：支持Srt、Vtt、Lrc字幕的精准翻译。
  • 职场人士与学生：便捷处理Word、PDF、MD等办公与学习文档。
  • 多语言工作者：需要保持长文翻译质量和一致性的专业翻译人员。

如何使用

1、下载与安装
前往 GitHub 获取开源项目：AiNiee GitHub 地址，网盘下载、根据说明配置所需接口。

2、导入文件
将需要翻译的文件（游戏文本、电子书、字幕或文档）直接拖拽到软件中。

3、自动识别与翻译
系统会自动识别文件类型与语言，快速生成译文。

4、优化与导出
用户可选择一键AI润色、排版或术语提取功能，并将结果导出为目标格式。
