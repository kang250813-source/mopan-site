pyJianYingDraft：轻量灵活的Python剪映草稿工具 全自动视频剪辑流水线

发布于 2025-07-26

pyJianYingDraft概述

pyJianYingDraft是一款轻量、灵活且易上手的Python库，可自动生成并导出剪映（Jianying Pro）草稿，助力全自动视频剪辑与混剪流水线的搭建。它在剪映5.9及以下版本中支持模板模式下的草稿读取与修改，在剪映6及以下版本中实现批量导出，并兼容剪映5及以上版本的丰富素材与轨道操作。

pyJianYingDraft核心功能

模板模式

  • 支持加载剪映5.9及以下版本的未加密 draft_content.json 作为模板
  • 替换模板中的音视频素材与文本内容
  • 将模板轨道（音频/视频/文本）整体导入到其他草稿
  • 提取模板中贴纸、气泡、花字等元信息

批量导出

  • 控制剪映打开指定草稿并导出到目标路径
  • 可调节输出分辨率与帧率
  • 仅支持剪映6及以下版本的批量导出功能

素材与效果

  • 添加本地视频、图片和音频素材，支持自定义片段起止时间、持续时长和播放速度
  • 视频调整：旋转、缩放、亮度等属性及关键帧设置
  • 入场/出场和组合动画，蒙版、滤镜及片段特效
  • 示例功能：背景填充、贴纸关键帧、花字气泡、文字描边及背景

音频与轨道管理

  • 音频淡入淡出、音量关键帧及场景音效果
  • 增加轨道、分层管理视频/滤镜/特效轨道

转场与字幕

  • 自定义转场时长与效果
  • 导入 .srt 文件一键生成并批量格式化字幕
  • 文本自动换行、设置最大行宽，支持关键帧动画

pyJianYingDraft安装与快速上手

  1. 安装： 
    pip install pyJianYingDraft

    推荐 Python 3.8 或 3.11。若发生 import 失败，可参考相关 issue 排查 uiautomation 兼容问题。

  2. 示例演练：
    • 在剪映中创建空草稿，定位其 draft_content.json 路径
    • 设置示例脚本 demo.py 的 DUMP_PATH，运行后自动生成包含视频、音频、文本、淡入淡出、转场及花字气泡等效果的草稿
    • 重新打开草稿，验证时间轴及各项效果配置
