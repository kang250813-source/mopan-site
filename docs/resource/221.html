Make It Heavy：用开源方式重现 Grok Heavy 的 AI 智能协作

Make It Heavy 是一款以 Python 编写的 AI 框架，灵感来自 Grok Heavy 模式，通过并行部署多个智能代理（Multi-Agent）协同工作，针对任何问题提供全面、深入、多视角的答案。无论是复杂研究还是信息整合，它都能高效完成。

多智能体并行分析，模拟 Grok Heavy 深度模式

框架核心在于智能代理系统（Agent System）。它可同时运行4个（或更多）专精化AI代理，每个代理从不同角度发问、研究并汇总答案，最终生成一份经过智能融合的统一回应，全面覆盖问题的不同层面。

例如，面对“Pietro Schirano是谁？”这一问题，系统将自动生成4个研究子问题，并分派给不同代理执行，包括：职业背景、技术贡献、影响力分析、角色验证等，最后输出整合后的深度答复。

功能亮点一览

  • 🧠 Grok Heavy仿真模式：支持并行智能体深度协同分析
  • 🔀 并行智能架构：4个AI代理同时执行任务，提升分析广度
  • 🎯 AI问题自动生成：根据用户查询自动拆解出研究子问题
  • ⚡ 实时可视化反馈：在运行过程中展示每个Agent的进度状态
  • 🛠️ 工具热插拔：支持自动加载自定义工具（如Web搜索、计算器等）
  • 🔄 智能观点整合：多个智能体的答案最终自动融合为一致内容
  • 🎮 单Agent模式：可切换为单智能体运行，适用于简单任务

快速开始：只需三步

  1. 安装依赖与环境（推荐使用 uv 进行管理）： 
    git clone https://github.com/Doriandarko/make-it-heavy.git
cd "make it heavy"
uv venv
source .venv/bin/activate  # Windows 用户使用 .venv\Scripts\activate
uv pip install -r requirements.txt
  2. 配置 OpenRouter API：
    打开 config.yaml，填入你的 API Key。
  3. 启动运行：
    • 单Agent模式：uv run main.py
      用于一般问答、搜索、工具调用等任务。
    • Grok Heavy模式：uv run make_it_heavy.py
      4个智能体并行运行、实时反馈、观点整合。
