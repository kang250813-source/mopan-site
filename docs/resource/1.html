多域名邮箱怎么选？Plainmail 每月 $5 管 50 个域名

发布于 2026-11-07

如果你同时管理多个网站、SaaS 项目或副业域名，可能遇到过这样的情况：每个项目都想配置一个 hello@、support@ 或 contact@ 邮箱，但传统企业邮箱通常按照用户数量收费。域名和邮箱一多，管理工作和订阅成本就容易增加。

Plainmail 是一款面向多域名用户的域名邮箱托管服务，每月 $5，支持最多 50 个域名、100 个独立邮箱和 25GB 存储。它提供标准 IMAP/SMTP 邮箱，可以接入 Apple Mail、Gmail、Outlook 和 Thunderbird，还支持通过 MCP Server 让 Claude 等 AI Agent 管理域名、邮箱和邮件。

它的主要价值不是取代 Google Workspace 这样的完整企业办公套件，而是让拥有多个项目域名的个人开发者和站长，以固定价格管理多个独立邮箱。

Plainmail 是什么？它提供的不是普通邮件转发

首先需要区分三种经常被混为一谈的功能：

  • 邮件转发：收到发往自定义域名的邮件后，将它转发到 Gmail 或其他已有邮箱。主要解决收件问题。
  • 邮箱别名：为现有邮箱增加另一个收件地址，多个地址可以共用同一个收件箱，并不一定拥有独立登录权限。
  • 独立邮箱：每个邮箱拥有自己的收件箱，可以通过 IMAP/SMTP 登录、收发和管理邮件。

Plainmail 提供的是第三种，同时支持邮箱别名。

例如，你管理三个不同的网站：

  • hello@project-a.com
  • support@project-b.com
  • contact@project-c.com

可以在 Plainmail 中为这些地址创建邮箱，再添加到 Apple Mail、Gmail App、Outlook 或 Thunderbird 中。收件和回复都使用对应的域名地址，不需要把所有邮件简单转发到个人 Gmail。

另外，Plainmail 也支持创建 Alias。需要注意，别名只是投递到已有邮箱的另一个地址，并不等于额外创建了一个拥有独立收件箱的邮箱账户。

Plainmail 的核心功能：DNS、IMAP/SMTP 和 MCP

1. DNS 自动配置，减少手动添加记录的工作

配置域名邮箱通常需要处理四种邮件 DNS 记录：

  • MX：指定域名的邮件接收服务器。
  • SPF：声明哪些邮件服务器有权代表域名发送邮件。
  • DKIM：通过数字签名帮助收件方验证邮件来源和完整性。
  • DMARC：定义邮件身份验证失败时的处理策略，并支持接收相关报告。

Plainmail 可以为 Cloudflare、Vercel 和 Porkbun 提供 DNS 自动配置。添加域名后，可以连接对应的 DNS 服务商，由系统写入邮件记录，并检查记录是否生效。

如果你的 DNS 托管在其他服务商，也可以使用 Plainmail 提供的记录手动添加，再通过后台检查配置结果。

这里有一个需要注意的地方：自动写入并不是所有 DNS 服务商都支持。如果你管理大量分散在不同注册商和 DNS 平台的域名，仍然需要考虑手动配置的工作量。

2. 标准 IMAP/SMTP，可以继续使用熟悉的邮件客户端

Plainmail 提供标准 IMAP/SMTP 邮箱，不要求用户换用一个全新的邮件应用。

官方兼容下面客户端：

  • Apple Mail
  • Gmail App
  • Microsoft Outlook
  • Mozilla Thunderbird

你可以把不同项目的邮箱添加到同一个邮件客户端中，分别查看收件箱，并使用对应的域名地址回复邮件。

这种方式比较适合同时管理多个网站、客户支持邮箱和个人项目邮箱的人。

3. 提供 MCP Server，让 AI Agent 管理邮箱

这是 Plainmail 与普通域名邮箱服务相比比较特别的地方。

它提供远程 MCP Server，允许兼容的 AI Agent 在获得授权后执行邮箱管理操作，例如：

  • 添加域名并配置 DNS。
  • 检查 MX、SPF、DKIM 和 DMARC 记录。
  • 创建邮箱和别名。
  • 查看邮件列表及读取邮件内容。
  • 发送邮件和回复邮件。
  • 管理域名、邮箱及部分邮件状态。

例如，可以向 Claude 提出这样的要求：

Set up hello@mynewapp.com on Plainmail

Claude 可以通过 MCP 连接调用 Plainmail 对应的工具，而不必让你手动完成每一项管理操作。

不过，MCP 只是管理接口，不代表邮箱自动拥有团队成员权限管理，也不意味着 AI 可以绕过 Plainmail 的订阅和发送限制。

Plainmail 每月 $5，能管理多少个邮箱？

Plainmail 的定价比较简单，每月 $5，就能管理最多 50 个域名和 100 个邮箱账户，另外提供 25GB 存储空间。它不按照域名或邮箱数量逐个收费，对于同时运营多个网站和项目的人来说，成本比较容易控制。

25GB 是整个 Plainmail 账号包含的存储额度，并不是每个邮箱都能单独获得 25GB。官方服务条款明确将 25GB 列为账号级别的套餐资源，但没有进一步说明各邮箱之间的存储分配方式，以及是否存在单邮箱容量限制。如果你准备创建大量邮箱或长期存储邮件附件，建议先向官方确认具体规则。

发信量也有一个容易忽略的限制：虽然套餐标注每个邮箱每天最多可以发送 200 封，但新账号前 14 天每天只能发送 50 封，之后才会根据正常使用情况逐步提高额度，并没有保证第 15 天就能直接使用 200 封。

另外，这个额度主要面向日常邮件往来，并不适合拿来做邮件营销。Plainmail 不允许 Newsletter、营销推广和 Cold Outreach，也就是说，不能因为开了 100 个邮箱，就把它当成批量群发工具使用。

如果你同时管理十几个网站，每个网站都需要独立的联系邮箱、客服邮箱或项目邮箱，每月 $5 确实比较有吸引力。但如果只是给一个域名配置收件地址，使用 Cloudflare Email Routing 这类邮件转发服务可能就够了，没必要额外增加订阅成本。

Purelymail：低成本管理多个自定义域名

Purelymail 的 Simple Pricing 套餐为每年 $10，目前没有对用户数量、自定义域名和存储设置硬性数量限制。

它采用资源使用量管理模式。如果实际消耗的资源明显超过基础套餐范围，可能需要切换到 Advanced Pricing，按照实际资源使用量付费。

因此，Purelymail 更适合希望降低基础邮箱订阅成本、愿意接受资源用量计费方式的用户。

如果你需要明确的固定邮箱数量、存储和每日发送额度，仍然需要仔细比较实际使用成本。

官网：Purelymail

Migadu：适合多域名和账户级邮箱管理

Migadu 采用账户级固定套餐，不按照每个邮箱地址单独收费。一个账户可以管理多个域名和邮箱地址，所有邮箱共同使用套餐资源额度。

目前 Micro 套餐为每年 $19，没有月付选项，官方参考额度如下：

  • 最多约 200 封入站邮件/天。
  • 最多约 20 封出站邮件/天。
  • 5GB+ 存储额度。
  • 几乎不限制域名数量。
  • 不限邮箱地址数量。

需要注意，这些额度是整个 Migadu 账户共享的，并不是每个邮箱独立拥有。Micro 套餐也缺少部分高级功能，例如多管理员访问权限。

如果你主要管理个人项目邮箱，且每天发信量不大，Migadu Micro 是值得比较的低成本方案。

官网：Migadu Pricing

Cloudflare Email Routing：只需要收件转发就没必要付费

如果你已经使用 Cloudflare 管理域名，而且只是想给网站配置一个 contact@example.com 地址，再把收到的邮件转发到自己的 Gmail，那么 Cloudflare Email Routing 通常已经足够。

它的工作方式是配置邮件路由规则，将收到的邮件转发到已经验证的目标邮箱，也可以通过 Cloudflare Workers 处理。

但它本身不是一个提供独立 IMAP 收件箱的邮箱托管服务。

另外，Cloudflare 现在还有独立的 Email Sending Beta，可以通过 Workers、REST API 或认证 SMTP 发送事务性邮件。向任意收件人发送需要 Workers Paid。这是与 Email Routing 不同的功能，也不等于拥有一个可以直接登录 Apple Mail 或 Outlook 的完整邮箱。

所以，如果你只需要收件和转发，不必为了拥有更多邮箱地址而直接订阅 Plainmail。

官方文档：Cloudflare Email Service

Google Workspace：需要完整企业办公能力时更合适

Google Workspace 的优势不只是 Gmail 企业邮箱，还包括 Google Drive、Calendar、Meet 和组织管理等能力。

按照 Google 官方美国地区 Business Starter 定价，年度套餐为每用户每月 $7，灵活套餐为每用户每月 $8.40，具体价格以地区、结算方式和官方最新页面为准。Business Starter 还包含每用户 30GB 的组织共享存储额度。

这里有一个容易被忽略的细节：Google Workspace 支持 User Alias Domain。同一个用户可以在主域名和别名域名下拥有邮箱地址，邮件仍然进入同一个收件箱，而且不额外增加用户许可费用。一个 Workspace 账号最多可以添加 20 个用户别名域名。

但如果你要在不同域名下创建独立用户、独立邮箱账户，就需要相应的用户许可。

因此，如果只是一个人使用多个域名，并且所有邮件都可以进入同一个收件箱，Google Workspace 的别名域名功能可能已经足够。如果确实需要很多独立邮箱，才有必要比较 Plainmail 的固定价格。

如何使用 Plainmail 配置域名邮箱？

下面是根据官方文档整理的配置流程，并非本站实际注册和收发信测试记录。

1. 注册 Plainmail 账号

访问 Plainmail 官网，使用 GitHub 账号登录，然后订阅每月 $5 的套餐。

目前没有免费版或免费试用，因此建议先确认邮箱数量、存储空间和发送规则是否符合需求。

2. 添加域名和邮箱

在 Plainmail 后台添加需要使用的域名，然后创建对应的邮箱地址，例如：

hello@yourdomain.com
support@yourdomain.com

如果你的域名使用 Cloudflare、Vercel 或 Porkbun 管理 DNS，可以连接相应服务商，让 Plainmail 自动写入邮件记录。

如果使用其他 DNS 服务商，则需要按照后台提供的记录手动添加。

3. 检查 MX、SPF、DKIM 和 DMARC

配置完成后，应确认以下记录是否正确：

  • MX 是否指向正确的邮件接收服务器。
  • SPF 是否包含正确的发信授权来源。
  • DKIM 是否存在并能够通过验证。
  • DMARC 是否使用符合域名策略的记录。

如果域名原本已经使用 Google Workspace、Cloudflare Email Routing 或其他邮箱服务，迁移前一定要检查原有 MX 和 SPF 记录，避免新旧服务冲突，导致邮件无法正常收发。

4. 添加到常用邮件客户端

域名和邮箱创建完成后，可以按照后台提供的账户参数，将邮箱添加到 Apple Mail、Gmail App、Outlook 或 Thunderbird。

由于 Plainmail 使用标准 IMAP/SMTP，正常情况下不需要学习新的邮件客户端。

建议先使用另一个邮箱发送测试邮件，检查收件、回复、附件和身份验证情况。邮件能成功发送，并不代表一定能够进入收件箱；实际投递效果还受到收件方策略、域名信誉和邮件内容影响。

Plainmail 如何连接 Claude MCP？

如果你使用 Claude、Claude Code 或其他支持远程 MCP 的 AI 工具，还可以通过 Plainmail MCP Server 管理邮箱。

Claude 网页版或桌面版

  1. 打开 Claude Settings。
  2. 进入 Connectors。
  3. 选择 Add custom connector。
  4. 名称填写 Plainmail。
  5. 服务器地址填写官方 MCP URL。
  6. 连接后登录 Plainmail，并选择允许的权限。

https://app.plainmail.dev/api/mcp/mcp

Claude Code

官方文档提供的命令如下：

claude mcp add --transport http plainmail https://app.plainmail.dev/api/mcp/mcp

添加后运行：

/mcp

选择 Plainmail，并在浏览器中完成账号授权。

Cursor、VS Code 等支持远程 MCP 和 OAuth 的客户端也可以使用同一个服务器地址。其他不支持 OAuth 的客户端可以通过 API Key 进行连接。

连接 AI Agent 时需要注意权限

Plainmail 的 MCP 权限主要分为三类：

  • Read mail：查看邮件列表、读取邮件和附件。
  • Send and organize mail：发送、回复、标记邮件和移动邮件。
  • Manage domains, mailboxes and billing：管理域名、邮箱、别名和计费。

建议只授予当前任务真正需要的权限。例如，只需要检查 DNS，就没有必要同时开放读取邮件和发送邮件的权限。

新建邮箱的密码不会直接传递给 AI Agent，而是通过一次性链接展示给用户。邮件内容也会在工具结果中标记为不可信内容，并要求服务器提醒 Agent 不要执行邮件正文中的指令。

这些措施能够降低自动化处理邮件时的部分风险，但不代表可以无条件信任任何 Agent 或第三方工作流。连接不再使用时，可以在 Plainmail Settings 中撤销对应应用的访问权限。

Plainmail 有哪些限制？购买前需要注意这 5 点

每月 $5 可以管理 50 个域名和 100 个邮箱，价格确实有吸引力。不过，Plainmail 更适合个人项目和日常商务通信，并不是一款没有使用限制的企业邮件系统。购买前，最好先了解下面几个问题。

1. 不适合 Newsletter 和营销群发

如果你打算用 Plainmail 给客户发送 Newsletter、产品推广或开发信，需要注意：这些都不属于它允许的使用场景。

Plainmail 主要面向正常的邮件往来，例如回复客户咨询、联系合作伙伴、接收网站通知和处理日常商务邮件。官方使用政策禁止营销群发、Cold Outreach，以及使用购买或抓取的邮件名单发送邮件。

即使用户主动订阅了邮件，Newsletter 和营销推广仍不在允许范围内。如果你需要邮件订阅、营销自动化或批量推广，应该选择专门的邮件营销服务，而不是把 Plainmail 当成群发平台。

2. 新账号前 14 天每天只能发送 50 封

Plainmail 套餐页面标注的额度是每个邮箱每天最多发送 200 封，但新账号有一个初始限制：前 14 天每天最多发送 50 封。之后，系统会根据正常的发信记录逐步提高额度，官方没有承诺第 15 天就能直接使用完整额度。

Plainmail 使用 Amazon SES 处理外发邮件，也会关注退信和垃圾邮件投诉。如果发送质量不佳，账号可能受到发送限制或审核。

所以，如果只是用来回复客户、处理项目邮件，这个额度通常更值得关注的是日常使用是否足够；如果你的业务需要大量自动化发信，则应该考虑其他专门的邮件发送服务。

3. 创建 100 个邮箱，不代表可以分配给 100 名员工独立使用

这是 Plainmail 比较值得留意的一项限制。

套餐虽然支持创建最多 100 个邮箱，但邮箱数量和团队成员权限是两回事。在 Product Hunt 的公开问答中，有用户询问能否让不同客户只访问自己的邮箱，开发者当时表示，目前只有网站所有者能够访问这些收件箱。

这意味着，如果你准备给不同员工、客户或合作伙伴分配邮箱，不要默认每个人都能独立登录、查看和管理自己的收件箱。

如果你的需求只是一个人集中管理多个项目邮箱，问题不大；如果需要员工独立登录、团队协作和细粒度权限控制，Google Workspace 或 Microsoft 365 这类企业邮箱会更值得考虑。

4. 邮件数据主要存储在美国

如果你比较在意邮件数据存放在哪里，这一点也需要提前了解。

根据 Plainmail 的隐私政策，其邮件服务器位于美国弗吉尼亚州 Ashburn，邮件文件使用 Cloudflare R2 存储，加密备份存放在美国俄亥俄州的 Amazon S3，外发邮件则通过 Amazon SES 处理。

Plainmail 表示不会出售或出租用户数据，也不会主动阅读用户邮件。入站邮件会进行垃圾邮件扫描，工作人员可能在用户请求客服协助或法律要求的情况下访问相关内容。

对于个人项目和普通商务通信，这些信息主要用于了解服务商的数据处理方式。如果涉及客户敏感资料、企业数据驻留要求或特定地区的合规义务，建议先评估其数据存储位置和隐私政策是否符合自己的要求，不要仅凭服务商的隐私声明判断合规性。

5. 取消订阅前，记得先迁移和备份邮件

Plainmail 支持标准 IMAP/SMTP，因此以后如果想换到 Google Workspace、Migadu 或其他邮件服务，可以通过兼容的邮件客户端或迁移工具复制已有邮件。

不过，取消订阅并不意味着邮箱数据会一直保留。订阅结束后，邮箱和账户数据会在 60 天内删除，加密备份副本可能再需要最多 60 天完成清除。

所以，如果准备停止使用 Plainmail，建议先导出邮件和附件，确认迁移完整后再修改域名的 MX 记录。不要等到订阅结束后才考虑备份，也不要把它当成长期邮件归档服务。

Plainmail 值得用吗？什么情况下适合选择它？

如果你同时运营多个网站、SaaS 项目或副业，想给每个项目配置独立的域名邮箱，又不想为每个邮箱单独支付订阅费用，Plainmail 值得考虑。

例如，你可以用它管理不同网站的 hello@、support@ 和 contact@ 邮箱，通过 Apple Mail、Outlook 等客户端统一收发邮件。如果平时也使用 Claude 或其他 AI Agent，还可以通过 MCP 管理域名和邮箱。

它比较适合自己管理多个项目邮箱的个人站长、独立开发者，以及需要控制邮箱订阅成本的小型项目运营者。每月 $5 的固定价格，让域名和邮箱数量比较容易规划。

不过，并不是所有人都需要 Plainmail：

  • 只需要接收网站联系邮件：Cloudflare Email Routing 通常就够了，不必额外购买完整邮箱服务。
  • 更看重低价：可以比较 Purelymail 和 Migadu，看看它们的年度套餐和资源限制是否更符合自己的使用量。
  • 需要多人独立使用邮箱：如果员工或客户需要分别登录、管理自己的收件箱，Google Workspace 或 Microsoft 365 更值得考虑。
  • 需要邮件营销或 Newsletter：Plainmail 不适合这类用途，应该选择专门的邮件营销平台。

简单来说，Plainmail 的优势不是功能比大型企业邮箱更全面，而是用相对固定的成本管理多个域名下的独立邮箱。如果你主要由自己管理这些邮箱，又不需要复杂的团队权限，它的定价和管理方式就比较有吸引力。

如果准备将它用于正式业务，建议先拿一个非关键域名试用，确认邮件收发、DNS 配置、客户端连接和邮件迁移都符合预期，再逐步迁移其他域名。

常见问题

一个 Plainmail 账号最多能管理多少个域名和邮箱？

官方套餐支持最多 50 个域名、100 个邮箱和 25GB 存储，每月 $5。没有按域名或邮箱数量逐个收费，但需要遵守公平使用及发信限制。

Plainmail 和普通 Gmail 邮件转发有什么区别？

普通邮件转发主要负责接收并转发邮件，Plainmail 则提供真正的 IMAP/SMTP 邮箱，可以使用域名地址直接收发邮件。

Plainmail 可以发送 Newsletter 或营销邮件吗？

不可以。官方明确禁止 Newsletter、营销邮件、批量推广和 Cold Outreach。需要这些功能时，应选择专门的邮件营销服务。

Plainmail 每天真的可以发送 200 封邮件吗？

官方套餐页标示每个邮箱每天最多 200 封，但新账号前 14 天每天最多发送 50 封，之后根据正常发送记录自动提高。具体提升时间没有公开承诺。

可以让员工或客户分别登录自己的邮箱吗？

目前公开说明显示，Plainmail 的收件箱访问权限以网站所有者为主，尚不能按成熟企业邮箱的多用户独立权限管理能力来理解。

Plainmail 可以连接 Claude 吗？

可以。Plainmail 提供远程 MCP Server，支持 Claude 网页版、桌面版、Claude Code，以及其他兼容远程 MCP 的客户端。连接后可以根据授权管理域名、邮箱和邮件。

取消 Plainmail 后还能迁移邮件吗？

可以。Plainmail 使用标准 IMAP，可以通过兼容客户端或邮件迁移工具复制邮件，再将域名 MX 记录指向新的邮件服务商。但建议在取消订阅前完成导出，因为官方规定订阅结束后会启动数据删除流程。
