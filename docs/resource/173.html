Fast Note Sync：Obsidian 多平台实时同步与私有化部署的笔记插件

发布于 2026-01-07

📝 Fast Note Sync 插件介绍

Fast Note Sync 是一款专为 Obsidian 用户设计的高性能笔记同步与备份插件，支持私有化部署，并实现跨平台、实时、无干扰的同步体验。它不仅能同步文本笔记，还全面支持图片、音频、视频等附件文件，适用于 Mac、Windows、Android、iOS 各主流平台，充分满足移动办公与多设备使用需求。

🔧 插件亮点功能

极简配置，开箱即用

无需繁琐设置，只需粘贴远端服务配置，即可快速启动同步服务。专为非技术用户打造的极简上手流程，让效率最大化。

实时笔记同步

自动监听 Obsidian Vault 中的笔记创建、修改与删除操作，确保各设备间内容始终一致，实时更新不丢稿。

全面附件支持

同步包括图片、音频、视频等在内的所有非设置类文件。需注意插件版本 v1.0+ 与服务端 v0.9+ 才能稳定支持此功能。

多设备配置同步

支持同步插件配置内容，免去多设备手动复制配置的烦恼（需插件 v1.4+，服务端 v1.0+，功能仍在测试中）。

历史版本管理

可查看任意笔记的历史修改版本，通过插件或服务端 WebGui 快速访问修改记录与内容对比。

服务端版本可视

插件界面可查看当前连接服务端的版本信息，便于维护与排查问题。

🌍 多语言 & 多平台支持

插件具备完整的多语言界面，并兼容 Mac、Windows、Android、iOS 等主流系统，为跨平台用户提供统一流畅体验。

🚀 快速开始指南

  • 手动安装插件：
    访问 GitHub 发布页，下载最新版插件包并解压至 .obsidian/plugins/ 目录。
  • 配置服务端：
    插件需搭配独立部署的 Fast Note Sync Server 使用。配置方式简洁，只需粘贴服务端配置即可完成连接。

⚠️ 插件尚未上架 Obsidian 官方插件市场，当前需通过手动方式安装。
