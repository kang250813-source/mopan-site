Logi Options+ Mini：一键禁用 AI 组件与推广弹窗 (罗技驱动深度精简/优化指南)

发布于 2026-01-14

你是否发现罗技官方的 Logi Options+ 越来越臃肿了？

强制要求登录 (SSO)、后台常驻的分析服务 (Analytics)、关不掉的 AI Prompt Builder 弹窗，甚至还有设备推荐… 这些功能不仅占用内存，还干扰工作。如果你只想安安静静地用鼠标和键盘，Logi Options+ Mini 就是你一直在寻找的解决方案。

一、 什么是 Logi Options+ Mini？

这是一个开源的驱动定制安装工具。它的原理非常巧妙：它不是破解版，而是利用罗技官方安装包的隐藏命令行参数，实现“官方原版”的模块化安装。

它能帮你“干掉”什么？(Debloat Features)

  • 🚫 LogiVoice / AI Prompt Builder： 彻底移除烦人的 AI 语音和写作助手。
  • 🚫 Analytics / SSO： 移除用户数据收集和强制账号登录模块。
  • 🚫 Device Recommendation： 移除软件内的新产品推广弹窗。
  • 🚫 Auto Update： 此时此刻，由你决定何时更新。

它保留了什么？

它只保留你真正需要的核心功能：按键自定义映射、SmartActions (宏命令) 和基础驱动支持。

二、 跨平台安装指南 (Windows & macOS)

🍎 macOS 用户安装步骤

(支持原生 GUI 应用或终端脚本)

  1. 下载项目的 最新 Releases 版本。
  2. 安全提示： 由于是开源工具，首次打开可能会被 macOS 拦截。请前往 设置 -> 隐私与安全 点击“仍要打开”。
  3. 或者使用更极客的 Shell 方式： 
    git clone https://github.com/tjsky/logi-options-plus-mini.git
cd logi-options-plus-mini
chmod u+x logi-options-plus-mini.command
./logi-options-plus-mini.command

🪟 Windows 用户安装步骤

Windows 用户更加简单，无需复杂的 Git 操作，甚至可以直接下载脚本运行。

  1. 下载项目 ZIP 包或 Run_Install.bat 脚本。
  2. 右键以管理员身份运行 Run_Install.bat。
  3. 交互式配置： 脚本会自动下载官方驱动，并询问你需要保留哪些功能。
    • 输入 0：静默安装。
    • 直接回车：极简安装（推荐），不开启任何额外功能。
    • 自定义：例如输入 6 10，仅保留背光控制和 SmartActions。

三、 常见问题 (FAQ)

Q: 这会影响我的保修或设备功能吗？
A: 不会。这是官方驱动的合法配置安装，核心驱动文件均来自罗技官网下载。

Q: 安装失败怎么办？
A: 如果你之前安装过完整版，建议先使用卸载工具（如 macOS 的 Pearcleaner 或 Windows 的 Geek Uninstaller）彻底清理旧版本及其注册表残留，再运行本脚本。
