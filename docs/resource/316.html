Firefox 内置 VPN 已逐步推送：免费隐藏 IP，但只保护浏览器流量

发布于 2026-06-29

最近有 Firefox 用户发现，浏览器里多了一个新功能：Firefox 内置 VPN。

它不是插件，也不是之前那个付费的 Mozilla VPN，而是火狐正在分阶段测试的浏览器级隐私功能。简单说，就是让 Firefox 里的网页流量先经过一层安全代理，再访问目标网站，用来隐藏真实 IP，并降低网站通过 IP 判断你所在位置的准确性。

看到“免费 VPN”这几个字，很多人第一反应可能是：能不能当全局代理用？能不能拿来下载？答案基本是否定的。它只管 Firefox 浏览器里的流量，不管微信、游戏、其他浏览器，也不适合当长期网络代理方案。

大白话：你可以把它理解成 Firefox 自带的一层“网页隐私保护”。打开后，网站更难直接看到你的真实 IP；但它不是系统级 VPN，也不会保护电脑里其他软件的联网流量。

Firefox 内置 VPN 和 Mozilla VPN 根本不是一回事

这是大家最容易搞混的一点，Mozilla 官方在支持文档中也专门强调了这两者的区别。很多人以为这次测试的是那个收费多年的全设备代理服务，其实完全不同。

 

Mozilla VPN（付费产品）： 这是一个成熟的全设备安全方案。一份订阅可以保护多台设备，它接管的是你整台电脑或手机的网络出口。不管你是用微信、玩游戏还是用其他浏览器，所有流量都在保护范围内。

Firefox 内置 VPN（本次免费测试功能）： 从命名就能看出，它是“浏览器专属”。它只遮蔽你在 Firefox 浏览器窗口内产生的流量。一旦你关掉火狐，或者切换到其他 App，这层保护就不复存在了。

Firefox 内置 VPN 当前流量规则：夏季不限量，之后恢复 50GB

这里要分清“当前活动”和“常规规则”。按 Mozilla 官方说明，Firefox 内置 VPN 原本带有每月 50GB 的数据限制；但在 2026 年夏季活动期间，符合条件的用户到 8 月 31 日前可以临时获得不限流量，并使用更多 VPN 位置。

当前状态：到 2026 年 8 月 31 日前，符合条件的 Firefox 内置 VPN 用户可临时不限流量。9 月 1 日后，官方说明会恢复为每月 50GB，并回到 5 个可选位置。实际显示以 Firefox 内置 VPN 面板和 Mozilla 官方页面为准。
  • 活动期内更适合试用：如果你已经有入口，现在测试网页浏览、公共 Wi-Fi 下的 IP 隐藏会更宽松，不用太担心 50GB 很快用完。
  • 常规规则仍要记住：活动结束后会恢复 50GB/月。查资料、看网页基本够用，但长期高清视频、大文件传输仍不适合。
  • 企业环境不推送：如果你的 Firefox 由公司 IT 部门统一管理，并启用了 Enterprise Policies，这个功能大概率不会出现。它更偏个人用户，不是团队统一网络出口方案。
  • 日志保留有限：官方说明会保留维持服务运行所需的技术数据，比如连接状态和当天流量消耗；不会记录你具体访问了哪些网站或通信内容。

Firefox 内置 VPN 开放地区：中国大陆用户现在能看到入口吗？

Firefox 内置 VPN 还不是全球开放，而是按地区和账号分批推送。Mozilla 支持页当前列出的地区已经扩展到多个国家和地区，包括美国、英国、德国、法国、加拿大、澳大利亚、日本、马来西亚、新加坡、泰国等。

中国大陆目前不在官方开放名单里。对大陆直连用户来说，即使升级到新版 Firefox，也不一定能看到入口；连接稳定性和实际体验也不好判断。现阶段更适合把它当成 Firefox 的功能更新来了解，不建议当成稳定可用的网络方案。

Firefox 内置 VPN 怎么开启？先看你有没有入口

如果你的账号和地区已经被纳入测试，开启方式并不复杂。更新到支持版本的 Firefox 后，浏览器右上角工具栏可能会出现 VPN 提示或 VPN 图标。点击后按提示登录 Mozilla 账号，再在 VPN 面板里打开开关即可。

  • 更新 Firefox：该功能从 Firefox 149 起分阶段推出，建议先把浏览器更新到较新版本。
  • 登录 Mozilla 账号：Firefox 内置 VPN 需要登录账号后使用。
  • 查看工具栏入口：符合测试条件时，工具栏右上角会出现 VPN 提示或 VPN 图标。
  • 在 VPN 面板中开启：点击图标进入面板，用开关启用或关闭该功能。

如果右上角没有 VPN 图标，多半是账号、地区或推送批次还没轮到你。现阶段不建议强行开启，等官方入口出现再试更稳。

 

Firefox 内置 VPN 适合谁，不适合谁？

把它当成 Firefox 的一个“小安全开关”会更准确。它适合解决的不是全设备联网问题，而是 Firefox 浏览器里的网页访问隐私。

比较适合：你本来就在用 Firefox，也经常连接机场、酒店、咖啡馆这类公共 Wi-Fi。打开后，网站不容易直接看到你的真实 IP，基于 IP 判断位置的准确性也会降低。

不太适合：你想让电脑里所有软件都走同一套网络保护，或者准备用它长期看高清视频、传大文件。Firefox 内置 VPN 只管浏览器流量，还有流量额度限制，不能当成全局 VPN 或下载通道来用。

所以这项功能更像是 Firefox 给普通用户加的一层轻量隐私保护。能看到入口的用户可以试试；如果你没有入口，或者需要更稳定的全设备方案，就没必要为它折腾。
