Lubulu 健康决策转盘，让每一次选择更理性

发布于 2025-07-04

Lubulu应用概述

Lubulu 是一款极简而优雅的健康决策工具，通过 99 等分的转盘机制为你提供理性且富有趣味的选择过程。每次转动都伴随动画与音效，让你在面对诱惑时多一份仪式感，也保留最终决定权。

Lubulu核心功能

转盘抽取

  • 99 等分轮盘：包含 1 个“Lu！”（红色）和 98 个“不Lu”（绿色）
  • 真随机算法：基于 Web Crypto API，确保每次结果公平公正
  • 精美动画与音效：5 秒、12 圈旋转动画配合旋转与提示音
  • 智能确认：若抽中“Lu！”，可自行决定是否执行该选择

日历记录

  • 历史追踪：用彩色圆点标记每日决策结果
  • 一目了然：红点代表“Lu”，绿点代表“不Lu”，灰杠表示未抽取
  • 月份导航：支持查看任意月份的记录
  • 今日高亮：当前日期特殊标识，便于快速定位

数据统计

  • 实时统计：显示“Lu”次数、“不Lu”次数及总次数
  • 克制率计算：健康选择占比即时可见
  • 可视化展示：用清晰数字让数据一览无余

高级设置

  • 保底机制：可设定连续“不Lu”天数上限，达到后必然触发“Lu！”
  • 数据管理：支持导入与导出历史记录，便于备份与迁移
  • 输入校验：所有参数严格验证，保障数据安全

分享功能

  • 一键截图：自动生成包含完整界面的高质量 PNG 分享图
  • 结果保留：截图中含有当前抽取结果，让你的决定更具说服力

Lubulu视觉与交互设计

主色采用深紫色（#673AB7）象征理性与克制，辅以淡紫背景（#EDE7F6）和纯净白色，结合扁平化、新拟态与玻璃拟态效果。响应式布局兼容桌面端（1440×1024）和移动端（390×844），每次点击与动画都带来即时视觉与听觉反馈。

Lubulu技术实现

  • 前端框架：原生 HTML5、CSS3 与现代 JavaScript (ES6+)
  • 随机数生成：Web Crypto API 提供高质量真随机数
  • 动画效果：CSS 动画与 Web Animations API
  • 音效处理：Web Audio API
  • 本地存储：localStorage
  • 截图工具：html2canvas

Lubulu设计理念

随机性助力理性

面对诱惑时常有人想“就这一次”，而 Lubulu 引入随机元素，让决策过程既有趣又公平。大多数情况下得到“不Lu”的结果，你更易坚持健康习惯，偶尔的“Lu！”又不会让过程过于刻板。

概率说明

  • “不Lu”概率：98/99 ≈ 98.99%
  • “Lu！”概率：1/99 ≈ 1.01%
  • 可通过保底机制设定连续“不Lu”天数上限

这种设计让你在绝大多数情况下做出健康选择，同时保留小概率奖励，让健康习惯养成更轻松。
