AutoGLM For Android：无需电脑的纯 Android 端智能手机自动化助手

发布于 2026-01-02

一站式 Android 自动化 AI 助手

AutoGLM For Android 是一款基于 Open-AutoGLM 项目深度改造的 Android 原生应用，彻底摆脱对电脑和 ADB 连接的依赖，让你仅凭手机就能用自然语言控制设备完成一系列操作。从点击、滑动到输入文本、打开 App，甚至还能理解屏幕内容并规划操作流程。

AutoGLM For Android截图

🔧 原生运行，无需 ADB

AutoGLM 彻底打破传统自动化工具的门槛，只需手机本身即可运行。无需连接电脑，无需 USB 调试，只需安装 Shizuku 和 App 本体，即可解锁强大的自动化能力。

  • Shizuku 权限管理：无需 Root，即可获取系统权限
  • Material Design 原生体验：交互简洁、流畅直观
  • 悬浮窗反馈机制：操作步骤、思考过程全程可见
  • 兼容多模型 API：支持任何 OpenAI 格式 + 图像理解模型

🎯 功能亮点

自然语言任务执行

只需一句话描述你想做的事情，AI 会自动截图、分析界面、规划步骤并执行操作。

示例任务包括：

  • 打开微信 → 搜索联系人 → 发送消息
  • 进入淘宝 → 搜索耳机 → 按销量排序
  • 打开高德地图 → 导航至最近的地铁站
  • 启动抖音 → 刷5个视频

屏幕理解 + 多种操作

支持截图 → 图像模型识别 → 执行操作链条，涵盖点击、滑动、长按、双击、文本输入、应用启动等常用动作。

可视化控制

任务状态清晰可见，可随时暂停、继续、取消任务。

高阶配置功能

  • 多模型快速切换
  • 任务模板一键复用
  • Prompt 自定义系统提示词
  • 通知栏快捷磁贴快速启动
  • 导出调试日志，自动脱敏

🚀 快速上手

环境要求

  • Android 7.0 及以上
  • 安装并激活 Shizuku
  • 连接网络，配置任意 OpenAI 接口模型服务

推荐模型配置示例：

平台 Base URL 模型 说明
智谱 BigModel https://open.bigmodel.cn/api/paas/v4 autoglm-phone 限时免费开放
ModelScope https://api-inference.modelscope.cn/v1 ZhipuAI/AutoGLM-Phone-9B 支持 image_url

详细配置、权限引导、模型设置等说明均可在应用内完成，并配有详尽的交互提示。

📱 原生 Android UI，轻松上手

应用提供清晰分区的界面模块，包括：

  • 主界面：任务输入、执行状态
  • 设置页：模型参数、Agent 控制、提示词设定
  • 历史页：任务记录与截图查看
  • 悬浮窗：任务进度、操作反馈、执行详情
