ComeCut概览

ComeCut「来剪」 是一款轻量级的免费开源视频编辑器，提供网页版与桌面版（Windows、MacOS、Linux），用户无需注册即可使用。软件灵感来自 CapCut，但更注重开源生态与 AI 融合，目标是打造一个真正开放、可扩展的视频编辑平台。

关键亮点

  • 免费使用：无限制功能开放。
  • 零门槛：无需注册即可开始编辑。
  • 隐私友好：强调本地化处理，保障个人数据安全。
  • AI 融合：引入多家模型与工作流，提升剪辑与字幕效率。
  • 跨平台体验：Web、Windows、macOS、Linux 均可访问（当前为 beta 演示）。

AI 能力与状态

字幕翻译（支持 SRT / VTT / LRC）

  • Gemini：✅ OK
  • DeepSeek：✅ OK
  • Ollama：✅ OK

可一键生成与翻译双语字幕，适合教程视频、出海内容与多语渠道分发。
