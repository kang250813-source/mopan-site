PPT Master：AI驱动的多格式SVG演示文稿生成系统，支持PPT、小红书、朋友圈等场景

发布于 2025-12-21

AI 驱动的多格式演示文稿生成器

PPT Master 是一个以 AI 为核心的智能视觉内容创作系统，通过角色协作方式（策略师、执行师、图片生成师、优化师），实现从内容策划、图文视觉到PPT、社交贴图的自动生成，全面提升内容制作效率与美感。

该工具支持生成符合麦肯锡、BCG 等顶尖咨询风格的商业PPT，也适用于小红书笔记、朋友圈海报、营销推广图等格式，满足多场景下的内容分发需求。

主要功能亮点

🎨 多格式支持，场景全面覆盖

  • PPT（16:9 / 4:3）
  • 小红书封面（3:4）
  • 朋友圈与社交平台（1:1 / 9:16）
  • 支持SVG输出，可直接编辑与高清放大

🤖 多角色协作式AI生成

  • 策略师：理解需求、制定结构
  • 图片生成师：辅助生成视觉配图
  • 执行师：排版逻辑与组件拼接
  • 优化师：进行排版与视觉微调

📊 数据可视化组件内置

  • KPI 图表、时间轴、漏斗图、数据模块
  • 全流程遵循 CRAP 四大设计原则（对比、重复、对齐、亲密性）

🖼️ 高质量 SVG 输出

  • 所有页面均为矢量图形格式
  • 自适应不同分辨率，无需第三方依赖

快速上手指南

  1. 克隆项目仓库
    使用命令行或编辑器 clone 代码：
    git clone https://github.com/hugohe3/ppt-master.git
  2. 选择工具启动对话
    可使用 Antigravity（推荐）、Cursor、VS Code + Copilot 等任意 AI 编辑器
  3. 直接输入需求
    示例：

    “我有一份 Q3 财报草稿，想生成10页标准咨询风格的PPT”
    系统将自动完成结构分析与图文排版。

推荐工具与模型

工具/模型 推荐度 说明
Antigravity ⭐⭐⭐ 免费集成Opus 4.5，支持生成图文并优化图像
Gemini ⭐⭐ 适合生成高分辨率配图，建议下载原图使用
Claude Code ⭐⭐ Anthropic CLI 工具，适合开发者用户

🧽 Gemini 图片含星星水印？可用 gemini_watermark_remover.py 一键去除。
