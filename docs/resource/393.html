侠客日记（SwashbucklerDiary）：开源跨平台的本地隐私日记APP

发布于 2025-10-17

🗡 开源日记新方式：记录你的江湖日常

侠客日记（Swashbuckler Diary） 是一款开源、跨平台的本地日记应用，基于 Blazor 技术开发，支持 Windows、macOS、Linux、Android、Web 多端使用。它以极简设计与隐私保护为核心理念，让每一次记录都更自由、更安心。

相比云笔记或联网日记应用，侠客日记的最大亮点在于 “完全本地存储，无需联网”，所有文字、图片、视频都保存在你的设备中，不上传云端，数据始终掌握在你自己手里。

🧩截图界面

✍ 功能亮点

  • Markdown 实时渲染：支持标题、列表、代码块、表格等格式，书写体验丝滑自然。
  • 多端适配与响应式布局：无论是手机、平板还是桌面端，都能获得统一体验。
  • 多媒体支持：支持图片、音频、视频、脑图、流程图、甘特图等多种内容形式。
  • 隐私保护模式：可设置加密与本地模式，防止外泄。
  • 标签分类与情绪追踪：可按主题、天气、心情、位置管理你的生活轨迹。
  • 文件导出与备份：支持多格式导出、WebDAV云端备份、局域网同步。
  • 深色模式与多语言支持：夜间使用更护眼，也适合全球用户体验。

💻 系统兼容与开发环境

侠客日记支持以下平台：

  • Windows 10/11
  • macOS 11+
  • Linux 各主流发行版
  • Android 8.0+
  • iOS 14+（测试版）
  • Web 浏览器版本

开发环境建议使用 Visual Studio 2022 或 VS Code，支持 .NET 桌面开发与多端 UI 框架。
