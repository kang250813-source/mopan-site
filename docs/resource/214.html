Port22：Claude Code、Codex 远程控制工具，用手机管理 AI Agent

发布于 2026-08-06

直白点说：
Port22 就相当于给你的 Mac 终端 AI（比如 Claude Code）配了一个“iPhone 遥控器”。它不替代电脑上的开发环境，而是让你离开工位后，也能在手机上查看状态并处理 AI Agent 的授权请求。
当前状态：
截至目前，Port22 仍处于 Waitlist（等待列表）阶段，Mac 端和 iOS App 尚未正式开放下载。本文主要基于公开资料介绍其功能逻辑，实际体验需要等待官方开放测试。

如果你现在主要还是在网页端和 ChatGPT 聊天写代码，这个工具你用不上。但如果你已经开始在 Mac 上使用 Claude Code、Codex 或 OpenCode 等终端 AI 编程助手，可能遇到过一个问题：AI Agent 执行长任务时，会因为等待人工确认而暂停。

Port22 是一款连接 Mac 与 iPhone 的开发者效率工具。它不负责生成代码，而是将终端 AI 助手运行状态同步到手机端，帮助用户查看进度并处理授权请求。

 

Claude Code 远程控制：Port22 如何解决 AI Agent 长任务等待问题？

随着 AI 编程能力提升，越来越多开发者开始使用 Claude Code、Codex 等终端 AI Agent 执行代码重构、测试编写和项目分析等长时间任务。但新的问题也随之出现：当 Agent 开始运行后，开发者是否必须一直守在电脑旁？

由于文件修改、命令执行等操作可能需要用户确认，Claude Code 在部分场景下会暂停等待授权。如果开发者暂时离开电脑，任务可能停留在等待状态。

Port22 针对的就是这种场景。它不是替代 Claude Code，而是连接现有的终端会话，将 Mac 上运行的 AI Agent 状态同步到 iPhone，让用户可以远程查看进度，并处理需要确认的操作。

Port22 支持哪些 AI 编程 Agent？

Port22 的定位不是替代 AI 编程工具，而是连接已有的终端 AI Agent 会话。它支持 Claude Code、Codex 和 OpenCode 等终端 AI 编程工具。

  • Claude Code：
    Anthropic 推出的终端 AI 编程助手，也是 Port22 主要面向的使用场景之一。用户可以通过 Port22 查看会话状态，并处理运行过程中的授权请求。
  • Codex：
    OpenAI 推出的 AI 编程工具，Port22 可以同步 Codex 终端会话状态，并在手机端查看运行进度和处理需要确认的操作。
  • OpenCode：
    开源终端 AI 编程工具，Port22 可以将其运行状态同步到 iPhone，用于查看会话进度和处理交互请求。

但是，Port22 本身不是移动端 IDE，也不会在 iPhone 上重新运行这些 AI 编程环境。它主要负责同步 Mac 上已有的终端会话状态，并提供移动端查看和授权交互。

Port22 和 Claude Code、Codex 官方移动端有什么区别？

Claude Code 和 Codex 都在提供移动端体验，但 Port22 解决的是另一个问题：如何管理已经运行在 Mac 终端里的 AI Agent。

官方移动端更适合直接使用 AI 服务，而 Port22 更偏向终端开发工作流的远程辅助。它不会替代 Claude Code、Codex 或 OpenCode，而是连接这些已经运行中的会话，让用户通过 iPhone 查看状态，并处理需要确认的操作。

  • 已有终端习惯：不需要迁移 Claude Code、Codex 等 CLI 工作流。
  • 多 Agent 场景：可以同时查看多个终端 AI 会话状态。
  • 长任务管理：适合代码重构、测试生成等需要等待较长时间的任务。

Port22 如何连接 Mac 和 iPhone？

很多人的第一反应是：我用 SSH 连回家里的 Mac 不就行了？当然可以，但如果只是查看 AI Agent 状态和处理授权请求，SSH 需要维护完整的远程终端连接，对于这类场景来说配置和使用成本会更高。

📱 Port22 实际运行演示

演示展示 Port22 如何将 Mac 上运行的 AI Agent 状态同步到 iPhone，并处理终端会话中的确认请求。

Port22 采用的是更轻量的连接方式。它不需要你更换终端环境，也不需要重新包装 Claude Code、Codex 等现有 AI 编程工具，而是直接连接已经运行中的 Mac 终端会话，将相关状态同步到 iPhone。

对于同时使用多个 AI 编程助手的用户，Port22 支持查看多个终端会话。例如可以在 Mac 上运行 Claude Code 处理 Bug，同时运行 Codex 编写测试，然后通过手机端统一查看运行状态和处理需要确认的操作。

Port22 通过 Apple ID 进行设备配对，连接策略采用局域网优先：当 Mac 和 iPhone 处于同一网络环境时优先建立本地连接，离开局域网后使用加密中继保持通信。

除了基础状态同步，Port22 还针对 iPhone 提供实时通知体验，包括 Dynamic Island 和锁屏状态展示，方便用户快速查看 Agent 当前状态以及是否需要进一步操作。

需要注意的是，Port22 会同步终端会话相关内容。如果涉及企业代码、商业项目或敏感开发环境，建议在正式使用前了解其数据传输方式，并确认是否符合团队安全要求。

Port22 适合哪些开发者？

Port22 解决的是 AI Coding Agent 长任务运行时，需要人工确认但用户又无法一直守在电脑旁的问题。因此，它更适合已经将 Claude Code、Codex 等终端 AI Agent 纳入日常开发流程的用户。

  • 使用 AI Agent 处理复杂任务的开发者：
    例如代码重构、Bug 排查、测试生成等需要较长执行时间的任务，可以通过手机查看运行状态。
  • 同时运行多个 Agent 工作流的用户：
    例如一个 Claude Code 负责修改代码，一个 Codex 负责生成测试，可以通过 Port22 统一查看任务进度。
  • 独立开发者：
    需要让 AI 长时间处理项目任务，又不希望一直守在电脑旁，可以通过手机处理必要确认。

如果你只是偶尔使用 AI 生成代码片段，或者主要使用网页端 ChatGPT、Claude 等聊天工具，Port22 的使用价值会比较有限。

Port22 当前状态和使用限制

除了目前仍处于 Waitlist 阶段，Port22 还有一些使用上的限制，需要根据自己的开发环境判断是否适合。

  • 设备要求：
    目前主要面向 Mac + iPhone 用户，需要 Mac 端持续运行 AI 编程会话，并通过 iPhone 查看状态。
  • 功能边界：
    手机端主要用于查看 Agent 状态和处理授权请求，并不能替代电脑上的完整开发环境。
  • 版本限制：
    官方目前公布的信息，免费版本支持 1 台 Mac 和 2 个并行会话。未来更多会话能力是否收费，以正式版本规则为准。

Port22 更适合已经把 Claude Code、Codex 等终端 Agent 纳入日常开发流程的用户。对于普通 AI 编程体验用户来说，它解决的是一个比较具体的问题：让长时间运行的 Agent 不必一直等待人在电脑旁确认。
