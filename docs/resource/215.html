BrowserWing 浏览器 Agent：开源 AI 网页自动化平台，录制脚本 + MCP 集成，低 Token 高效率

发布于 2025-12-19

一款真正实用的AI浏览器助手

BrowserWing 是一个基于浏览器的自动化平台，它不仅能获取信息，更能执行复杂操作，如发帖、部署、填表、订票等任务，并可通过自然语言或大模型指令自动化整个流程。无需写代码、不耗费大量 token、启动即用，真正解决了市面上 AI 浏览器普遍存在的执行效率低、配置复杂、成功率差等问题。

支持哪些操作？

信息获取场景：

  • 抓取小红书、知乎、即刻、v2ex 等平台内容
  • 获取 GitHub Trending 动态、帖子回复数、推特动态
  • 追踪域名过期时间或 GitHub Star 数量

执行与发布操作：

  • 自动发布知乎、CSDN、公众号等平台文章
  • 执行部署流程、填写网页表单、预订服务
  • 组合任务链，比如：自动抓取 GPT5.2 热门讨论、整理摘要并发送到微信

特性亮点一览

  • 脚本录制与可视化编辑：支持点击、导航、输入等操作自动记录
  • 浏览器管理：控制实例、Cookie 持久化
  • MCP 协议支持：将脚本转为 LLM 可读的命令序列
  • 大模型接入：兼容 OpenAI、Claude、DeepSeek 等模型调用
  • 环境要求极低：仅需安装 Chrome 或 Chromium

快速开始方式

你可以通过以下两种方式快速使用 BrowserWing：

🔹 方式 A — 直接下载可执行文件（推荐）

  • 前往 GitHub Releases （国内加速：网盘）下载对应操作系统版本
  • 启动后访问 http://localhost:8080 即可使用

🔹 方式 B — 从源码构建

支持 Go 与 pnpm 的完整构建流程，并可构建集成前后端版本或打包发布版本。

为什么选择 BrowserWing？

  • 开源免费，无商业限制
  • Token 使用友好，成本极低
  • 支持复杂网页任务自动化，脚本可回放稳定性强
  • 与大模型高度集成，适合 AI Agent、RPA、数据爬取与智能浏览场景
  • 丰富社区生态与脚本示例，轻松上手并扩展
