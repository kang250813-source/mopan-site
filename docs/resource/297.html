iMessage Exporter：开源跨平台的 iMessage 数据导出与诊断工具

发布于 2025-11-19

📨 iMessage Exporter 是什么

iMessage Exporter 是一款面向 macOS、Windows 和 Linux 的开源工具，用于提取、导出和诊断 iMessage 数据。项目由社区维护，目标是更准确、更全面地呈现 iMessage 数据结构，让用户能够真正掌控自己的通讯记录。该工具既包含可执行文件，也提供开发者可直接调用的库，适用于个人备份、设备迁移、数据分析、企业合规等多种场景。

🚀 能做什么

工具专注于安全、只读地访问 iMessage 数据，支持：

  • 导出、保存、备份与归档 iMessage 对话
  • 迁移消息记录到不同设备或平台
  • 保存图片、视频、音频等多媒体附件
  • 对 iMessage 数据库运行诊断
  • 生成 txt 或 HTML 格式的聊天记录
  • 完整保留线程、表情、格式化文本、贴贴、Tapbacks、Apple Pay 等多种互动内容
  • 满足合规性或数据保留需求
  • 支持 macOS、Windows、Linux 三大平台

所有功能均基于开源代码，用户对自己的数据拥有完全的掌控权。

🧩 二进制工具（Binary）

可执行文件 imessage-exporter 提供快速的导出与诊断能力，可将聊天记录转换为便于阅读的文本或 HTML 文件，并检测数据库潜在问题。安装方式可在项目文档中查看。

🛠 开发者库（Library）

项目内的 imessage_database 库提供跨平台数据结构，开发者可以在自己的应用中读取和处理 iMessage 数据。文档中包含结构说明和示例代码。

🔎 支持的功能范围

项目支持 macOS Tahoe 26.1 与 iOS 26.1 的全部 iMessage 特性，包括：

  • iMessage、RCS、SMS、MMS
  • 消息线程与回复
  • 文本格式化
  • 多媒体附件
  • Tapbacks、Sticker、Expressives
  • 数字触控、手写消息
  • URL 预览与应用内扩展
  • 编辑过的消息
  • 群聊与 Apple Pay 信息

详情可在项目主页查看。
