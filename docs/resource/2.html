InvoiceFlowAI：开源发票自动整理工具，邮箱下载、OCR 与 Excel 汇总

发布于 2026-08-28

每到月底报销的时候，发票一多就有点麻烦了。邮箱里找邮件、下载 PDF 或 OFD、重新命名，再把日期、金额和发票号填进 Excel，虽然看起来每一步都不复杂，但是这些步骤加起来就很费时间。

InvoiceFlowAI 就是用来省掉这些重复操作的一个开源发票自动整理工具。配置好邮箱后，它可以批量收集电子发票，用 AI OCR 提取金额等信息，再自动整理文件并生成 Excel 报销汇总表。目前它更适合个人、自由职业者和有固定报销需求的小团队使用。

发票自动整理工具 InvoiceFlowAI 能做什么？

InvoiceFlowAI 处理的是一整套报销前整理流程：先从邮箱里找到并下载发票，再识别票面上的金额、日期等信息，最后按规则整理文件并生成 Excel 汇总表。相比只负责下载附件或单独做 OCR 的工具，它把发票收集、识别和归档放在了一套流程里，非常方便。

它支持常见的 PDF、OFD 和 XML 电子发票，也能处理部分邮件里的发票下载链接，例如百望云这类需要跳转后才能拿到 PDF 的场景。住宿发票和水单、打车发票和行程单还可以自动配对并相邻命名，整理完成后会生成对应的文件目录和 Excel 报销台账，方便后续核对。

发票只有下载链接怎么办？

有些电子发票邮件并不会直接附上 PDF 文件，而是只提供“查看发票”或“点击下载”之类的网页链接。碰到这种情况，单纯扫描邮箱附件就很容易漏掉发票。

InvoiceFlowAI 对这类邮件加入了 PDF 恢复流程。系统会先识别邮件中的发票下载链接，再根据链接类型尝试获取对应的 PDF 文件。项目目前对包括百望云在内的部分发票平台做了适配，并结合直接下载、网页解析等方式处理只有链接、没有附件的发票邮件。

这项功能比较适合差旅、打车、住宿等发票来源比较杂的场景，可以减少手动打开邮件、进入发票平台再逐张下载 PDF 的操作。不过，不同开票平台的页面和下载机制可能发生变化，并不能保证所有发票链接都能自动恢复，实际使用时仍建议检查是否存在遗漏。

邮箱发票怎么筛选？AI OCR 双引擎怎么识别

邮箱里的绝大多数邮件都和发票无关，全部交给 AI 跑一遍确实没必要，而且也会增加识别时间和 API 调用。InvoiceFlowAI 会先筛选邮件，再处理真正需要识别的附件。

1、四层邮件筛选：依次检查发件域名、邮件主题、正文内容和二维码，把明显无关的邮件提前排除。通过筛选的邮件才会继续提取 PDF、OFD、XML 等附件或发票下载链接。

2、Track A + Track B + 本地兜底：Track A 采用 OCR 提取文字后交给大模型解析，Track B 使用 GLM-4.5V 直接识别发票图片，同时还保留本地正则规则作为兜底。某一路能够可靠提取出结果后，就可以进入后续的分类和归档流程。

这套做法的重点不是让每封邮件都经过大模型，而是尽量把 AI 调用留给真正需要识别的发票材料，减少无效处理和额外的 API 消耗。

InvoiceFlowAI 哪些数据会上传到 API？

InvoiceFlowAI 的邮件读取、发票下载和文件归档主要在本地完成，但 AI 识别部分会根据使用方式调用外部模型。

1、桌面版：启用 GLM OCR 或 GLM 视觉识别后，待识别的发票图片会发送到配置的模型服务，用来提取金额、日期、发票号码等信息，邮件原文不会一起发送。

2、DSH 插件：发票先在本地完成 OCR，再把识别出的文字交给当前选择的 DeepSeek 模型提取字段。发送给模型的主要是 OCR 文本，而不是整封邮件内容。

所以它不能简单理解成完全离线工具。如果发票里包含公司财务、客户信息或其他敏感内容，使用第三方 AI API 前最好先确认团队的数据合规要求。

InvoiceFlowAI 支持哪些邮箱和系统？

InvoiceFlowAI 目前主要适配 QQ 邮箱和 163 邮箱，桌面客户端支持 Windows x64 和 Apple Silicon Mac。第一次使用需要配置邮箱 IMAP 授权码；如果要使用 GLM OCR 和视觉识别，还需要准备对应的 API Key。

邮箱和系统支持

1、邮箱：官方目前主要介绍 QQ 邮箱和 163 邮箱的 IMAP 接入方式，Gmail、Outlook / Exchange 暂未列入明确支持范围。

2、Windows：提供 x64 安装版和免安装版。当前版本未签名，首次运行时可能出现 Windows SmartScreen 提示。

3、macOS：目前提供 Apple Silicon（ARM64）版本。应用尚未签名和公证，首次启动时可能需要在“系统设置 → 隐私与安全性”中手动允许打开。

4、AI API：完整的 AI 识别流程会用到 GLM OCR、视觉模型等能力，需要用户自行配置对应的 API Key，实际费用取决于模型和调用量。

目前还有哪些限制？

1、不等于发票管理系统：官方目前没有列出发票验真、重复票据检测，以及微信或支付宝票夹导入等功能，它更偏向邮箱发票收集、识别和整理。

2、识别失败需要人工处理：如果金额、日期、发票号码等信息没识别准，相关文件会被放进“待人工复核”目录，方便你之后手动检查。

3、正式报销还需核对：项目作者明确说明了，不保证识别和生成结果的准确性、完整性，以及税务、财务或会计合规性，金额、日期、发票号码等关键字段建议人工检查。

如果平时一个月只处理几张发票，手动保存可能更省事；发票数量比较多，或者经常需要整理差旅票据时，批量下载、自动命名、凭证配对和 Excel 汇总这些功能才更容易体现出价值。

InvoiceFlowAI 常见问题

Q：InvoiceFlowAI 需要付费吗？
InvoiceFlowAI 项目采用 Apache-2.0 协议开源，桌面客户端可以从 GitHub Releases 下载。使用 GLM OCR、视觉模型等第三方 AI 服务时，需要自行准备 API Key，相关费用按照模型服务商的实际调用量计算。

Q：InvoiceFlowAI 能做发票验真、查重或导入微信和支付宝票夹吗？
目前官方公开文档没有把发票验真、重复票据检测，以及微信或支付宝票夹导入列为支持功能。InvoiceFlowAI 的重点是从邮箱收集电子发票、OCR 提取信息、分类归档和生成 Excel 汇总，如果这些功能是刚需，需要另外确认最新版本或搭配其他工具。

Q：发票识别失败后怎么办？
无法可靠确认的材料会保留到“待人工复核”目录，而不是直接当成正确结果归档。图片模糊、特殊格式或字段识别不完整时，仍需要人工检查和补充。

Q：Intel Mac 可以运行 InvoiceFlowAI 吗？
目前 GitHub Releases 提供的是 macOS Apple Silicon（ARM64）版本，没有提供 Intel x86_64 Mac 的正式安装包。Intel Mac 用户在下载前建议查看最新 Release 是否新增了对应构建。

Q：InvoiceFlowAI 识别出的发票信息可以直接用于正式报销吗？
不建议跳过人工核对。项目作者明确说明，不保证发票数据和生成结果的准确性、完整性，以及税务、财务或会计合规性。正式提交前应检查金额、日期、发票号码和相关凭证是否正确。
