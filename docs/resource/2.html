Kaze AI：AI 图片与视频生成平台，支持 Chat Edit 与 Watermark Removal API

发布于 2026-09-22

Kaze AI 是一个 AI 图片与视频生成平台。可以上传现有图片用 Chat Edit 直接修改，也可以从文字生成新的图片和视频；照片修复、图片扩展、画质增强、人物移除、文字清理这些单一任务，则有独立的 单项图片处理工具可以直接使用。

它比较适合两种用法：一张图片需要来回修改很多次时，用 Chat Edit 连续改；任务已经很明确，比如扩图、修旧照片或者清理图片里的对象时，直接打开对应工具会更快。

开发者也可以通过 API 接入其中一部分能力。目前公开的图像接口包括 Watermark Removal 和 Image Expand，视频侧则提供 Seedance 2.0、Seedance 2.5 等独立 API。网页端使用 credits，API 使用单独的 API Balance，两边并不是同一笔余额。

本文功能、接口和价格信息核对至 2026 年 9 月。Kaze AI 的模型、套餐和 API 价格可能继续调整。

Kaze AI 的三个主要入口

Kaze AI 里的功能很多，但真正使用时并不需要把所有工具都研究一遍。

Chat Edit 适合同一张图片需要连续修改。比如换掉背景、删除桌上的物体，再调整整体风格，可以直接通过自然语言继续描述下一步。

Image / Video Generator 用来从文字、图片或者参考素材生成新的视觉内容。视频模型并不只有一个，平台会提供 Seedance、MiniMax 等不同模型。

单项图片处理工具 则解决明确的单项任务。照片模糊就用 Upscale，需要补画画面边缘就用 Image Expander，旧照片用 Photo Restoration，图片里有不需要的人物或文字，就用对应的移除工具。

选入口时不用想得太复杂：连续改一张图走 Chat Edit，明确的小任务走 单项图片处理工具，从零做内容再进入图片或视频生成器。

Kaze AI Chat Edit 怎么用？

Chat Edit 的重点是直接描述“这张图哪里需要改”。

例如上传一张产品图以后，可以要求换成白色背景、删除桌面上的杂物，再调整整体光线；人物照片也可以修改背景、移除周围元素或者改变整体视觉风格。

同一张图需要连续调整时，这种方式比每改一个地方就重新找一个工具方便。

但自然语言编辑并不等于像素级编辑。遇到品牌字体、复杂排版、人物五官、商品边缘和精细结构时，生成结果仍然应该放大确认。

Kaze AI 的 AI 图片生成与图片处理

图片生成和图片编辑在 Kaze AI 里是两条不同但可以衔接的路径。

从零开始时，可以使用图片生成模型制作广告草稿、社交媒体图片、概念图和视觉素材。已经有图片时，则可以进入 Chat Edit 或单项工具继续处理。

常用的独立图片工具包括：

  • Photo Restoration：修复旧照片和部分受损区域。
  • Enhance & Upscale：放大图片并提升清晰度。
  • AI Image Expander：向画面四周继续生成内容，用来重新构图或改变比例。
  • Remove People：删除照片中的人物并重新补全背景。
  • Remove Text：清理图片里的文字。
  • Logo Remover：处理图片中的 Logo。
  • Watermark Removal：清理水印和其他覆盖元素。

这些功能并不会自动互相叠加。比如 Image Upscaler 负责放大和增强，Watermark Removal 负责清理指定内容，不能因为使用了去水印工具，就默认图片同时完成了画质增强。

Kaze AI 的 AI 视频生成功能

Kaze AI 的视频部分采用多模型方式，当前可以看到 Seedance 2.0、Seedance 2.5、MiniMax H3 等模型，支持文字生成视频和图片生成视频。

这些模型来自不同提供方，并不是都由 Kaze AI 自己训练。实际可以使用哪些模型、支持多长的视频和什么分辨率，会随着平台模型列表变化。

例如 Seedance 2.5 的开发者 API 支持最长 30 秒输出，同时提供文字、图片等参考输入；Seedance 2.0 也有独立的异步视频 API。

如果只是把一张产品图做成动态展示、制作短视频草稿或者测试一个镜头，直接使用网页端会简单很多。需要把视频生成放进自己的应用或自动化流程，再考虑 API 更合理。

Chat Edit、单项图片处理工具、生成模型和 API 怎么选？

网页端和 API 的区别也不只是“处理数量多少”。网页端本身已经支持部分批量操作，API 真正解决的是程序能不能自动提交任务、获取结果和继续下一步流程。

Kaze AI Watermark Removal 一次可以处理 20 张图片

Watermark Removal 网页可以拖入、点击选择或者直接粘贴图片，一次最多加入 20 张。

所以手里有十几张图片时，并不需要为了“批量”专门接 API。网页端已经能够应付这种小批量处理。

Watermark Removal：https://kaze.ai/watermark-removal

AI 清理图片时有一个边界容易被忽略：模型不是把水印下面原来的像素重新读取出来，而是根据附近的纹理和内容重新生成缺失区域。

水印如果位于天空、墙面、桌面等简单背景，通常比较容易补全。压在人脸、头发、商品细节、文字、窗框或重复纹理上时，生成错误会更容易被看出来。

Kaze AI 去水印是还原原图吗？

不是严格意义上的“还原”。

已经被水印覆盖的原始像素并不会因为 AI 处理重新出现。模型看到的是水印以及周围画面，再根据这些信息生成一个视觉上合理的替代区域。

因此处理完成以后，最好重点检查人脸五官、头发边缘、商品小零件、建筑直线、图片文字和重复图案。

缩略图看起来正常，不代表放大以后没有纹理断裂、边缘变形或者生成出来的新细节。

Kaze AI Watermark Removal API

需要把图片处理放进网站、后台、脚本或者自动化工作流时，可以使用 Watermark Removal API。

它采用异步任务方式。程序提交图片以后先取得 task_id，再查询任务状态和最终结果。

API Base URL：

https://api-srv.kaze.ai

提交任务：

POST /api/ext/v1/submit_watermark_removal

查询结果：

POST /api/ext/v1/get_task_result

请求需要携带 API Key：

Authorization: Bearer

使用图片 URL 提交任务

curl --location --request POST \
'https://api-srv.kaze.ai/api/ext/v1/submit_watermark_removal' \
--header 'Authorization: Bearer ' \
--header 'Content-Type: application/json' \
--data-raw '{
  "image_url": "https://example.com/image.png"
}'

提交成功后会拿到类似这样的任务 ID：

{
  "code": 0,
  "message": "success",
  "data": {
    "task_id": "xxxxxxxx"
  }
}

除了公开图片 URL，也可以提交 image_base64。Base64 需要直接传图片数据，不要附带：

data:image/png;base64,

smear mask 有什么用？

如果只希望模型修改图片的一小块，可以在 Watermark Removal API 中提供 smear_url 或 smear_base64。

遮罩图片需要与原图保持相同尺寸。需要处理的位置使用颜色标记，纯黑和纯白区域则不会被修改。

比如 Logo 紧贴商品边缘，或者文字刚好覆盖人物附近时，限制处理区域通常比让模型自由判断整张图片更容易控制。

Kaze AI 还有 Image Expand API

Kaze AI 的图像 API 不只有 Watermark Removal。

Image Expand API 可以对图片进行 outpainting，通过 paste_position 指定上、左、下、右分别扩展多少像素，再由模型生成新增区域。

提交接口：

POST /api/ext/v1/submit_expansion

例如四周各增加 100 像素：

{
  "image_url": "https://example.com/image.png",
  "paste_position": [100, 100, 100, 100]
}

Image Expand 同样是异步任务，提交后通过 task_id 查询结果。

Kaze AI API 怎么收费？

截至 2026 年 9 月，Watermark Removal API 和 Image Expand API 的官方标准价格都是每张图片 0.10 美元。

视频接口则按照输出时长计费。当前 Starter API 中，Seedance 2.0 的标准价从约 0.14 美元/秒起，Seedance 2.5 为约 0.22 美元/秒，不同模型和套餐价格可能变化。

如果每天通过 Watermark Removal API 处理 100 张图片，按当前标准价计算，基础调用成本约为 10 美元。

大批量使用前最好重新查看 API 页面，因为模型价格和企业折扣都可能调整。

网页 credits 和 API Balance 是同一笔钱吗？

不是。

Kaze AI 网页端采用 credits 和订阅体系，用于网页里的图片和视频生成；开发者接口则使用独立的 API Balance。

购买网页端 credits，不会自动给 API Balance 增加余额。

如果只是测试图片和视频效果，先从网页端开始会更省事。确定结果能够满足实际需求，而且确实需要程序自动处理以后，再创建 API Key 和充值 API Balance。

网页套餐：https://kaze.ai/pricing

Kaze AI 适合什么样的工作？

Kaze AI 更适合需要频繁制作和修改视觉内容，但又不要求每个像素都手工控制的场景。

例如社交媒体配图、电商素材、博客插图、广告草稿、产品视觉、短视频素材，以及需要快速验证想法的设计工作。

如果一张图片需要严格的品牌字体、复杂版式、精确蒙版或者专业摄影后期，AI 生成结果更适合作为中间素材，而不是直接代替 Photoshop 这一类专业编辑工具。

上传客户图片和内部素材前要看数据规则

Kaze AI 属于在线服务，上传的图片、提示词和生成结果需要进入其处理系统。

截至 2026 年 9 月，其服务条款写明，注册用户创建的私有内容会保存，直到用户主动删除相关内容或注销账户。

条款还说明，Kaze AI 会使用第三方 AI 技术合作方来提供和改进服务，用户提交的 prompt、参考图片以及对应输出可能会与这些合作方共享。

用户内容还授予 Kaze AI 一定范围的许可，用于运行服务、内容分类和审核，以及在其条款约定范围内改进和训练 AI 模型。

所以客户资料、身份证件、合同、内部设计稿和未公开产品图，不适合只因为操作方便就直接上传。企业或者团队有明确的数据边界时，应先核对当前服务条款，或者改用能够自己控制文件流向的方案。

AI 修改图片不会改变原来的版权

一张图片经过 AI 修改以后，原来的版权和授权条件不会自动消失。

自己拍摄的照片、自己制作的设计、已经取得授权的商业素材，通常更适合拿来继续修改。

如果素材来自图库、摄影师、设计师、品牌方或者其他版权所有者，仍然需要按照原来的授权范围使用。

Kaze AI 常见问题

Kaze AI 网页 credits 和 API Balance 通用吗？

不通用。网页端使用 credits，开发者 API 使用独立的 API Balance。给网页账户购买 credits 不会自动增加 API 余额。

Kaze AI 去水印能恢复水印下面真正的原图吗？

不能这样理解。AI 会根据周围画面生成新的替代内容，而不是恢复已经被覆盖的原始像素。复杂纹理、人脸和商品细节仍然需要人工检查。

Kaze AI Image Expander 有 API 吗？

有。Image Expand API 可以通过图片 URL 或 Base64 提交图片，并使用 paste_position 指定四个方向需要扩展的像素。当前官方标准价格为每张图片 0.10 美元。

Kaze AI 的视频模型是自己开发的吗？

不能全部这样理解。Kaze AI 是模型和创作工具的平台入口，当前视频侧可以使用 Seedance、MiniMax 等不同模型，具体模型列表会随平台更新。

敏感图片适合上传 Kaze AI 吗？

Kaze AI 是在线服务。当前条款允许其在提供和改进服务时与第三方 AI 技术合作方处理部分输入和输出，而且注册用户的私有内容会保存到主动删除或注销账户为止。涉及客户资料、内部素材、证件或其他敏感图片时，应该先确认当前条款是否符合自己的数据要求。
