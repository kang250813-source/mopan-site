Wallpaper-generator：个性化壁纸生成器，支持多平台的一站式智能图片聚合与壁纸自动更换工具

发布于 2025-11-18

✨ 个性化聚合式壁纸生成平台

Wallpaper-generator是一款将图片聚合、AI生成与智能壁纸管理结合的平台，适用于 Windows 与 Linux。用户可以在一个界面中完成生成、挑选、管理与自动更换壁纸的全部流程，让桌面保持灵感更新。

平台以“心之所向，个性聚合”为理念，通过异步架构与多线程处理，让壁纸生成速度保持高效流畅。无论是想要简洁风、渐变色、AI绘画图，还是来自 Pixiv 等来源的内容，都能自由组合。

✨ 功能亮点

🖼 高速生成与更多图源

  • 异步前后端架构，多线程加速生成。
  • 支持 AI 绘图、Pixiv、福瑞等丰富类型，通过插件市场自由扩展。
  • 自研 APICORE 规范，让自定义生成流程更轻松。

🎨 更灵活的个性化选择

  • 可以手动制作渐变色壁纸。
  • 可设定时间间隔，自动轮播壁纸。
  • 每日一图自动推荐，让桌面始终保持新鲜感。

💻 系统兼容性

  • 适用于 Windows 10 / Windows 11 等 X64 系统。
  • 需安装 .NET Framework（可按指引下载）。

✨ 使用方式概览

📌 安装步骤

  • 前往 Releases 页面下载最新安装包(下载地址：Wallpaper-generator：个性化壁纸生成器)
  • 双击启动安装程序，根据引导完成设置
  • 启动软件即可进入生成界面

🎯 壁纸生成流程

  • 在顶部导航栏选择图片类型
  • 若无喜欢的类型，可前往“图片源市场”添加新图源
  • 通过“设置”选择壁纸保存路径
  • 调整生成数量与参数，点击生成
  • 可将生成的图片设为壁纸、在系统查看器中打开或在资源管理器中定位
  • 可使用页面指示器浏览全部图片

🔄 自动更换壁纸

  • 在欢迎页面启用“自动更换壁纸托盘程序”
  • 设置更换间隔与开机自启
  • 系统托盘可随时手动更换当前壁纸
  • 设置完成后应用即可

✨ 代码部署

5.1.0 版本主要基于 Python 运行：

  • 需 Python ≥ 3.10 环境
  • 新建虚拟环境：python -m venv wpg_next
  • 安装依赖：pip install -r requirements.txt
  • 启动主程序：python ./MainWindow.py
