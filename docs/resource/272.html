SearchGal：Galgame资源聚合搜索工具｜多源实时检索、免登录标签、开源可自建

发布于 2025-11-30

SearchGal简介

SearchGal 是一个专为 Galgame 玩家打造的资源聚合搜索工具，整合 32+ 主流平台与补丁站点信息，通过实时检索、多线程加速与智能标签，让玩家可以在一个入口中完成资源搜索、平台筛选与信息获取。页面同时适配电脑与移动端，查找资源的体验更加轻松流畅。

在 SearchGal 中，你可以：

  • 按中文游戏名或关键词快速搜索

  • 一眼看到各平台的访问特性（免登录、需代理、需特殊条件）

  • 在 PC 端查看游戏封面、简介、标签与人物信息

  • 在移动端享受同样顺畅的搜索体验

项目亮点

  • 多端适配：PC 与移动端均可流畅使用；PC 端可显示封面、简介、标签、人物信息（国内网络环境下加载速度视线路而定）。
  • 多源聚合：实时整合 32+ 主流 Gal 资源平台与 2+ 补丁站，结果覆盖更广。
  • 快速响应：多线程加速检索，减少等待。
  • 标签提示：自动标注站点特性：免登录、需代理、需登录或其他特殊条件，选择更省心。
  • 开源可自建：便于二次开发与私有化部署，社区参与度高。

核心功能

  • 多源实时检索：一次查询拉取多平台结果，跨站比对更高效。
  • 平台特性标注：用颜色/标签区分访问条件，直观判断可达性。
  • 结果展示优化：封面、简介、标签与人物信息集中呈现，便于筛选。
  • 下载指引：对易出现的验证与限速场景给出通用工具建议。

已收录平台与标签说明

  • 🟢 免登录直链：可直接访问与下载，更适合新手与快速获取。
  • ⚪ 需登录/特殊条件：需满足注册或站点规则后访问。
  • 🟡 需代理访问：受地区网络限制，可在合规前提下配置网络代理。

注：站点状态具备时效性，若发现条目失效或标注不准确，可在项目仓库提交 Issue 协助修正。

使用指南

精准搜索

  • 中文名检索命中率更高。
  • 缩短为核心词可减少噪音示例：Senren＊Banka → 千恋万花 → 千恋。

结果筛选

  • 优先尝试绿色标签平台。
  • 黄标平台需合规代理，白标平台需完成登录或其他条件后再试。

下载提示

  • 推荐使用 IDM/FDM 等工具提速。
  • 遇到 Cloudflare 验证可耐心等待完成后再进行下载操作。

部署与运行

Linux（建议 Nginx 反代 Gunicorn）

git clone https://github.com/Moe-Sakura/SearchGal.git
cd SearchGal && screen -S sg
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
nice -n 19 gunicorn -c gunicorn_config.py --preload app:app

Windows

git clone https://github.com/Moe-Sakura/SearchGal.git
cd SearchGal && python -m venv venv && venv\Scripts\activate
pip install -r requirements.txt
python app.py
