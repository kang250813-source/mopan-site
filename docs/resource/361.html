AITradingSimulator：基于大语言模型的加密货币AI交易模拟器｜自定义策略 · 实时行情 · 专业绩效分析

发布于 2025-10-28

🚀 AITradingSimulator概览

AITradingSimulator是一款由大语言模型驱动的智能交易决策系统，用户可自定义交易策略、实时查看市场数据，并通过专业级绩效分析了解策略表现。系统提供交互式交易大屏，支持多模型对比与可视化分析，全面提升量化交易效率与学习体验。AITradingSimulator不仅是交易模拟工具，更是AI驱动的量化研究与教学平台。它让用户以可视化方式理解AI交易逻辑，适用于个人投资者、量化研究员及高校教学场景。

官网地址：https://trade.easy2ai.com
开源项目：https://github.com/LargeCupPanda/AITradingSimulator

核心功能

🧠 AI智能交易系统

  • 个性化策略：可为每个模型自定义Prompt，形成独特交易风格。
  • 智能决策引擎：基于15+技术指标（SMA、EMA、MACD、RSI、布林带等）自动分析行情。
  • 决策透明化：详细展示AI思考逻辑与推理过程。
  • 自动交易循环：每3分钟执行一次交易决策，支持1–20倍杠杆和做多/做空操作。

📊 实时交易与绩效分析

  • 实时展示BTC、ETH、SOL、BNB、DOGE、XRP等主流币种价格。
  • ECharts可视化收益曲线、排行榜与回测报告。
  • 支持夏普比率、Sortino比率、Calmar比率等专业绩效指标。
  • 提供风险管理、仓位监控、止盈止损策略。

🔐 用户系统与安全设计

  • 完整的注册/登录体系与Session管理。
  • 支持Linux DO OAuth登录与数据隔离，保障隐私与模型独立性。
  • 路由级权限控制确保账户与交易安全。

🌙 专业用户体验

  • Bloomberg/TradingView级别UI，支持暗黑模式与响应式设计。
  • 5秒自动刷新实时行情，数据流畅不卡顿。
  • Docker一键部署，支持OpenAI、DeepSeek、Claude、Kimi等接口。

应用场景

场景 功能价值
AI交易策略测试 测试不同AI模型（GPT-4、Claude、DeepSeek）交易能力，验证策略有效性
量化交易学习 学习技术指标、风险管理与绩效回测方法
多模型对比 创建不同策略模型，通过排行榜分析最优交易逻辑
教育展示 可视化AI在金融交易领域的应用流程与数据表现

技术栈

后端：Python 3.9+ / Flask 3.0
前端：原生 JavaScript / ECharts 5.4.3
数据库：SQLite
AI接口：OpenAI兼容（支持DeepSeek、Claude、Kimi）
部署方式：Docker / Gunicorn
实时通信：WebSocket (Flask-SocketIO)

特色亮点

  • 全链路AI交易决策与实时可视化
  • 用户可定义交易风格与风险偏好
  • 多模型排行榜与月度收益分析
  • 兼容多家AI接口与跨平台部署
