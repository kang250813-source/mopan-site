Lively Wallpaper：免费开源的桌面动态壁纸与屏保工具（多屏/超宽支持）

发布于 2025-09-25

Lively Wallpaper概览

Lively Wallpaper 是一款免费开源（FOSS）的桌面定制工具，可在 Windows 上设置动态壁纸与屏保，支持多显示器与超宽屏。采用 WinUI 3 与 Windows App SDK，界面现代，拖拽即可应用网页、视频、GIF 或应用为壁纸。项目由社区维护，无付费墙。

官方与开源

  • 官网：rocksdanister.com/lively
  • GitHub：github.com/rocksdanister/lively

主要特性

  • 开源与社区驱动：完全开源，面向社区开发与改进。
  • 现代体验：贴合 Windows 11 设计语言，界面友好。
  • 多屏与超宽支持：适配超宽屏与多显示器场景。
  • 高性能与智能暂停：全屏运行游戏或应用时自动暂停壁纸，资源占用≈0%；可基于前台应用设置播放规则；支持电池电量模式与远程桌面时自动暂停。
  • 硬件加速与播放器内核：集成 mpv/VLC，支持自定义视频滤镜与硬件加速解码。
  • 便捷上手：拖拽媒体或网页到 Lively 即可设置为壁纸。
  • 屏保支持：任何壁纸均可用作 Windows 屏保，多显示器可用。
  • 自动化与脚本：命令行参数控制，支持与 Python、AutoHotKey 等脚本软件集成。
  • 开发者能力：提供 Lively API，可获取硬件读数、音频频谱、音乐信息等，方便构建交互式壁纸、音乐可视化与小组件。
  • 机器学习拓展：可利用推理能力制作动态、数据驱动的壁纸。
  • 网页渲染：内置基于 Chromium 的轻量网页渲染器；支持 Shadertoy 链接作为壁纸。
  • 原生高效：原生 Windows 应用，体积精简、运行高效。
  • 版权与声明：与 Unity、Godot、Shadertoy 无官方隶属关系。

创作与工具

  • 音乐可视化与小组件：内置丰富的壁纸开发工具，可快速制作音频可视化、时钟、系统信息等组件。
  • API 扩展：通过硬件/音频接口实现互动响应，如随音乐节奏变化的粒子特效。
  • 自动化工作流：命令行 + AutoHotKey 组装场景切换、专注模式、演示模式等自动化流程。

性能与使用建议

  • 全屏游戏或应用触发自动暂停，降低 CPU/GPU 占用。
  • 可为特定前台应用设置播放/暂停规则，减少干扰与能耗。
  • 笔记本在电池供电时可自动暂停，延长续航。
  • 远程桌面会自动暂停，避免资源浪费。

适合人群

  • 追求个性化与沉浸感的桌面用户。
  • 直播、演示与内容创作者，需要可视化舞台与动态背景。
  • 开发者与设计师，想利用 API/脚本构建交互壁纸与数据可视化。
