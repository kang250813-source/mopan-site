Agili 的 Hacker Podcast：AI 驱动的 Hacker News 中文播客，每日同步全球科技热点

发布于 2025-12-20

🔍 什么是 Agili 的 Hacker Podcast？

Agili 的 Hacker Podcast 是一个由 AI 驱动的中文播客项目，每天从 Hacker News 自动抓取热门文章，通过 AI 生成精炼的中文摘要，再借助 TTS 技术转换为播音内容。无论你是忙碌的开发者、技术极客，还是对前沿趋势敏感的内容创作者，都能从中快速掌握每日技术圈热点。

Agili 的 Hacker Podcast访问地址：

📺 网站预览：hacker-podcast.agi.li

🤖GitHub地址：miantiao-me/hacker-podcast

📡 RSS 订阅：hacker-podcast.agi.li/rss.xml

🚀 功能亮点

  • 🤖 每日自动抓取 Hacker News 热门内容
  • 🧠 利用 OpenAI API 智能生成文章与评论摘要
  • 🎙️ 通过中文 TTS 技术生成自然语音播报
  • 📱 支持网页收听与播客 App 订阅
  • 🗂️ 提供完整文字稿与音频归档
  • 🔄 无需人工干预，自动更新内容

🛠 技术架构

  • 内容生成：基于 OpenAI API 提取文章核心信息与热门评论
  • 前端开发：采用 Next.js + Tailwind CSS + shadcn-ui 组件库
  • 部署运行：由 Cloudflare Workers 支持，实现高效边缘计算
  • 播报转换：使用 TTS 技术生成流畅中文语音
  • 数据存储与分发：音频文件与文本内容存储于 Cloudflare R2 与 KV，支持 RSS 和网页访问

🔁 工作流程概览

  1. 每天定时抓取 Hacker News 热门话题
  2. AI 自动撰写中文摘要与播报文稿
  3. 使用 TTS 语音合成转换为可听播客
  4. 发布至网页和 RSS 订阅渠道，自动推送更新

🎧 适合谁听？

  • 想高效获取科技新闻的开发者与产品人
  • 通勤、健身时想“听”点技术内容的知识型用户
  • 对 AI 播客自动化有兴趣的内容创作者
  • 喜欢 Hacker News 却时间有限的中文用户群体
