Nitter：一个注重隐私与性能的Twitter无广告、无追踪前端开源替代方案，Twitter开源镜像

发布于 2025-12-05

什么是 Nitter？

Nitter 是一个免费的开源 Twitter 替代前端，专为提升隐私体验和浏览速度而设计。它不依赖 JavaScript、不显示广告，所有请求通过服务端中转，有效避免 Twitter 对用户的 IP 或浏览器指纹进行跟踪。受 Invidious 项目启发，Nitter 提供了一种无痕浏览 Twitter 的解决方案，无需 Twitter 开发者账号即可使用非官方 API 获取内容。特别适合用于匿名浏览、RSS 订阅、聚合展示等场景。

Nitter 的核心优势

  • 隐私优先：不与 Twitter 客户端直接通信，避免被追踪
  • 无广告干扰：页面纯净，无任何 JavaScript 或广告脚本
  • 无需开发者账号：调用 Twitter 非官方 API，简单直接
  • 轻量快速：以 @nim_lang 为例，页面大小仅 60KB，相较原生 Twitter 页面（784KB）更节省流量
  • RSS 支持：可轻松订阅用户推文、关键词更新等内容
  • 响应式设计：支持移动设备流畅访问
  • 开源透明：采用 AGPLv3 授权，禁止建立专有闭源实例
