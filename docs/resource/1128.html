全能计算与换算神器：极巧立算 JicoCalc（Android/iOS 免费、多语言、84 款工具）

发布于 2025-08-10

极巧立算 JicoCalc概述

极巧立算（JicoCalc）是一款免费的多功能计算器 App，集成 84 种计算与换算工具，覆盖日常、学习、职场与开发场景。支持简体/繁体中文、英语、日语、韩语、西班牙语、俄语等多语言，iOS 与 Android 均可使用。

极巧立算 JicoCalc核心亮点

  • 计算全面：基础计算器 + 科学计算器，结果精准。
  • 单位换算强：内置 41 个单位类别，支持长按拖动排序、基准单位一键切换，小数位可设定。
  • 金融能力足：汇率换算支持 168 种货币，可离线；房贷、贷款、利息、销售税、小费、折扣与单价计算一步到位。
  • 效率工具多：日期/时间差、年龄、人民币大写、公历/农历、中文转拼音、简繁转换、摩斯电码等。
  • 数学与学习：随机数、最大公约数/最小公倍数、质数检验、分数与平均数计算。
  • 开发者加分项：进制转换、CIDR、字符串哈希、网页源码查看、Whois、Ping、SSL 查询、HTTP 状态码、Base64、Hex、正则表达式库等。
  • 体验细节：本地收藏、分类与收藏排序、历史记录、智能搜索、深浅色主题、iPhone/iPad 适配，无需登录。

极巧立算 JicoCalc功能一览

计算与换算

  • 基础/科学计算：满足学习与专业场景。
  • 单位换算：长度、面积、体积、压强、时间、温度、速度、质量、角度、数据存储、能量、功率、力/力矩、密度、摩尔质量、物质的量、照度/亮度/光度、油耗、磁感强度、电学相关（电导/电导率/电感/电荷/电流/电容/电势/电阻）、加速度、体积流量/标准体积流量/质量流量/摩尔流量、运动/动力粘度、功率密度、热阻、频率、放射性。

效率与生活

  • 亲戚关系计算器：收录 76,602 条关系，支持称谓查询、互查与合称。
  • 日期/时间计算、年龄计算（含公历/农历、星座、属相、下次生日推算）。
  • 人民币大写、公历/农历互转、中文转拼音、简繁体转换、摩斯电码。
  • 健康工具：BMI、体脂率、宏量营养素（卡路里、BMR、TDEE、三大营养素配比）。
  • 实用参考：女性标准身材计算、十二时辰对照表。

金融财务

  • 汇率换算（168 货币，排序/基准切换/侧滑删除，离线可用）。
  • 房贷/贷款计算、年终奖个税、利息（单利/复利）、单价/销售税/小费/折扣等购物与结算场景。

数学与学习

  • 随机数生成（唯一与排序）
  • 质数检验与质因数分解、分数简化与小数转分数、多种平均数。

开发者工具

  • 进制转换、CIDR 子网、MD5/SHA 系列哈希
  • 网页源码查看、Whois、Ping、SSL 证书详情
  • 随机端口、硬盘整数 GB 分区
  • HTTP 状态码速查、Base64、字符串 Hex、正则表达式大全。
