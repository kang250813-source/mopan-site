DuckStation：全平台高速PS1模拟器，打造极致游戏体验

DuckStation是一款专为Sony PlayStation（PS1）打造的高性能模拟器，致力于在保持精准度的同时，兼顾运行速度与设备适配性。无论你是怀旧玩家，还是游戏开发者，这款工具都能带来几乎原汁原味的主机体验，支持在Windows、Linux和macOS等主流操作系统运行。

✅ 高度兼容，几乎覆盖全部PS1游戏

DuckStation的默认设置就已能运行绝大多数可玩的PS1游戏，尽可能减少用户手动调整的门槛。它摒弃了大量“外挂式”的Hack选项，专注在准确模拟与长期可维护性上，为用户提供更稳定的游戏体验。

🌐 支持多种架构与系统平台

  • 支持的处理器架构：x86_64、ARMv7、AArch64、RISC-V（RV64）
  • 系统兼容性：Windows 10/11（x64/ARM64）、Linux（AppImage）、macOS 11+（Universal Build）

🔧 功能强大，满足进阶玩家需求

  • 硬件渲染支持：Direct3D 11/12、OpenGL、Vulkan、Metal
  • 高画质增强：纹理滤镜、图像放大、PGXP几何校正、深度模拟
  • 图像美化与滤镜：边框遮罩、后处理特效（GLSL、ReShade FX、Slang）
  • 全功能UI系统：Qt前端 + 类TV大屏UI（ImGui）
  • 存档/金手指/状态恢复：支持实时存档、自动金手指加载、回滚/快进等功能
  • 光枪与特殊手柄支持：支持GunCon、Justifier、NeGcon等稀有输入设备
  • 支持格式丰富：CD、bin/cue、CHD、PBP等常见镜像格式
  • 多碟共享存档、预载光盘到内存、主机BIOS跳过
  • RetroAchievements成就系统 + Discord Rich Presence展示状态
  • 支持视频录制、自由视角、并行端口扩展、调试模式等开发者功能

🎮 运行需求低，老电脑也能带得动

  • 最低CPU：支持x86-64/AArch32/AArch64/RV64的处理器
  • 最低GPU：兼容OpenGL 3.1、D3D 11、Vulkan 1.0等现代图形API
  • 手柄支持：兼容SDL、XInput、DInput，推荐Xbox或PlayStation系列手柄

📦 安装与获取方式

GitHub发布页（持续更新）：DuckStation

📌 使用提示

DuckStation不会捆绑任何BIOS镜像，用户需自行从自己的主机中导出PS1或PS2 BIOS（如使用Caetla工具），以实现完整模拟体验。
