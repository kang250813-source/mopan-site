Claude Code Skills：用 /last30days 找到最近 30 天真正好用的 Prompt

发布于 2026-01-29

别让你的 AI 活在“半年前”：怎么让它自动帮你做功课？

AI 圈有个很头疼的问题：变化太快了，快到离谱。

你有没有过这种经历：在网上搜“最好的 AI 提示词教程”，结果搜出来的文章是半年前写的。你照着试了一遍，发现效果根本不行——因为模型早就更新了好几代，旧套路早就不灵了。

其实，真正好用、热乎的技巧，往往藏在 Reddit 和 X (Twitter) 的评论区里。但我们毕竟是肉体凡胎，不可能每天花几个小时去人肉翻帖，那样太累了。

今天给大家安利一个开源小工具 /last30days。别被它的英文名字吓到，它就是专门来解决这个问题的：能在几秒钟内，把“过去 30 天大家公认好用的东西”喂到你嘴边。

它能帮你干什么？（说人话版）

简单来说，它就是你的“全自动情报员”。作为一个运行在 Claude Code 里的插件（你可以理解为给 AI 装了个外挂），它只做三件事：

  • 聚合信息： 自动去 Reddit 和 X 上，汇总最近 30 天关于某个话题的高互动讨论
  • 过滤水贴： 剔除掉那些发广告的、没营养的，只保留有点赞、有干货的内容。
  • 提炼总结： 把这些碎片化的经验，整理成一段你可以直接复制的 Prompt（提示词）或者结论。

真实场景：这玩意儿怎么用最爽？

1. 偷懒写出“版本最强”的提示词

比如你想写个 Python 脚本，但不知道现在的 Claude 3.7 最吃哪一套指令。你可以直接问它：
“最近 30 天，大神们都是怎么写 Claude 代码提示词的？”
它会分析社区里的最佳实践，直接给你生成一个当前版本最好用的模板。

2. 做内容选题不发愁（自媒体必备）

不用拍脑袋猜大家喜欢看什么。直接查：
“最近 30 天，大家对 Notion 新功能的槽点和夸点分别是什么？”
拿到的都是真实用户的反馈，基于这些“大实话”写的文章，阅读量通常都不会差。

3. 避坑省钱指南

想买个新出的 AI 硬件？千万别看软文。用这个工具搜一下最近一个月的真实讨论，一眼就能看到用户反馈的 bug 和真实续航，帮你省下冤枉钱。

3 分钟上手指南（小白不慌）

👀 友情提示：
看到下面的黑色代码框别害怕！你不需要懂编程，只需要把这些代码“复制 -> 粘贴”到你的 Claude Code 界面里按回车就行，跟发微信一样简单。

前提： 你需要已经安装了 Claude Code（这是一个在电脑终端里运行的工具），并且有一个 OpenAI 的 Key（就是一串密钥，用来帮你搜索总结）。

第一步：安装插件（把工具下回来）

复制下面这行代码，回车：

git clone https://github.com/mvanhorn/last30days-skill.git ~/.claude/skills/last30days

第二步：配置 Key（填入你的密码）

它需要调用 LLM 来帮你读帖子，所以需要配置一下密钥。依次复制下面这几行：

mkdir -p ~/.config/last30days
# 注意：把 sk-… 换成你自己的 OpenAI Key
echo “OPENAI_API_KEY=sk-你的密钥在这里” > ~/.config/last30days/.env

第三步：直接开问！

配置好后，直接在 Claude Code 里输入 /last30days 加上你想问的问题。例如：

/last30days prompting techniques for ChatGPT
💡 老鸟建议：
这个工具不是用来“代替思考”的，而是用来“节省时间”的。把它当成一个 24 小时无休的调研助理，帮你把海量的信息过滤一遍，最后做决策的还是你。

🔗 项目与官方文档

  • GitHub 项目地址：mvanhorn/last30days-skill
  • 注意事项：
    这是一个开源工具，完全免费。它在帮你做总结的时候，会调用一点点 API 额度（Token），不过费用很低，大家放心用。
