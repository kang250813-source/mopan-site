Arboris-Novel：AI写作伙伴，让小说创作更轻松

发布于 2025-10-24

Arboris-Novel概述

Arboris-Novel 是一个为小说创作者打造的智能写作空间。它并不会代替你写作，而是像一个懂你的创作搭档，在你卡壳时帮你理清思路、记录细节、激发灵感。无论是故事设定混乱、人物细节遗忘，还是剧情结构难以串联，Arboris 都能帮你把混乱的灵感整理成清晰的故事主线。

🔗 在线体验地址：https://arboris.aozhiai.com
📂 开源地址：GitHub – arboris-novel

截图界面

适用场景

  • 连载到中后期，设定细节多、容易前后矛盾。
  • 手里只有零散片段，需要梳理为主线。
  • 想保持更新节奏，临时需要草稿或接续写作。
  • 希望比较多种写法，逐步贴近个人文风。

核心能力

设定管理与检索

角色、地点、派系、规则等要素集中记录，可随时查阅，减少“人设崩塌”“世界观冲突”。

灵感到主线的梳理

将零散片段与想法交给 AI 对话，自动提炼出一条清晰的故事线，形成从开端到结局的纲要。

不会疲惫的写作搭档

在状态不佳时生成草稿，再以个人风格打磨；或由你写开头，让 AI 试着续写，激发新思路。

多版本对比与风格“驯化”

同一段落可生成多版文本，对比挑选优点并合并，逐步让系统更懂你的笔触与节奏。

产品理念与开源

Arboris-Novel 的定位是“写作伙伴”而非“自动生成器”。它强调对你作品世界与角色的持续理解，帮助你稳步推进故事。项目开源，工具的改进由创作者共同参与，利于长期可用与个性化扩展。

使用方式

  • 访问在线体验，创建作品并录入核心设定。
  • 通过对话整理灵感，生成主线大纲与章节骨架。
  • 在关键桥段使用多版本比对功能，逐步定稿。
  • 需要自部署或二次开发时查看 GitHub 仓库与文档。
