Open Scouts：开源 AI 网络监控平台，自动搜索全网并实时邮件提醒

发布于 2025-12-15

智能网页侦查，从此无需人工刷新

Open Scouts 是一个基于 AI 的网页监控平台，允许用户自定义侦查器（Scouts），定时搜索网页内容、实时追踪更新，并在发现目标内容时自动发送邮件提醒。无论你是在寻找本地新餐厅、跟踪 AI 新闻，还是监测某个关键词的网页出现频率，Open Scouts 都能全天候、自动化地完成任务。

用户只需定义一个查询目标（如“监控最新的印度餐厅”或“跟踪AI相关新闻”），系统会自动生成合适的搜索逻辑，并按照设定的频率运行，从每分钟、每天到每周都可灵活配置。

技术架构：强大、现代、可扩展

平台由一整套现代前后端技术构建而成：

  • 前端框架：Next.js 16 + React 19 + Tailwind CSS 4，实现实时更新与快速加载
  • 后端支持：Supabase 提供数据库、认证与边缘函数；支持 pg_cron 定时任务和 pgvector 向量搜索
  • AI能力：基于 OpenAI GPT-4，结合语义嵌入与函数调用，实现智能抓取与摘要
  • 网页抓取：Firecrawl SDK 提供灵活的网页搜索与内容抽取能力
  • 通知机制：集成 Resend，支持高质量 HTML 邮件推送与自定义域名验证

无缝部署，快速上手

部署过程简单清晰，支持 bun、npm、pnpm 三种包管理器，只需克隆代码、配置 API 密钥、运行初始化脚本，即可完成数据库建表、扩展启用、边缘函数部署与通知服务配置。

还支持：

  • Supabase Auth 登录（支持邮箱密码与 Google OAuth）
  • 伙伴集成模式（为每位用户生成独立 Firecrawl API Key）
  • 实时数据隔离与安全保障（RLS 行级权限控制）

Scout系统工作机制

  • 用户无需登录即可浏览公开主页
  • 创建侦查器时会提示用户登录或注册
  • 每个用户只管理自己创建的侦查器，数据完全隔离
  • 每次执行都会生成一句话语义摘要，并存储为可搜索向量
  • 支持“立即执行”按钮，方便手动测试或触发
  • 邮件推送结果格式美观，可通过“发送测试邮件”功能检查配置是否成功

适合哪些用户？

  • 内容创作者：实时获取感兴趣话题的最新网页动态
  • 媒体分析师：自动追踪关键词相关报道与资讯变化
  • 商业从业者：监控市场变化、竞品页面更新、促销活动上线
  • 技术爱好者：构建自己的自动化网页信息捕捉系统
