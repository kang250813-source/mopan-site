TextGO：开源跨平台的智能文本处理助手

TextGO 是一款功能强大、界面简洁的跨平台文本处理工具，能够智能识别选中的文本类型，并根据用户自定义规则执行自动化操作。无论你是开发者、内容创作者，还是日常办公用户，都可以通过 TextGO 提升文本处理效率，实现个性化操作体验。

下载地址：网盘

项目开源地址：👉 https://github.com/C5H12O5/TextGO

核心亮点

🖱️ 多种触发方式

TextGO 支持通过快捷键、鼠标双击或划词等方式触发操作，用户可根据不同使用场景配置独立规则。

⚡ 灵活执行模式

提供“立即执行”与“工具栏交互”两种模式，适合习惯快速操作或需要选择性处理的不同用户。

🧠 智能识别与处理

内置丰富的文本类型和处理动作（如翻译、搜索、格式化等），支持通过正则表达式、脚本、机器学习模型或本地 AI 扩展识别能力。

🎨 个性化图标支持

用户可从内置图标库选择，也可上传自定义 SVG 图标，打造专属的浮动工具栏，提升交互美感与效率。

安装与使用

  1. 前往 GitHub Releases 页面，下载对应系统版本的安装包。
  2. 安装完成后，TextGO 即可在系统后台常驻运行。

针对 macOS 用户常见问题，也提供了解决方案：

  • 如果提示“App 已损坏”，可在终端执行以下命令： 
    sudo xattr -r -d com.apple.quarantine /Applications/TextGO.app
  • 如果提示“Apple 无法检查 App 是否包含恶意软件”，可在“系统设置 > 隐私与安全性”中点击“仍要打开”。

应用场景无限拓展

  • 快速调用翻译、搜索、提取链接、生成摘要等常用动作
  • 配合 ChatGPT 本地插件执行文本总结或重写
  • 针对开发者：高亮代码片段、转换格式、生成 Markdown
  • 办公场景：标准化文档格式、批量处理内容模板

TextGO 是 PopClip、SnipDo 等工具的开源平替方案，且具备更高的自由度与扩展性，让你的文本处理工作更加高效、智能、有趣。
