LuoGen-agent：一键生成爆款视频的全自动AI数字人口播工具

发布于 2025-10-06

LuoGen-agent介绍

LuoGen-agent 是一款面向内容创作者、短视频运营者和品牌团队的全自动视频生成工具。用户只需输入一个参考文案，系统便能完成从文案提取、仿写、声音合成、数字人口播、字幕生成、BGM搭配到视频封面制作的全流程操作，最终可一键发布到抖音、B站等主流平台。

本工具通过自动化流程，帮助用户快速生成高质量的数字人口播视频并发布至多平台。核心功能包括：

  • 📝 智能文案处理：自动提取对标文案 + 智能仿写优化
  • 🎤 声音克隆：基于 Whisper 和 CosyVoice 实现高保真语音合成
  • 👥 数字人生成：集成 HeyGem 实现自然口播效果
  • 🎬 全流程视频制作：字幕/BGM/标题/封面自动生成 + 多平台发布

🌟 核心功能

功能模块 技术实现
语音克隆 Whisper（语音识别） + CosyVoice（语音合成）
数字人口播 HeyGem 数字人引擎
视频后期 FFmpeg（合成） + 动态字幕
多平台发布 平台 API 集成（抖音/B站等）
