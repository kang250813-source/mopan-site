Status Trio：受 iPhone Duo 启发的 Mac 菜单栏三合一状态图标

发布于 2026-10-19

Mac 上的软件装多以后，菜单栏很容易被各种图标塞满。特别是带刘海的 MacBook，右上角能留给状态图标的位置本来就不多。

Status Trio 是一款开源 macOS 菜单栏工具，把原本分开的 Wi-Fi、电池和音量整合进一个状态图标。它可以放在菜单栏，也可以放进 Dock，或者两个位置同时显示。

Status Trio 的设计灵感来自 iPhone Duo：后者把 Wi-Fi、蜂窝网络和电池整合进一个组合状态图标，到了 Mac 上，Status Trio 用音量替代了蜂窝网络。项目为独立作品，与 Apple 没有隶属关系。

它和 Bartender、Ice 这类菜单栏整理工具不太一样，也不是 iStat Menus 这种系统性能监控软件。Status Trio 主要就是把几个每天都会看的系统状态放到一个位置，减少菜单栏占用。

Status Trio 是什么？

Status Trio 的组合图标分成三个区域：上方显示电池，中间显示 Wi-Fi、以太网或蓝牙音频设备，下方用圆点或弧线表示音量。平时看一个图标就能知道大概状态，需要更多信息时再点开弹出面板。

项目源码和开发进度可以在 Status Trio GitHub 查看，官方展示页面 也提供了不同状态下的图标效果。

三合一状态图标怎么看？

电池

图标顶部负责显示电池状态，可以看到剩余电量、正在充电、接通电源但没有充电、低电量以及 Low Power Mode 等状态。

打开电池详情后，还能查看适配器功率、电压、电流和电池循环次数，并直接开关 Low Power Mode。第一次使用这项控制时，需要在 macOS 的“登录项与扩展”中批准相应后台辅助程序。

电池圆环还可以自定义“满格”阈值，在 50%～100% 之间选择一个数值。对于设置了充电上限、平时不会充到 100% 的 Mac，这样看起来会更直观。

Wi-Fi 和网络

图标中间通常显示当前网络状态，包括 Wi-Fi 信号、以太网和热点等。

点开以后可以查看当前网络名称、附近网络和连接详情，也可以选择显示 Mac 当前的局域网 IP 地址。如果经常访问 NAS、Home Assistant、本地开发服务器或其他局域网设备，这个信息比较实用。

Status Trio 还提供 Internet Sharing 的快捷入口，不过这里只是打开 macOS 的“共享”设置页面，并不会直接开启或关闭互联网共享。

需要注意的是，Status Trio 当前不会直接替你加入另一个已保存的 Wi-Fi 网络。选择其他网络时，会交给 macOS 自带的 Wi-Fi 设置继续处理。它也不会为了自动切换网络去读取 Keychain 中保存的 Wi-Fi 密码。

音量和音频输出

图标底部用于表示当前音量，可以选择圆点或弧线样式，并反映静音状态。

打开面板后，可以直接调节音量并查看当前音频输出设备。它还支持通过鼠标滚轮或触控板滚动调整音量，滚动方向也能自己设置。

除了三合一图标，还能做什么？

AirPods 和蓝牙设备

Status Trio 后来的版本已经把 Bluetooth 做得比最初的“三合一图标”更完整。开启 Bluetooth 面板后，可以查看已经配对的设备和当前连接状态。

AirPods 等设备还能显示电池信息，部分情况下包括左右耳以及充电盒的电量。正在通过蓝牙设备播放音频时，也可以让 AirPods、耳机或扬声器自己的图标替换中间的网络图形，同时把音量状态显示成蓝色。

蓝牙面板默认不需要开启，用到时再打开，并在 macOS 第一次询问时授予 Bluetooth 权限即可。

把实时状态图标放进 Dock

如果连一个额外菜单栏图标都不想留，也可以让 Status Trio 只显示在 Dock。它支持只在菜单栏、只在 Dock，以及菜单栏和 Dock 同时显示。

Dock 里的图标不是普通静态 App 图标，而是会跟着电池、网络、音量和蓝牙状态实时变化，还可以跟随系统外观，或者固定使用深色、浅色背景。

这也是 Status Trio 和 DuoBar 比较明显的差异之一。

图标和面板自定义

Status Trio 可以调整图标尺寸、符号比例、电池圆环粗细、状态颜色、音量图形，以及弹出面板里显示哪些项目。电池、网络、蓝牙和音量的排列顺序也能自己改。

界面提供简体中文、繁体中文、英语、日语、韩语、德语、法语、西班牙语、意大利语、葡萄牙语、俄语和阿拉伯语等语言。

Status Trio 最近更新了什么？

Status Trio 最新正式版本为 v1.6.0。项目更新比较快，具体版本可以在 Status Trio Releases 查看。

v1.6.0 主要补充了几个日常比较实用的功能，包括在电池详情中开关 Low Power Mode、自定义电池圆环满格阈值，以及显示 Mac 当前的局域网 IP 地址。

网络部分还增加了 Internet Sharing 快捷入口，不过它只是打开 macOS 的“共享”设置页面，并不会直接修改共享状态。

这一版本也修复了部分 Wi-Fi 信号读数异常和图标对齐问题。如果后续已经出现新版本，这部分以项目 Release Notes 为准。

安装和系统要求

Status Trio 怎么安装？

普通用户不用自己编译，直接从 GitHub Releases 下载最新 DMG，打开后把 Status Trio.app 放进“应用程序”即可。

不过当前公开构建使用的是 ad-hoc 签名，没有 Apple Developer ID 公证，所以第一次运行时，macOS 可能提示无法验证开发者或无法验证应用安全性。

第一次启动前，建议确认 DMG 来自项目官方 GitHub Releases，并在需要时核对项目公布的 SHA-256。打开一次后，可以进入“系统设置 → 隐私与安全性”，使用“仍要打开”进行放行。

项目也提供了删除 quarantine 属性的方式：

xattr -dr com.apple.quarantine "/Applications/Status Trio.app"
open "/Applications/Status Trio.app"

但是不要为了安装 Status Trio 全局关闭 Gatekeeper。后续应用更新使用 Sparkle，并通过项目配置的签名更新源进行验证。

如果是由公司统一管理的 Mac，MDM 或企业安全策略也可能禁止用户手动放行未公证应用。这种情况下应以公司的设备策略为准，不建议绕过管理限制。

macOS 13 能运行吗？

Status Trio 当前最低支持 macOS 13，Apple Silicon 和 Intel Mac 都可以使用，不需要分别下载不同版本。

如果你还在用 macOS Ventura，这里要多留意一点：项目目前已经把 macOS 13 设为最低支持版本，但 Ventura 下的实际运行验证还没有完全做完。

简单来说，macOS 13 已经达到安装要求，但暂时还不能理解成“所有功能都已经在 Ventura 上完整验证过”。如果你的 Mac 还停留在 Ventura，安装前可以顺手看一下最新的 Releases 和 Issues，看看有没有新的兼容性反馈。

隐私、Telemetry 和系统权限

Status Trio 会上传数据吗？

Status Trio 提供可选的使用统计，而且默认是关闭的。新安装会在首次使用时询问要不要开启，旧版本升级后也不会自动打开。只有你自己同意启用，应用才会开始发送统计信息。

开启后，发送的主要是一些基础运行数据，比如随机生成的安装 ID、App 和 macOS 版本、CPU 架构、系统与 App 语言，以及图标现在放在菜单栏、Dock，还是两个位置同时显示。

这部分统计里不包含姓名、邮箱、账号、Wi-Fi 网络名称、蓝牙设备信息、精确位置或硬件唯一标识。

发送频率也不算高，两次成功统计至少间隔 20 小时，正常使用大约一天一次。把使用统计关掉以后，后面就不会再继续发送，不过之前已经收到的数据不会因为关闭开关自动删除。

如果你比较在意隐私，项目的 Privacy & Telemetry 页面 里有更完整的字段和数据保留说明。

为什么需要位置和蓝牙权限？

位置权限主要和 macOS 对 Wi-Fi SSID 等网络信息的权限控制有关。拒绝以后，基础网络状态仍然可以工作，只是部分网络名称或详情可能无法显示。

Bluetooth 权限用于蓝牙设备面板，包括查看已经配对的设备及其连接状态。

Low Power Mode 控制还会用到单独的后台辅助程序，第一次启用时需要在 macOS 中批准。当前版本不会为了自动切换 Wi-Fi 去读取 Keychain 中保存的 Wi-Fi 密码。

目前有哪些限制？

Status Trio 的定位比较清楚：它是状态工具，不是完整系统控制面板。

Wi-Fi 网络切换：可以显示附近网络和当前连接状态，但切换到其他保存网络时，会交给 macOS 系统设置处理。

突破充电上限：如果 macOS 因优化充电或充电上限暂停充电，Status Trio 可以显示状态，但不会通过 SMC 强制继续充电。

蓝牙电量：部分配件电量依赖 macOS 能提供的数据，不代表所有蓝牙设备都一定可以显示完整电量。

多显示器和 Space：带状态颜色的图形在部分 Space 拖拽切换、非活动显示器菜单栏等场景中，可能无法像系统单色模板图标那样及时跟随颜色变化。

项目还单独维护了 Known Limitations 文档，比较在意兼容性的话，安装前可以一起看。

Status Trio vs DuoBar：怎么选？

如果只看设计思路，Status Trio 和 DuoBar 很接近：两者都受到 iPhone Duo 风格组合状态图标的启发，都希望把电池、网络和音量压进一个更紧凑的 Mac 状态图标。

真正影响选择的，主要是 Apple 公证、Wi-Fi 操作、Bluetooth、Dock 以及隐私策略。

更适合 Status Trio 的情况

如果你想要 Dock 实时状态图标，或者更在意 Bluetooth 设备面板、AirPods 电量以及更完整的电池详情，Status Trio 功能覆盖更深。

对经常连接 AirPods、蓝牙耳机，或者希望把网络、电池和设备状态集中到一个小面板里的人，它会更有吸引力。

更适合 DuoBar 的情况

如果更在意正常 Apple 公证安装、不想处理 Gatekeeper 放行，或者明确希望软件没有 Telemetry，DuoBar 当前优势比较明显。

DuoBar v1.3.1 还可以浏览附近 Wi-Fi，并通过公开 CoreWLAN API 加入开放网络和部分个人加密网络。

对于 Mac mini、Mac Studio、iMac 这类没有内置电池的桌面 Mac，DuoBar 的 Adaptive Ring 还能自动反映 CPU、内存或 Thermal Pressure。

和 Bartender、Ice、iStat Menus 有什么区别？

Bartender 和 Ice 主要解决的是菜单栏图标太多的问题，用来隐藏、整理和调用其他 App 的菜单栏项目；iStat Menus 更偏系统监控，用来查看 CPU、GPU、内存、温度、风扇和网络等运行数据。

Status Trio 和 DuoBar 都不是这两类软件的直接替代品。它们更像是在重新设计 macOS 自己的几个常用状态，把网络、电池和音量压缩进一个图标。

如果问题是第三方 App 图标太多，Bartender 或 Ice 更合适；如果想看完整性能数据，iStat Menus 更对路；如果只是觉得 Wi-Fi、电池和音量分别占一个位置有点浪费，Status Trio 和 DuoBar 才是同一类选择。

常见问题

Status Trio 免费吗？

目前 GitHub 提供公开 DMG 和完整源代码，没有发现使用当前核心功能必须购买订阅的要求。项目未来的商业模式仍可能变化，因此不建议把它描述成“永久免费”。

Status Trio 是开源软件吗？

是。项目明确使用 Apache License 2.0，并公开提供 LICENSE 和 NOTICE 文件。

Status Trio 支持 Intel Mac 吗？

支持。当前构建为 Universal，同时支持 Apple Silicon 和 Intel Mac。

什么情况下更适合用 Status Trio？

带刘海的 MacBook 用户最容易感受到它的价值，因为菜单栏空间本来就比较紧张。经常使用 AirPods、蓝牙耳机，或者希望把实时状态放进 Dock 的用户，也能用到 Status Trio 后来增加的 Bluetooth 和 Dock 功能。

如果只是觉得 Wi-Fi、电池和音量分别占一个位置有点浪费，它的三合一设计很直观；现在又补上了 Bluetooth、电池详情、局域网 IP 和 Dock 实时状态，已经不只是单纯换一个菜单栏图标。

目前比较明显的门槛是公开版本尚未经过 Apple 公证，以及 macOS 13 Ventura 仍处于运行验证状态。公司统一管理、要求软件必须经过 Apple notarization 的 Mac，目前也不太适合安装。

能接受这些限制，同时更看重 Bluetooth、AirPods 电量和 Dock 功能，Status Trio 会更合适。如果更重视安装省心、Apple notarization、无 Telemetry，或者希望直接在弹窗中加入部分 Wi-Fi 网络，DuoBar 当前更有优势。

本文基于 Status Trio 和 DuoBar 当前 GitHub README、Release Notes、Known Limitations 以及 Privacy / Telemetry 文档整理。功能、系统支持和隐私策略可能随版本变化，下载前请以各项目最新 Release 为准。
