AirBattery：开源 Mac 电量监控工具，集中查看苹果设备电量

发布于 2026-06-30

同时使用 iPhone、AirPods、Apple Watch、iPad 和 Mac 外设时，电量信息经常分散在不同入口里。耳机要打开盒子看，手表要从手机或手表上确认，妙控键盘和鼠标又在 macOS 的蓝牙设置里。设备一多，快速确认剩余电量就会变得很零碎。

AirBattery (旧版名: DockBattery)是一款开源的 Mac 电量监控工具，可以把 iPhone、iPad、Apple Watch、AirPods、妙控键盘、妙控鼠标，以及部分蓝牙耳机和键鼠的电量，集中显示在 Dock、菜单栏或桌面小组件中。它更适合长期在 Mac 前工作、同时管理多台苹果设备的用户。

一句话看它的定位：AirBattery 适合想在 Mac 上集中查看多台苹果设备电量、又想寻找免费开源方案的用户。它不是 App Store 分发的软件，首次使用涉及未公证 App 提示、设备信任配对和蓝牙权限，更适合能接受一次初始设置的 Mac 用户。

作为 Mac 电量监控工具，AirBattery 实用在哪？

菜单栏、Dock 和小组件集中显示设备电量

启动后，AirBattery 会自动识别支持的设备，并把电量显示在菜单栏、Dock 图标或桌面小组件中。你可以只保留一个状态栏小图标，也可以使用更直观的小组件，同时查看多台设备的电量。它还支持低电量提醒，适合 AirPods、妙控键盘、妙控鼠标这类容易被忽略的设备。

Nearcast 查看局域网内其他 Mac 及外设电量

Nearcast 更偏多 Mac 场景。如果家里或办公室同时有 iMac、MacBook 等设备，并且它们处在同一个局域网内，AirBattery 可以查看其他 Mac 及其外设的电量。这个功能对单机用户意义不大，但对多机协作或固定桌面环境更有价值。

安装 AirBattery 前需要注意什么？

AirBattery 是一款开源 Mac 电量监控工具，安装和使用并不复杂，但它不是通过 App Store 分发的商业软件。正式使用前，建议先了解系统公证、设备配对和 Apple Watch 电量读取方式，避免遇到无法打开、设备不显示或电量不更新的问题。

安装前建议先看这几点：

  1. 目前没有经过 Apple 公证：AirBattery 不是 Apple Notarization 公证应用，首次运行时可能会被 macOS 拦截或提示无法验证开发者。遇到这种情况，可以进入“系统设置 – 隐私与安全性”，找到被拦截的 AirBattery 并选择允许运行；如果仍无法运行，建议先确认是否下载的是最新版。
  2. iPhone / iPad 需要先完成信任配对：手机和平板不是安装后就一定会自动出现。需要在 AirBattery 运行时，用数据线连接一次 Mac，并在 iPhone 或 iPad 上点击“信任此电脑”。完成配对后，再保持设备与 Mac 处于同一局域网内。
  3. Apple Watch 电量依赖 iPhone 中转：AirBattery 读取 Apple Watch 电量时，通常需要依赖已配对的 iPhone。如果 iPhone 只是通过蓝牙被发现，而不是通过 WiFi 或 USB 连接，可能无法显示 Apple Watch 的电量。
  4. 电量更新受连接环境影响：蓝牙信号、局域网状态、设备休眠和距离都会影响电量刷新。设备暂时离线或长时间没有更新数据时，不一定代表软件本身出错。

AirBattery 需要哪些权限？蓝牙权限和数据处理说明

AirBattery 需要获取 Mac 的蓝牙权限，用来发现附近设备并解析电量信息。它的核心用途是本地显示设备电量，但由于工具本身未经过 Apple 公证，如果你对蓝牙权限、开源客户端或第三方安装包比较敏感，建议优先从 GitHub Releases 获取最新版，并在安装前查看项目说明和源码。

AirBattery 更适合哪些 Mac 用户？

AirBattery 更适合苹果设备数量比较多、并且经常在 Mac 前工作的用户。比如桌面上长期有 iPhone、AirPods、Apple Watch、iPad、妙控键盘或妙控鼠标，平时只是想快速确认这些设备还剩多少电，不想在手机、手表、蓝牙设置和系统小组件之间来回切换。

如果你的使用场景比较简单，只是偶尔连接一个蓝牙耳机，或者主要使用一台 Mac 和有线外设，macOS 自带的蓝牙电量显示基本已经够用。AirBattery 的优势，主要体现在多设备同时管理上。

它更适合把“集中查看电量”当作刚需的小工具用户，也适合正在寻找类似 Batteries 的付费多设备电量监控工具之外开源选择的人。需要注意的是，AirBattery 目前不是 Apple 公证应用，首次使用还涉及蓝牙权限和设备配对；如果你更在意 App Store 安装体验和商业软件支持，付费工具会更省心。
