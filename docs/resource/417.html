心之链：用AI和换位思考+雷达图可视化，重新认识自己与朋友的心理世界

发布于 2025-10-08

心之链概览

心之链是一款结合心理学与人工智能的微信小程序，旨在让用户通过游戏化的方式填写心理健康问卷，从而更好地了解自己与朋友的心理差异。它以“换位思考”为核心理念，让朋友站在彼此的角度回答问题，通过AI分析与可视化雷达图展示结果，帮助用户发现自我认知与他人印象之间的差距。所有核心功能免费，依靠封面广告覆盖服务器与Token成本。首次打开即自动创建账号，无需繁琐注册。

心之链核心亮点

  • 换位思考：邀请朋友站在你的角度填写同一份问卷，获得“朋友眼中的你”。

  • AI智能分析：基于问卷作答生成专业分析，呈现个人与朋友视角的异同。
  • 可视化对比：支持雷达图等图表，对比不同朋友的评价与自评。

  • 多样化问卷：提供多个版本，覆盖不同人群与场景（后续持续增加）。
  • 一键上手：初次使用自动建号；可在个人中心完善昵称与头像。
  • 分享参与：将问卷一键分享给朋友，扩大样本，结果更客观。
  • 完全免费：核心功能零门槛体验，通过封面广告维持运营。

心之链使用流程

  1. 打开微信小程序“心之链”，系统自动为你创建账号。
  2. 选择感兴趣的问卷，先以“自己视角”完成作答。
  3. 生成专属链接，邀请朋友以“你的角度”填写同一问卷。
  4. 在结果页查看AI分析与雷达图对比，可按好友维度进行可视化选择。
  5. 分享给更多朋友，随着样本增多，综合结果更具参考价值。

适用人群与场景

  • 希望系统化梳理自我认知的人群。
  • 想更真实了解“朋友如何看我”的学生、职场人士与情侣/亲友。
  • 团队互评、课堂活动、社群破冰等需要轻量评估与可视化输出的场景。

心理学原理与意义

心之链的核心理念源于“社会镜像理论”——我们通过他人眼中的自己来重新认识自我。结合AI的情绪分析与数据建模，平台让用户在娱乐中获得科学的心理反馈。这种“AI换位思考”模式不仅具备趣味性，也让心理健康的自我探索变得更轻松。

常见问题要点

  • 如何注册：首次打开自动创建账号；可在“我的—修改资料”完善信息。
  • 是否收费：核心功能免费，靠封面广告维持服务器开销。
  • 结果作用：完成问卷即可查看分析与可视化对比；分享越多，结果越客观。
