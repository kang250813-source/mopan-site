Selene：基于 MoonTV v100 的移动端影视聚合播放器（Android/iOS），多源搜索与断点续播一站到位

发布于 2025-09-24

Selene概览

Selene 是一款以 MoonTV v100 为后端的移动端客户端，面向 Android 与 iOS 用户提供更顺手的观影体验。项目采用 Flutter 构建，延续 MoonTV 的内容聚合与搜索能力，带来更贴合手势与小屏操作的交互。

MoonTV 背景

MoonTV 是开源、跨平台的影视聚合播放器，聚合多家免费资源站，支持多源搜索、在线播放、收藏与播放记录。其 Web 端基于 Next.js、Tailwind CSS、TypeScript 搭建，支持 Docker 快速部署与 PWA，方便在 NAS 等个人环境中使用。

为什么选择 Selene

  • 原汁原味的内容聚合：直连 MoonTV v100，延续多源搜索与在线播放能力。
  • 移动端交互优化：手势友好、布局更紧凑，适配小屏阅读与操作节奏。
  • 跨平台覆盖：Android（ArmV8）与 iOS 双平台发布，观影方式更灵活。

Selene功能与体验

核心功能

  • 多源聚合搜索：一次搜索，覆盖多个视频源。
  • 智能播放记录：自动保存进度，支持断点续播。
  • 个人收藏夹：常看片单集中管理，回看更快捷。
  • 多内容类型：电影、电视剧、动漫、综艺均可浏览与播放。

交互与视觉

  • 现代化 UI：遵循 Material Design 3，信息分层清晰。
  • 深色模式：明暗主题自由切换，长时间观看更舒适。
  • 流畅动画：转场与操作反馈顺滑，降低操作成本。

技术特性

  • 高性能播放：基于 FVP 播放器，兼容多种格式。
  • 智能缓存：集成豆瓣数据缓存机制，页面加载更快。
  • 网络优化：支持 WebSocket 实时搜索，结果响应更及时。

Selene平台与适配

  • Android：最低支持 Android 5.0（API 21）。
  • iOS：最低支持 iOS 12.0。

Selene上手指南

  • 首次使用：启动后应用会检查登录状态；未登录将跳转登录页；登录成功进入主界面。
  • 主要入口：
    • 首页：热门推荐、继续观看、我的收藏。
    • 搜索：多源聚合搜索，提供实时建议。
    • 分类浏览：按电影、电视剧、动漫、综艺筛选。
    • 播放器：常用控制齐全，进度自动记录。
