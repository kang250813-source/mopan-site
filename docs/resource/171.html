ChatLab：本地优先的聊天记录分析工具，用 SQL + AI Agent 重新理解你的社交数据（开源免费）

发布于 2026-01-08

ChatLab（chatlab.fun）是一款本地优先（local-first）的聊天记录分析应用：把聊天记录留在你的电脑里，用灵活的 SQL 与 AI Agent 帮你“重看”过去的对话，从碎片信息里挖出规律、趋势与有趣的细节。项目免费、开源，面向真实使用场景持续迭代。

为什么选择 ChatLab

很多聊天记录分析产品依赖云端处理，数据一旦离开本机就会引发隐私焦虑。ChatLab 的思路更直接：把分析能力塞进本地，通过本地数据库完成存储与计算，让你在可控边界内掌握自己的社交数据。

本地优先的隐私策略

聊天记录与配置默认存放在本地数据库，分析过程也在本机执行。项目说明中提到：AI 相关能力可能存在“例外”，更适合在你确认数据边界后再启用，用与不用由你决定。

核心特性一览

🚀 极致性能：百万级消息也能顺滑浏览

采用流式计算与多线程并行架构，面对百万条级别聊天记录仍能保持流畅交互与快速响应，适合长期重度聊天用户与多群场景。

🤖 智能 AI Agent：让数据会“说话”

内置 10+ Function Calling 工具，支持动态调度，用更接近“分析助手”的方式深入挖掘聊天记录：把模糊问题变成可追踪的线索，把零散对话串成可理解的结论。

📊 多维可视化：趋势、规律、排行一眼看懂

提供活跃度趋势、时间规律分布、成员排行等图表维度，把“感觉”变成可验证的数据视图，适合复盘社群运营、团队沟通与个人社交习惯。

🧩 格式标准化：不同平台也能统一分析

通过数据抽象层抹平不同聊天软件的格式差异，让聊天记录以更统一的结构进入分析流程，降低跨平台整理成本。

支持的平台与路线图

  • 已支持：微信、QQ、WhatsApp
  • 即将支持：iMessage、Discord、LINE

项目处于早期迭代阶段，难免存在缺陷与未完成功能。遇到问题时，反馈往往比“忍着用”更能推动产品变好。
