蛐蛐（QuQu）：开源免费的 Wispr Flow 替代品，FunASR 本地识别 + 可配置大模型的中文语音工作流

发布于 2025-09-27

蛐蛐（QuQu）概览

蛐蛐（QuQu）是一款为中文用户打造的桌面端语音输入与文本处理工具。与 Wispr Flow 不同，蛐蛐完全开源免费，语音在本地计算机完成识别与处理，优先适配国内大模型生态，强调隐私与中文体验。

与 Wispr Flow 的差异

  • 价格：蛐蛐免费；Wispr Flow 为 $12/月 订阅。
  • 隐私：蛐蛐本地处理；Wispr Flow 依赖云端处理。
  • 中文体验：蛐蛐针对中文优化；Wispr Flow 为通用支持。
  • 模型生态：蛐蛐支持国产 AI 模型与 OpenAI API 兼容服务；Wispr Flow 仅国外模型。

 

核心优势

顶尖中文识别，兼顾隐私

内置 阿里巴巴 FunASR Paraformer，在本地运行，能理解中文口语与网络语境，语音数据不出设备。

“ASR + LLM”的两段式引擎

先做高精度识别，再用大模型做智能优化与重写。可自动过滤口头禅，修正自我更正类表达（如“周三…不对，是周四”直接输出为“周四开会”），产出更适合阅读与发送的文本。

面向国内的开放 AI 生态

兼容 OpenAI API，优先适配 通义千问、Kimi 等国内模型，带来更快响应、更低成本与更好合规性。

贴合开发与效率场景

可准确识别并格式化 camelCase、snake_case 等编程术语。支持自定义 AI 指令，按当前应用情境（写代码、回邮件）自动调整输出。

关键功能

  • 一键唤醒：全局快捷键 F2。
  • 实时识别：本地 FunASR 引擎高精度中文转写。
  • 智能优化：连接你的大模型，自动润色、纠错、总结、重写为邮件或代码片段。
  • 无缝粘贴：转换完成自动粘贴到光标位置，减少手动切换。

使用场景

  • 日常语音输入、会议纪要、学习记录、邮件与文档撰写。
  • 开发者代码注释、提交信息、接口说明的口述生成。
  • 对隐私敏感、希望离线处理的个人与团队。

迁移理由

在使用 Wispr Flow 的前提下，希望节省订阅费用、提升中文体验并把数据留在本地，蛐蛐提供直接可用的替代路径。
