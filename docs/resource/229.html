发布于 2025-12-13

📌 书摘卡片生成器简介

书摘卡片生成器（app-book-excerpt-generator）是一款专为阅读爱好者打造的免费开源工具，帮助用户快速将书中精彩语句制作成美观的图片卡片。无需设计基础，通过可视化操作，即可生成适用于朋友圈、小红书、微博等平台的高颜值书摘图片，提升阅读分享的表现力与传播力。

地址：https://github.com/zhifu-tech/app-book-excerpt-generator

✨ 核心功能亮点

实时预览与所见即所得

用户在输入文字内容时即可实时查看卡片效果，所见即所得，操作简单流畅。

丰富的主题与字体支持

内置10+种精美主题背景（含纯色与渐变），支持宋体、行书、毛笔等多种中文字体，可自由切换字体颜色与字号。

灵活的排版与样式自定义

提供横排与竖排两种布局方式，可调整卡片宽度、字体大小和印章文字，让每一张书摘卡都独具风格。

一键导出高清图片

生成的卡片支持导出为高清PNG图片，适配微博、朋友圈、豆瓣、小红书等多种社交平台，分享便捷。

响应式网页设计

完美适配桌面与移动设备，随时随地制作卡片，无需安装任何插件或客户端。

🛠️ 技术实现

  • HTML5 + CSS3：语义化结构+响应式设计，兼容多端
  • JavaScript (ES6+)：模块化开发，交互流畅
  • html2canvas：高效导出为图片
  • JSDoc / ESLint / Prettier：规范代码与生成文档，保障开发质量

📚 使用方式

  1. 填写内容：输入书摘内容、书名、作者、印章文字
  2. 自定义样式：选择背景、字体、颜色与排版
  3. 预览导出：实时查看效果，点击“保存”即可导出高清图片

🎯 适合人群

  • 阅读博主、公众号作者
  • 小红书种草达人
  • 语录整理爱好者
  • 教育工作者或讲书类内容创作者
  • 需要制作“高质量读书分享图”的所有人
