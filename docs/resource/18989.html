VidServe：一键把电脑视频目录变成局域网视频服务器

发布于 2026-08-11

电脑里的视频想在手机、平板上直接播放，但又不想传文件、不想折腾 NAS 或 Jellyfin？VidServe 是一款轻量级局域网视频服务器，可以把电脑上的视频文件夹转换成浏览器可访问的视频页面。

只要设备连接同一个局域网，就可以直接打开网页播放，不需要额外安装播放器 App。

网络环境说明：
VidServe 主要运行在本地设备上，视频访问依赖你的局域网环境。手机、电脑等设备需要连接同一个网络，实际播放效果会受到局域网质量和浏览器视频格式支持影响。

VidServe 是什么？

VidServe 是一款面向本地网络的视频共享工具。选择电脑上的视频目录并启动服务后，同一局域网内的其他设备就可以通过浏览器访问。

它和 Jellyfin、Plex 这类完整媒体服务器的区别在于，VidServe 不提供海报墙、用户管理、播放记录等媒体库功能，重点放在快速访问本地视频，而不是长期管理影音资源。

 

为什么普通用户需要局域网视频服务器？

电脑里已经有视频，换到手机或平板观看时，常见做法无非是重新传一份文件、开启 SMB 共享，或者部署 Jellyfin、Plex 这类媒体服务器。

前两种方式需要额外操作，完整媒体服务器又更适合长期影音库。VidServe 填补的是中间这类需求：不想搭一套完整系统，只想让同一网络里的其他设备直接播放电脑上的视频。

VidServe 怎么使用？

VidServe 的使用流程就是“选择视频目录 → 启动服务 → 浏览器播放”。

  1. 安装 VidServe： 根据系统版本安装对应程序。
  2. 选择视频文件夹： 指定需要共享的视频目录。
  3. 启动本地服务： VidServe 会生成局域网访问地址。
  4. 连接同一网络： 手机、平板或其他电脑需要与运行 VidServe 的设备处于同一个局域网。
  5. 扫码或打开地址： 使用浏览器进入播放页面。

如果出现黑屏、没有声音或无法播放，通常需要检查视频编码是否被当前浏览器支持。

VidServe 和 Jellyfin、Plex 有什么区别？

如果只是想在手机、平板上播放电脑里的视频，VidServe、Jellyfin 和 Plex 都能做到，但它们的功能和使用门槛差别很大。

如果需要长期管理大量影视资源、记录观看进度或服务器端转码，Jellyfin、Plex 更合适。VidServe 更偏向局域网里的临时视频共享，重点是减少配置步骤，而不是提供完整媒体库。

VidServe 当前存在的几个限制

VidServe 的定位比较简单，它没有加入 Jellyfin、Plex 这类媒体服务器常见的媒体库管理功能，因此在一些使用场景下会存在限制。使用前可以先了解以下几点：

使用前可以先了解这几点：

1. 源码没有公开：
VidServe 有 GitHub 项目页面，但目前主要用于发布安装包，源代码没有公开，也没有看到明确的开源许可证。如果你比较在意源码审查或自行编译，这一点需要留意。

2. 暂不支持外挂字幕：
根据官方说明，当前版本还不能加载独立字幕文件。

3. 部分视频格式可能播不了：
VidServe 不负责服务器端转码，实际能否正常播放，和手机、平板浏览器支持的视频编码格式有关。遇到黑屏、没有声音时，通常要先检查视频编码兼容性。

4. 没有用户权限管理：
VidServe 更适合可信的家庭或办公局域网环境。只要设备能够访问对应地址，就可能打开视频页面，不适合直接当成带权限控制的媒体服务器使用。

VidServe 适合哪些用户？

  • 想在手机或平板直接播放电脑视频：不想先复制文件，也不需要长期管理媒体库。
  • 偶尔需要局域网共享视频：例如家庭录像、课程资料、产品演示或培训视频，希望其他设备打开浏览器就能播放。
  • 觉得 Jellyfin、Plex 配置太重：不需要海报墙、多用户、观看记录或服务器转码，只想完成最基本的视频共享。

如果你需要海报墙、多用户账号、观看进度、服务器端转码或远程访问，Jellyfin、Plex 或完整 NAS 媒体服务器会更合适。
