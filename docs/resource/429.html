FlipperDroid：将Android手机变成开源移动网络安全工具包（支持NFC、RFID、Bluetooth与BadUSB）

发布于 2025-10-05

FlipperDroid概述

FlipperDroid 是一款以 Kotlin 开发的 Android 应用，灵感来自 Flipper Zero。它把现代安卓手机改造成便携的网络与硬件安全测试工具包，基于手机原生能力与接口，面向安全研究者、渗透测试工程师与极客用户。支持在移动端直接交互并分析多种通信协议与接口。

FlipperDroid主要功能

  • NFC 与 EMV 读取/模拟：支持读取并模拟 NFC 卡片，包括部分非接触式芯片卡（用于研究与测试场景）。
  • 蓝牙接口：扫描周边蓝牙设备并建立连接，为后续模拟和分析打基础。
  • 网络工具（开发中）：计划集成 Nmap、Wi-Fi 扫描与数据包分析等网络诊断能力。
  • RFID 与红外模块：读取或发送 RFID/红外信号，用于设备交互测试。
  • BadUSB 模块：可模拟 USB HID 设备以评估主机的防护与用户安全意识。
  • 高级日志系统：记录设备交互、扫描与应用行为，支持查看与导出。
  • 可定制技术设置：提供参数调整以便更细粒度的测试。
  • Material UI 兼容：遵循 Material Design，使界面更适配原生 Android 体验。

要求与测试环境

需要 Android 10 或更高版本。开发者在已经 root 的 Google Pixel 7（运行 LineageOS）上进行了测试。
