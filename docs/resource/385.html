ClassIsland：智能班级课表显示与多媒体信息管理工具

发布于 2025-10-20

ClassIsland简介

ClassIsland 是一款专为学校与教学环境打造的 多媒体大屏课表信息显示工具，支持在 Windows 设备上清晰展示课程安排、当前课节、提醒和天气等信息,帮助教师与学生高效掌握每日教学节奏。其灵感源自 iOS 的 “动态岛（Dynamic Island）” 设计，强调信息的即时性与可视化体验。

ClassIsland核心功能亮点

1. 直观的课表显示

通过自定义组件，教师可在大屏上显示日期、时间、天气、倒计时、课程表等内容。组件支持多行排列与自动轮播，使信息展示更加灵活与丰富。

2. 智能提醒系统

ClassIsland 内置多种提醒方式，可在上课、下课等关键时间自动发出提示，支持横幅提醒、语音播报、音效和全屏特效，帮助师生掌握课堂节奏。

3. 强大的课表管理

教师可轻松导入学校提供的 Excel 或其他软件的课表数据，并通过内置编辑器快速调整时间表、科目和课程顺序。支持多周轮换、临时换课、跨天调课和课表预定，满足复杂教学场景。

4. 自动化与规则集

用户可定义“当 XX 发生时执行 XX 动作”的自动化规则，例如上课时自动隐藏主界面、定时切换组件、播放提示音等。内置天气、窗口、课程等多种触发条件，同时开放插件 API，支持自定义扩展。

5. 插件生态与扩展性

ClassIsland 拥有活跃的插件系统，可通过安装插件扩展功能，如天气预警、UI 提权、主题加载等。开发者可访问开放 API，自行编写插件，实现无限可能。

6. 高度个性化的主题

支持用户加载自定义主题或替换主界面样式，打造独具特色的教学显示界面。应用自动适配系统主题色，过渡动画流畅自然。

7. 稳定与安全保障

ClassIsland 注重运行可靠性与安全性，提供自动时间同步、崩溃防护、密码保护等机制。未来版本将推出“集控管理”功能，实现多设备统一控制与配置分发。

ClassIsland应用场景

  • 教室大屏课表与课程信息展示
  • 班级公告与提醒系统
  • 校园活动倒计时、天气预报显示
  • 教务自动化、教师值班安排可视化
