Agili 的 AIGC 周刊

由 Agentic AI 驱动的智能内容策展系统

Agili AIGC 周刊 是一份专注于人工智能生成内容（AIGC）领域的高质量精选周报，依托 Agentic AI Agent 实现自动策展，每周发布最新的 AI 工具、研究进展和技术观点。其目标是为 AI 开发者、内容创作者与研究者提供持续更新的行业资源和灵感来源。

访问地址：👉 https://aigc-weekly.agi.li
订阅 RSS：📡 https://aigc-weekly.agi.li/rss.xml

🧠 智能驱动 · AI 自动策展

本项目最大亮点是由 Claude Agent 驱动的 Agentic AI 策展系统，它基于 MCP（模型上下文协议），可以与 CMS 无缝交互，实现自动抓取、筛选并发布内容，显著提升编辑效率与内容质量。

🔧 技术架构一览

Agili AIGC 周刊构建在现代前沿技术之上，采用完整的 Serverless 架构，部署在 Cloudflare 边缘网络，兼顾性能与可维护性：

  • 前端框架：Next.js 15（App Router）+ OpenNext
  • CMS：Payload CMS（Headless）
  • 数据库：Cloudflare D1（基于 SQLite）
  • 对象存储：Cloudflare R2
  • Agent SDK：@anthropic-ai/claude-agent-sdk
  • 运行环境：Cloudflare Containers & Workers

这一组合构成了低延迟、高自动化、可持续扩展的 AIGC 内容发布系统。

🚀 快速部署指南

本项目支持快速启动与本地开发，适合开发者参考与复用：

安装步骤

git clone https://github.com/ccbikai/aigc-weekly.git
cd aigc-weekly
pnpm install

环境配置

  • .env.local：填写 Cloudflare 绑定、密钥等信息
  • worker/.env.local：配置 Firecrawl API Key 与 Agent 参数

本地运行

pnpm dev        # 启动前端
pnpm dev:agent  # 启动 Claude Agent
pnpm dev:worker # 启动 Cloudflare Worker

🧩 Agent 集成与 MCP 协议支持

AIGC 周刊通过 Claude Agent 与 Payload CMS 实现深度集成，支持通过 WebSocket、REST API 与 MCP 协议通信，构建起真正自动化的智能策展系统。

支持本地测试、WebSocket 接入与在线部署，所有功能模块都以模块化方式开放，便于开发者扩展。

📦 一站式部署到 Cloudflare

支持一键部署至 Cloudflare 全系服务，包括：

  • D1：数据库自动迁移
  • R2：内容存储
  • Workers：边缘服务逻辑
  • Containers：Agent 智能运行
pnpm deploy
pnpm deploy:worker
