PDF.hk：免费、安全、全能的在线 PDF 工具（合并/转换/压缩/OCR/编辑）

发布于 2025-08-15

PDF.hk概述

PDF.hk 是一个由开源项目 Stirling PDF 部署的在线 PDF 工具网站，面对日常办公与学习场景提供超过 50 种处理能力。支持合并、拆分、旋转、重排与删除页面，可在 PDF 与 Word、PPT、图片、Excel、HTML 等格式之间相互转换。平台内置压缩优化、电子签名与权限管理，能添加水印、页码、图像与附件，并提供 OCR 对扫描件与图片进行文字识别。站点提供多语言与暗模式体验，处理过程在本地完成，无需外部上传，更加注重隐私与安全。

PDF.hk核心功能

  • 文件合并与拆分：快速将多个 PDF 合并为一个，或按页拆分成多个文件，操作简便。

  • 格式转换：支持 PDF 与 Word、PPT、图片等多种格式互转，转换质量稳定，不易错位。

  • PDF 压缩：一键压缩文件，减少体积便于分享，同时保持清晰度。

  • 编辑功能：可添加水印、设置密码加密、内容涂黑（Redact）、电子签名，满足多种编辑需求。

  • OCR 文本识别：自动识别扫描件或图片中的文字，便于复制和二次编辑。

PDF.hk适用人群与场景

频繁处理合同、简历、报告、讲义与投递材料的个人与团队；需要在浏览器内快速完成合并、转换、压缩、签名与脱敏的用户；重视隐私与合规、希望尽可能在本地完成处理的使用者。
