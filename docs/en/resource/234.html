Mini Clipboard：轻巧高效的macOS开源剪贴板管理器

Published 2025-12-13

简洁高效的 macOS 剪贴板工具

Mini Clipboard 是一款开源、简约且功能强大的 macOS 剪贴板管理器。它支持自动记录文本、链接、图片、颜色等多种类型的复制内容，并通过可视化时间线、分组收藏与搜索过滤等功能，帮助用户高效管理和粘贴跨应用内容。

这款工具不仅操作直观、界面美观，兼容 Apple Silicon，还具备多种布局与快捷键支持，非常适合程序员、设计师、创作者等重度剪贴板用户。

核心功能亮点

📌 历史采集

自动捕获所有复制内容，包括文本、图片、链接、文件与颜色值，避免信息遗漏。

🗂 时间线浏览

支持横向列表、纵向列表和网格布局，内容预览一目了然，可自定义命名。

⭐ 收藏与分组

通过 Pinboards 功能将常用内容归类收藏，自定义分组名称与颜色标记，提升查找效率。

⚡ 快捷粘贴

支持双击或回车直接粘贴内容，并可选择纯文本粘贴方式，快速调用无需切换应用。

🔍 即时搜索

输入即搜，支持关键词与来源应用的组合筛选，信息检索高效灵活。

⌨ 快捷键与个性化设置

可自定义快捷键映射、历史保留时长、界面布局及面板位置，满足不同使用习惯。

快速操作指南

  • 呼出面板：⇧ + ⌘ + P（支持修改）
  • 直接粘贴：双击或按下回车键
  • 快速预览：空格键
  • 项目移动：方向键
  • 多选复制：Shift 或 Command + 点击
  • 搜索内容：直接输入关键词

安装方法

  1. 前往 GitHub Releases 页面 下载最新版 .dmg 文件（国内网盘）；
  2. 将 Mini Clipboard.app 拖入“应用程序”文件夹；
  3. 启用“安全性与隐私”中的“允许已知开发者的应用”；
  4. 启动应用，即可使用。

系统要求： macOS 12 及以上，原生支持 Apple Silicon。开发环境需 Xcode 15+ 与 Swift 5.9。
