OpenLess：开源语音输入工具，把口述需求整理成 AI Prompt

Published 2026-05-30

每天高频使用 ChatGPT、Claude 或 Cursor 的人，大概率算过一笔账：把你脑子里的复杂需求，一行行敲成逻辑严密的 Prompt（提示词），其实非常耗时。

很多人用语音输入时，真正难受的不是识别不准，而是说出来的内容太散。刚开始想这么说，中途又补一句，最后再改个要求，系统听写会把这些停顿、重复和临时改口全部照着打出来。

结果就是，字是出来了，但还不能直接用。想发给同事，要重新理一遍；想丢给 ChatGPT、Claude 或 Cursor，也得先把口水话改成清楚的 Prompt。

OpenLess 做的就是这一步：按住快捷键说完，它先转写，再用 AI 帮你把内容整理干净，最后直接输入到当前光标位置。你不用在录音、复制、粘贴、改写之间来回切换。

所以 OpenLess 更适合被理解为一款开源语音输入工具，而不是普通听写软件。它解决的不是“能不能把声音变成字”，而是“能不能把随口说的话变成可以直接使用的文字”。

摘要：
OpenLess 是一款支持 macOS 和 Windows 的开源 AI 语音输入工具。你只需按住快捷键随口描述需求，它会在后台调用 AI 大模型去掉口语废话、重组逻辑，然后把整理好的结构化 Prompt 或润色文本，直接输入到当前屏幕的光标位置，适合作为订阅制商业语音工具的开源替代方案。

开源语音输入的核心差异：不是转录，而是整理成 Prompt

OpenLess 最核心的区别在于它的“AI Prompt 模式（结构化输出）”。

比如你按住热键随口说：“嗯……帮我写个 Python 脚本，要求把文件夹里的图片批量转格式，注意下报错处理”。松开热键后，光标处直接输出的不是你的原话，而是一段整理好的英文或中文指令：


- 编写一个 Python 脚本，用于批量转换文件夹中的图片格式。
- 请确保包含完整的错误处理机制。
- 代码需附带必要的注释。

它不是一个独立的编辑器，而是悬浮在系统底层。不管你是停留在 VS Code、网页端 ChatGPT 还是微信输入框里，整理好的文字都会直接落到光标处，省去了复制粘贴的繁琐。

OpenLess 相比商业订阅工具，优势和门槛在哪里？

像 Typeless、Wispr Flow 这样的商业工具体验确实好，但采用的是订阅制（通常每月十几美元起步）。OpenLess 的切入点是把选择权还给用户。

  • 凭证与数据控制：商业工具通常由产品方托管模型与账号体系；而 OpenLess 允许你自带 API 凭证，并将转写历史、词库等基础数据保存在本地。
  • API 灵活性：它的语音识别（ASR）支持火山引擎流式接口、OpenAI Whisper 兼容接口，甚至本地的 Qwen3-ASR；润色模型则支持 DeepSeek、OpenAI、Anthropic 等主流厂商的兼容端点。
别把它理解成“永久免费云服务”
OpenLess 免费的是客户端和代码，不是背后的语音识别与大模型算力。实际使用时，你需要选择 ASR 和润色模型：接云端 API，就要按服务商规则付费，语音和文本也会交给对应服务处理；接本地模型，隐私边界更清楚，但对电脑性能和配置能力要求更高。

OpenLess 和几款同类 AI 语音输入工具怎么选？

如果你正在找 AI 语音输入工具，OpenLess 不是唯一选择。不同工具之间的差别，主要看你更在意开箱即用、本地处理、多语言支持，还是后续的 API 成本。

同类工具选型大白话指南：

  • 想用嘴写 Prompt，且愿意自己配置 API：选 OpenLess。它跨平台、开源，更适合把口述需求整理成可直接使用的 Prompt。
  • 想要开箱即用，不想配置太复杂：看 SpokenType 评测。它更偏产品化体验，重点在自动润色和自带 API，配置压力相对小一些。
  • 只用 Mac，并且更在意本地处理：看 Input 0。它更偏 macOS 本地语音输入，适合看重本地转录和自定义 LLM 润色流程的人。
  • 主要想免费输入、多语言转写，润色需求没那么强：看 LazyTyper。它基于 Whisper，更适合用来降低日常打字成本。

如果你的核心需求是把零散口述整理成 Prompt，OpenLess 的方向会更贴近这个场景；如果你更看重省心、本地处理或多语言输入，上面几款工具可以按需求分别比较。

macOS 用户安装 OpenLess 前要注意什么

Windows 用户的安装相对直接，但 macOS 用户需要注意签名限制。

安装避坑提醒：
由于当前早期的 macOS 版本可能未经 Apple 官方开发者公证（采用 ad-hoc 签名），你第一次打开时，大概率会遇到系统提示“已损坏，无法打开”。这通常不是软件损坏本身，而是 macOS Gatekeeper 对未公证应用的拦截。你需要手动在终端里执行 xattr -cr /Applications/OpenLess.app 命令解除隔离后才能正常运行。

OpenLess 适合谁，谁别折腾？

OpenLess 更适合已经把 ChatGPT、Claude、Cursor 当成日常工具的人。比如你经常要写长 Prompt、整理需求、写代码注释、改邮件措辞，又不想每个月为语音输入工具单独付一笔订阅费，那它的价值就比较明显。

它也更适合手里已经有 DeepSeek、OpenAI、火山引擎等 API Key 的用户。因为 OpenLess 省掉的是软件订阅费，不是模型调用成本。如果你本来就习惯折腾 API、模型端点和本地配置，上手成本不会太高。

反过来，如果你只是偶尔用语音输入发几句话，或者完全不想碰 API Key、终端命令、模型配置这些东西，OpenLess 未必是最省心的选择。对这类用户来说，系统自带听写或者开箱即用的订阅制工具，反而更直接。
