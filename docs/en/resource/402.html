vYinn：中文古籍电子印章生成工具（支持阴文/阳文、透明PNG、可配置）

Published 2025-10-13

vYinn简介

vYinn是一款专为中文古籍设计的电子印章制作工具，由“殷人”开发，是古籍数字复刻计划的重要组成部分。它可与vRain古籍刻本电子书制作工具配合使用，让电子古籍更具真实感与历史质感。该工具以Perl语言开发，依赖Image::Magick模块，能通过配置文件精确控制印章参数，生成带透明背景的高质量PNG印章图像。

核心功能

  • 印文样式：支持阴文、阳文。
  • 印框形状：圆形、方形、椭圆。
  • 色彩与质感：印泥颜色可自定义；提供“残缺”“墨迹”“扩散”等古风效果。
  • 文字排版：根据字体属性自动修正上下左右间距以获得初步对齐；单字可独立设定大小、坐标、横纵变形、旋转与描边。
  • 导出能力：生成透明底 PNG，便于叠加到电子书或图片；支持从现有古籍印文图中扣取并生成透明底新图（y2y 目录）。
  • 配置驱动：初始配置文件可自动生成，全部参数可在配置文件中集中管理。
  • 技术栈：Perl 开发，需安装 Image::Magick 等模块。

使用说明（快速上手）

1）理解参数

  • 查看 config/blank.cfg，了解画布、印框、印文、效果等参数含义。
  • 对照 yins/ 目录示例及其 config/ 中的对应配置。

2）初始化工程

  • 运行 new_config.pl 从空白模板生成新配置，例如：perl new_config.pl -n 4,4（4 行×4 列网格）。

3）测试与调校

  • 执行 vyinn.pl -t 生成设计侧图，查看 yins/ 下带 test 后缀的测试图。
  • 调整配置中的文字坐标、变形、边距等参数，直至视觉达到预期。

4）生成成品

  • 运行 vyinn.pl（不带 -t）输出最终效果图与透明底应用图（自动裁切）。
  • 使用 y2y/ 下脚本，可从现有古籍印文图中扣取并生成新的透明底印文图。

适用人群与场景

  • 需要为古籍数字化项目、电子书、学术出版或文化传播素材添加古风印记的个人或团队。
  • 对印文细节、边框、墨迹质感与排版参数有精细控制需求的设计与排版工作者。
