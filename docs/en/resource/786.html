Banana Slides｜基于 nano banana pro 的原生 AI PPT 生成器，一句话/大纲/口述直出「Vibe PPT」

Published 2025-12-11

打造真正的「Vibe PPT」体验

Banana Slides 是一款基于 nano banana pro🍌 的原生 AI PPT 生成应用，它不仅支持从一句话、大纲或页面描述自动构建演示文稿，还能通过上传素材、图表、口头指令快速调整内容与排版，真正让 PPT 设计回归表达本质——快而美。

这款工具的目标很明确：用 AI 降低 PPT 制作门槛，让任何人都能轻松创作出视觉美感与结构兼备的演示内容。你不需要设计背景，也不需要模板苦选，只需一句话，它就能帮你搞定整场演讲的内容和风格。

结果案例
软件开发最佳实践 DeepSeek-V3.2技术展示

为什么选择 Banana Slides？

许多传统 AI PPT 工具都卡在几个问题：模板死板、自由度低、缺乏设计感、无法口头修改。而 Banana Slides，正是为解决这些痛点而生：

  • 🔓 风格高度自定义：支持上传任意模板图参考，自定义“审美”风格
  • 🧠 智能素材解析：自动提取文档中的图表、链接和图像用于排版
  • 🎤 自然语言修改：像和朋友对话一样修改内容，如“把第三页改成案例分析”
  • 🎨 页面高颜值：基于 nano banana pro 精准渲染，生成统一风格的高清页面
  • 📦 一键导出：支持 PPTX / PDF 格式，完美适配16:9，无需二次编辑

适用人群与应用场景

  • 学生与教育者：将课堂内容转为图文教案，快速完成学术演示
  • 职场与商务人士：产品介绍、投资汇报、战略规划一键成稿
  • 内容创作者与设计师：获取灵感参考，自定义视觉风格
  • 新手用户：无需设计基础，也能制作高质量演示文稿

核心功能概览

🧩 多种创作入口

  • 一句话生成：AI 自动生成结构与逐页内容
  • 大纲/页面描述：手动或自动输入，灵活切换
  • 口头编辑：自然语言实时调整内容

📁 智能素材支持

  • 支持上传 PDF / Word / Markdown / 文本文件
  • 自动提取图文、数据、关键要素用于幻灯片构建
  • 可上传参考图打造专属视觉风格

🎨 局部修改 & 整页重绘

  • 改图改字口头说，例如“把这个图换成饼图”
  • 页面一体风格统一、内容高清精致

📤 一键导出与演示

  • 导出为 PPTX 或 PDF
  • 自动适配标准演示比例
  • 开箱即用，节省大量排版时间

技术架构简要

  • 前端：React 18 + Vite + Tailwind + Zustand
  • 后端：Python + Flask 3.0 + SQLite
  • AI能力：接入 Google Gemini API / OpenAI
  • 部署方式：支持 Docker Compose，一键启动

快速部署方式

推荐使用 Docker 🐳 一键启动：

git clone https://github.com/Anionex/banana-slides  
cd banana-slides  
cp .env.example .env  
docker compose up -d

前端访问地址：http://localhost:3000
后端API：http://localhost:5000

开源地址：https://github.com/Anionex/banana-slides
