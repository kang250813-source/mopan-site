BookmarkHub：跨浏览器书签同步神器｜基于 GitHub Gist，开源免费

Published 2025-08-23

BookmarkHub简介

BookmarkHub 是一款开源浏览器插件，专为跨浏览器书签同步设计。它支持 Chrome、Firefox、Microsoft Edge 等主流浏览器，利用 GitHub Gist 存储书签数据，确保安全与可靠性，开源免费。用户无需额外注册，只需使用 GitHub 账号的 Token 和 Gist ID，即可实现跨设备跨浏览器的书签同步。

亮点功能

  • 无需单独注册账号，使用个人 GitHub 账号的 Token 与 Gist 即可
  • 一键上传/下载书签，快速备份与恢复
  • 一键清空本地书签（操作前建议先备份）
  • 跨设备、跨浏览器同步
  • 显示本地与远程书签数量，便于核对

工作原理与安全性

  • 书签以结构化数据写入到你的 GitHub Gist
  • 只要掌握 Token 与 Gist ID，就能在任意支持的浏览器中读取与同步
  • 数据保存在你的 GitHub 账户下，便于审查与管理

快速上手（使用步骤）

  1. 使用个人 GitHub 账号创建可访问 Gist 的 Token（建议仅授予 Gist 权限）
  2. 在 GitHub 上新建一个 Gist，获取该 Gist 的 ID
  3. 安装 BookmarkHub 插件
    • Chrome Web Store：https://chromewebstore.google.com/detail/fohimdklhhcpcnpmmichieidclgfdmol
    • Firefox Add-ons：https://addons.mozilla.org/en/firefox/addon/BookmarkHub/
  4. 打开 BookmarkHub 设置面板，填入 GitHub Token 与 Gist ID
  5. 执行「上传书签」或「下载书签」以完成首轮同步
  6. 需要核对时，可直接在 GitHub Gist 页面查看同步后的书签数据

适用场景

  • 更换浏览器或重装系统时的书签迁移
  • 多台设备间的日常同步
  • 团队或个人在不同环境下保持书签一致
