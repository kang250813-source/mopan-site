Computable GPU Index：查看 H100/H200/B200 GPU 云算力价格

Published 2026-09-04

Computable GPU Index（简称 CGI）不是用来帮你找“哪家 H100 最便宜”的普通比价工具，而是一个专门衡量高端 GPU 云算力价格 的市场参考指数。它把不同服务商分散的公开报价统一成 $/GPU-hour，帮助你判断当前 H100 SXM、H200 SXM、B200、B300 等高端 GPU 的公开租赁价格大概处在什么水平。

现在租用云端 GPU 跑大模型，不同平台的计费方式和按需报价差异很大。以 NVIDIA H100 为例，CGI 当前追踪的是 H100 SXM。不同服务商的公开按需报价可能出现明显的价格差距。

速览摘要：Computable GPU Index 是一个开源的 GPU 云算力价格指数，目前覆盖 H100 SXM、H200 SXM、B200 和 B300。它每 15 分钟根据公开 On-demand 报价更新市场参考价，计算方法、历史记录和代码都可以公开查看并复算，同时提供免密钥 REST API 与只读 MCP 接口。它不是最低价排行，也不包含 Spot、Reserved 等价格。

它和普通 GPU 比价网站有什么不同

GPU 比价网站通常会保留具体服务商、实例规格和对应价格，方便用户直接比较哪家当前报价更低。而CGI 不是服务商排行，而是把固定 Provider Panel 中符合条件的公开报价合成一个统一指数。

不同平台的实例条件、计费方式和附加费用并不完全一样，所以最低挂牌价不一定适合直接拿来做长期预算。

CGI 使用固定服务商面板、异常值筛选和加权聚合来计算参考价，不会简单把所有服务商报价直接取平均。

所以它更适合拿来判断“现在 H100、H200 这些 GPU 的公开租赁价格大概在什么水平”。拿到某家服务商的报价后，可以先和指数对一下，再结合实际的计费条件判断价格是否合适。

H100、H200、B200、B300 现在大概多少钱？

CGI 每 15 分钟更新一次，所以这里的数字只能代表当时的市场情况。截至 2026 年 9 月 4 日 12:15 UTC，官方实时看板显示的指数价格如下：

GPU CGI 参考价格
NVIDIA H100 SXM $3.54 / GPU-hour
NVIDIA H200 SXM $4.29 / GPU-hour
NVIDIA B200 $6.65 / GPU-hour
NVIDIA B300 $7.81 / GPU-hour

比如 B300 当时的指数约为每小时 7.83 美元，这个数字可以拿来了解当前 B300 租赁价格大概处在什么位置。不过它不是某一家云厂商的实际成交价，也不包含 Spot、Reserved、存储、网络和企业合同折扣等费用。

由于价格会持续变化，如果需要最新数据，还是应该以 CGI 实时看板为准。

Computable GPU Index 的价格是怎么算出来的？

CGI 不是把所有报价加起来取个平均数。它会先采集公开报价，再按照不同 GPU 分组计算，并尽量减少异常价格和长期没有变化的数据源对结果的影响。

1、采集公开报价：CGI 每 15 分钟采集一次公开价格。截至本文整理时，官方 Methodology 记录的采集范围为 29 家服务商、31 条采集源。采集范围并不等于最终指数使用的服务商数量。

2、不同 GPU 分开计算：H100 SXM、H200 SXM、B200、B300 都有各自固定的 Provider Panel，不会把不同型号和所有服务商的报价直接混在一起。

3、不同数据源的权重会变化：CGI 会观察各个来源过去的价格变化是否及时、是否长期落后于其他服务商，再据此调整它们对指数的影响。

4、不是简单取平均：最终采用分位数均值（IQM）计算中间一段价格投票，减少异常高价和异常低价对结果的影响。

怎么在本地复算 CGI 指数？

项目在 GitHub 上公开了计算代码和历史记录，并提供了 reproduce 脚本。克隆项目并安装依赖后，例如要重新计算当天的 H100 指数，可以运行：

./reproduce h100 "$(date -u +%F)"

也可以指定 GPU 和日期，例如重新计算 2026 年 9 月 4 日的 B300：

./reproduce b300 2026-09-04

脚本会根据公开历史重新计算已经发布的指数，并核对计算结果和对应哈希。如果全部匹配，就能确认本地重新算出的结果与官方公开记录一致。

开发者与 AI Agent 怎么接入 CGI

除了网页看板，CGI 也提供 REST API、历史数据文件和 MCP Server。现在这些接口都是只读的，不需要先注册账号，也不用申请 API Key。

REST API：直接查询最新 GPU 价格

例如查询最新的 H100 指数，可以直接请求：

curl "https://api.getcomputable.com/v1/index/H100/latest"

如果还想查看这次指数对应的数据来源和 receipts，可以使用：

curl "https://api.getcomputable.com/v1/index/H100/latest?include=receipts"

需要历史价格时，也可以通过 history 接口查询，例如：

curl "https://api.getcomputable.com/v1/index/H100/history?limit=4"

这种方式比较适合把 GPU 价格接进内部成本面板、监控脚本或其他自动化工具，而不用手动打开网页查看。

怎么下载 CGI 的历史价格数据？

CGI 的公开历史记录还会以 JSON 文件形式放在 data.getcomputable.com。如果需要做离线分析、保存历史价格或自己重新计算指数，可以直接使用这些归档数据。

怎么让 AI Agent 通过 MCP 查询 GPU 价格？

CGI 还提供了只读 MCP Server：

https://mcp.getcomputable.com/mcp

官方目前通过这个 MCP Server 提供 3 个只读工具，客户端不需要另外配置 CGI 账号或 API Key。

在支持 MCP 的客户端中加入这个地址后，Agent 就可以直接查询 CGI 的 GPU 价格数据。例如在讨论训练预算时，可以让 Agent 查询当前 H100 或 B200 的指数，而不是只依赖模型原本记住的价格。

接口与安全提示：CGI 的 REST API 和 MCP Server 目前都是匿名只读接口，不需要提交云平台 API Key、OAuth 凭据或账号权限。不过它仍属于第三方网络服务，企业环境使用前应按自己的安全要求评估。

用 CGI 看 GPU 云算力价格，有哪些限制？

CGI 反映的是公开 On-demand GPU 租赁市场的参考价格，拿它和实际云厂商报价比较时，还要注意下面几个限制。

1、目前只提供 4 款 GPU 的实时价格指数：CGI 当前公开发布的指数只有 NVIDIA H100 SXM、H200 SXM、B200 和 B300。采集层虽然会记录更多硬件型号，但 RTX 4090、A100、L40S 等型号目前没有对应的实时 CGI 指数。

2、指数只采用 公开 On-demand（按需租用）报价：Spot、Preemptible、Reserved、Committed、Monthly-commit、Serverless 等价格不会进入当前指数。因此，CGI 不适合直接拿来比较抢占式实例、包月套餐或长期承诺价格。

3、GPU 每小时价格不等于最终使用成本：CGI 统计的是 GPU 本身的租赁价格，实际使用时还可能产生网络出网、存储、跨区域传输等额外费用。

4、代码能开源使用，不代表价格数据也能直接商用：项目代码采用 Apache-2.0 协议；CGI 发布的指数数据和历史归档采用 CC BY-NC 4.0，默认限制商业用途。如果要把这些指数用于收费产品、结算或金融产品，还需要另外确认项目方的授权条件。

5、项目上线时间还不长：Computable GPU Index 的代码、计算方法和历史数据已经公开，不过目前上线时间还不长，数据覆盖、社区规模和长期维护情况还需要继续观察。

Computable GPU Index 常见问题

CGI 的数据和接口目前免费吗？

目前可以免费使用。在线看板、REST API 和 MCP 都支持免注册、免 API Key 的只读访问。

CGI 发布的 GPU 价格数据可以商用吗？

项目代码采用 Apache-2.0 协议，但发布的指数数据和历史归档采用 CC BY-NC 4.0，默认不适用于商业用途。如果准备用在收费产品、结算或金融产品中，需要进一步确认项目方的授权条件。

为什么 CGI 没有 RTX 4090、A100 或 L40S 的价格指数？

底层采集器会收集更多硬件数据，但目前官方公开发布的实时指数只有 NVIDIA H100 SXM、H200 SXM、B200 和 B300。RTX 4090、A100、L40S 等型号当前没有对应的实时 CGI 指数。

接入 CGI 的 MCP Server 需要 API Key 吗？

不需要。目前官方 MCP Server 是公开的只读服务，无需注册账号或配置 API Key，按照所使用客户端的 MCP 配置方式添加官方端点即可。

CGI 的 GPU 价格是实际成交价吗？

不是。CGI 是根据固定服务商面板中的公开 On-demand 报价计算出的市场参考指数，不代表某一家云厂商的最终成交价，也不包含 Spot、Reserved、私有合同折扣、存储和网络等成本。
