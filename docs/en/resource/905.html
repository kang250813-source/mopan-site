内网打印神器 PrinterService：浏览器即可轻松打印任何文件

Published 2025-10-29

🚀 一键打印，不再被设备限制

PrinterService 是一款基于开源项目 lan-printing 的内网打印工具，专为解决“电脑连不上打印机”的问题而设计。它让用户无需复杂配置，只需打开浏览器即可上传并打印文件，在局域网内的任意设备都能使用。

🌟 功能亮点

  • 内网打印支持：实现浏览器直接调用打印机，适配不同系统环境。
  • 多格式自动转换PDF：支持 Word、Excel、PPT、TXT、图片等主流格式，自动转为 PDF 打印。
  • 拖拽上传与文件管理：用户可通过拖拽文件上传，支持文件预览、删除与源文件查看。
  • 轻量级Web界面：可在电脑、手机、平板等设备访问，无需安装额外软件。
  • 后台静默运行：程序启动后自动在系统托盘显示图标，无干扰运行。

🧩 使用说明

  • 环境要求：电脑需安装 Office，可正常连接打印机，确保内网网络稳定。
  • 启动方式：运行程序后，右下角显示打印机图标即可；右键图标可查看访问地址。
  • 客户端访问：在浏览器输入服务地址即可进入网页端，上传文件后自动转换为 PDF 进行打印。

🗂️ 支持的文件格式

类型 格式 转换方式
文档 .doc / .docx / .pdf 自动转换为PDF
表格 .xls / .xlsx 自动转换为PDF
演示 .ppt / .pptx 自动转换为PDF
文本 .txt / .md / .log 自动转换为PDF
图像 .jpg / .png / .gif 自动转换为PDF

🔄 最新更新

  • 新增支持更多文件格式，所有文件统一转为PDF打印。
  • 拖拽上传功能优化，交互更自然。
  • 新增文件管理面板，支持预览、查看源文件、删除操作。
  • 智能删除与日志优化，自动清理文件但保留打印记录。
  • 界面与离线优化，移除冗余资源，支持单文件运行，无需联网依赖。

💡 常见问题

  • 没有界面？ 程序在后台运行，系统托盘中显示打印机图标即为启动成功。
  • 支持哪些文件？ 支持 Word、Excel、PowerPoint、PDF 等格式，其余格式会自动转换为PDF。
