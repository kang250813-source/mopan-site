Claude-Ally-Health：智能本地化个人医疗数据管理系统

Claude-Ally-Health 是一款集成 Claude AI 技术与专业医疗知识的智能健康助手，由 WellAlly Tech 团队开发。系统支持通过自然语言交互管理症状、药物、检查报告与健康记录，并配备多学科智能分析模块，是当前少有的完全本地化、零云依赖的个人医疗数据管理方案。

GitHub 开源地址：👉 https://github.com/huifer/Claude-Ally-Health

官方网站：🌐 www.wellally.tech

核心功能亮点

📁 数据私有化存储

  • 无需数据库，所有数据均保存在本地文件系统中
  • 使用 JSON 文件+目录结构组织信息
  • 无任何上传行为，100%数据私密与掌控

🧠 Claude Code AI 命令操作

  • 使用 Slash 命令形式进行自然语言操作
  • 无需编程基础即可高效管理健康数据

🧾 医疗文档结构化解析

  • 智能识别医学图像与检查单
  • 自动提取生化指标、影像描述与手术记录
  • 出院小结结构化存储与可查询

👨‍⚕️ 多学科智能分析系统（MDT）

  • 覆盖9大医学专科的分析能力
  • 支持并行处理与智能会诊建议整合

💊 药物相互作用智能检测

  • 支持药物-药物、药物-疾病、药物-食物等类型
  • 基于五级严重程度预警系统（A/B/C/D/X）
  • 提供用药建议、管理策略与监测指标

☢️ 医学辐射管理

  • 基于体表面积与指数衰减模型计算辐射暴露
  • 支持跨时间与多设备辐射剂量追踪

安全原则与免责声明

Claude-Ally-Health 致力于提供科学合理的辅助决策工具，并不替代专业医生，系统不会：

  • 给出处方药名称或剂量建议
  • 做出生死预后判断
  • 替代专业医疗行为

所有分析报告仅供个人参考，若有紧急情况，请立即就医。更多使用限制请查阅官方《安全原则文档》。

功能模块 技术特点

谁适合使用 Claude-Ally-Health？

  • 追求数据隐私与控制权的个人用户
  • 有长期慢病、体检记录管理需求的人群
  • 医疗工作者进行数据分析与研究的辅助工具
  • 对开源医疗健康项目感兴趣的开发者与科研者
