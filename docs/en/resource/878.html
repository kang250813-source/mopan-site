One-KVM：基于 PiKVM 的开源 BIOS 级远程控制工具 低成本实现 BIOS 级远程控制

Published 2025-11-04

🖥 One-KVM：开源、灵活、低成本的远程控制系统

One-KVM 是一个由社区开发者基于开源项目 PiKVM 深度二次开发的 DIY IP-KVM 方案。它通过廉价硬件（如电视盒子、开发板等），实现了 BIOS 级别的远程服务器和工作站管理，让远程维护变得更轻量、更智能。

项目定位于“非商业化开源解决方案”，为开发者和运维人员提供低成本的远程控制通道，支持 Docker 快速部署、视频流传输、虚拟存储、ATX 电源控制、VNC 控制 等多项功能。

🚀 One-KVM项目亮点

🔧 无侵入式远程访问

无需在目标设备上安装额外软件或驱动，支持直接访问 BIOS 与 UEFI 设置，实现系统级控制。

💰 高性价比部署

支持通用硬件如电视盒子、S905 芯片设备、树莓派等，大幅降低 IP-KVM 的搭建成本。

🧩 功能增强版 PiKVM

在原有功能上加入 Docker 部署、一键安装脚本、中文 Web 界面、视频录制、网页终端 等多种增强能力。

🌐 多平台兼容

支持 amd64、arm64、armv7 架构的 Linux 系统，可通过 Docker 镜像 或 整合固件包 快速部署。

⚙️ One-KVM快速部署方式

✅ Docker 一键部署（推荐）

使用以下命令即可完成完整环境搭建：

curl -sSL https://docs.one-kvm.cn/quick_start.sh -o quick_start.sh && bash quick_start.sh

支持多端口服务，包括 HTTP/HTTPS、VNC、IPMI、WebRTC 低延迟通信与 WOL 唤醒功能。

💾 固件整合包直刷

针对特定硬件（如玩客云、我家云、私家云二代等）提供预配置镜像，可实现开箱即用。
