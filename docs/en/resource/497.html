PlainApp：开源 AirDroid 替代，用浏览器管理安卓手机

Published 2026-06-12

想在电脑上管理安卓手机，很多人第一反应会想到 AirDroid。但实际用下来，文件传输、短信管理、屏幕镜像这些功能，经常会和账号登录、广告、会员限制或云端中转绑在一起。对于只是想在家里或办公室临时传个文件、看几张照片、回一条短信的用户来说，这套流程有点重。

PlainApp 更像是一个轻量的 AirDroid 替代。它是一款开源的安卓手机网页管理工具，安装到手机后，会在本机启动一个局域网 Web 服务。电脑或平板只要和手机连在同一个 WiFi 下，打开浏览器输入手机显示的地址，就能在网页端管理文件、相册、短信、通话记录和部分设备信息，也能进行实时屏幕镜像。

 

它最吸引人的地方不是功能堆得多，而是使用方式足够直接：电脑端不用装客户端，不需要注册账号，正常局域网使用场景下也不依赖第三方云端中转。如果你想找一个更干净、更本地化的安卓手机管理方案，PlainApp 确实值得单独拿出来看。

为什么说 PlainApp 适合作为 AirDroid 替代？

和市面上常见的手机管理工具相比，PlainApp 最大的优势在于“纯本地”与“免客户端”。

比如老牌的 AirDroid，其部分高级功能（如无限制传文件、电脑发短信）往往有付费门槛，且很多时候依赖自家的云端服务器中转；

而另一个极客圈常用的开源替代 KDE Connect，虽然也是纯本地，但它强制要求你在电脑端安装客户端，对普通用户体验并不算友好。

PlainApp 则把这两点揉在了一起：开源无广告 + 纯本地局域网传输 + 只要有浏览器就能连。

本地访问不等于随便开启

PlainApp 采用 AGPL-3.0 协议开源。正常在家里或办公室的同一 WiFi 下使用时，文件、照片、短信等数据不需要经过第三方云服务器中转，这也是它适合作为 AirDroid 替代的一个重要原因。

不过，PlainApp 要实现文件管理、短信查看、联系人读取这些功能，本身会涉及较高权限。建议只在可信网络里开启服务，用完及时关闭，不要把访问地址暴露到公网。

个人日常使用基本不用纠结协议问题；如果企业准备基于它二次开发、分发或对外提供服务，就需要提前看清 AGPL-3.0 对源码开放和网络服务场景的要求。

PlainApp 能在浏览器里管理哪些安卓手机内容？

PlainApp 不只是一个无线传文件工具。手机端启动服务后，电脑浏览器里会出现一个比较完整的安卓手机管理面板，常用能力基本都集中在里面。

1、文件管理：支持浏览手机内部存储、SD 卡和 USB 设备，可以上传、下载、重命名、移动和删除文件。

2、照片、视频与音乐：可以在浏览器里查看相册、播放视频和音乐，很多临时预览场景不需要先把文件下载到电脑。

3、短信与通话记录：支持读取和发送短信，也可以查看通话记录，适合在电脑前办公时临时处理验证码或短信回复。

4、应用与 APK 导出：可以查看已安装应用列表，并导出 APK 文件，适合备份常用 App 或在多台安卓设备之间迁移安装包。

5、通知镜像：手机通知可以同步显示到浏览器端，适合不想频繁拿起手机的桌面办公场景。

6、屏幕镜像：基于 WebRTC 将手机画面实时显示到浏览器中，最高支持 30fps 和音频。实际流畅度取决于路由器、WiFi 信号和手机性能。

7、设备信息：可以查看电池、存储、网络和系统信息，方便快速判断手机当前状态。

8、内置工具：PlainApp 还带有 Markdown 笔记、RSS 阅读器、媒体播放器、DLNA / Chromecast 投屏、P2P 聊天与文件分享、番茄钟和声级计等工具。

PlainApp 使用限制：适合局域网手机管理，不是远程控制工具

PlainApp 更适合在家庭、办公室、工作室这类固定 WiFi 环境下使用。它的核心能力是让电脑通过浏览器管理安卓手机，而不是像 TeamViewer 那样跨公网远程控制设备。使用前需要先了解几个边界，避免把它当成万能手机远控方案。

避坑指南与使用限制：

1、仅限同一局域网： 它没有内网穿透功能。也就是说，你在公司没法控制放在家里的手机。如果非要跨网，你需要自己折腾 Tailscale 等虚拟局域网工具。

2、仅支持安卓阵营： 目前要求 Android 9.0 及以上系统，苹果 iPhone 用户无法作为服务端使用。

3、自签证书警告： 首次在电脑浏览器访问那个 https://192.168.x.x 地址时，浏览器会提示“证书不可信”，你需要手动点击“继续前往”。这对纯小白来说可能会造成一点困惑。

4、后台运行和电量消耗：长时间开启本地 Web 服务和屏幕镜像，会增加手机耗电。部分安卓系统还可能因为省电策略杀后台，需要手动允许后台运行。

5、权限范围较大：文件、短信、联系人、通知等功能都需要对应权限。只开启自己需要的模块，并尽量在可信网络下使用，会更稳妥。

PlainApp更适合固定 WiFi 下的日常手机管理

如果你的主要场景是在家里、办公室或固定工位，把安卓手机里的截图、视频、安装包、文档来回导到电脑上，PlainApp 的实用性会比较明显。它在同类局域网手机管理工具里完成度不低，文件管理、短信查看、相册预览和屏幕镜像都能放到浏览器里完成。

更关键的是，它把大部分数据流转留在本地网络内，不需要先把文件丢到网盘、聊天软件或第三方同步服务里中转。只要你能接受“手机和电脑必须在同一 WiFi 下”这个前提，PlainApp 就可以作为一个长期保留的安卓手机管理工具。
