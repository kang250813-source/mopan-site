玉桃文飨轩：一键把 Markdown 变成精美图片的文本转图片工具

Published 2025-12-09

玉桃文飨轩简介

玉桃文飨轩🍑是一款面向创作者与阅读爱好者的文本转图片工具。一键将 Markdown 渲染为高清长图，提供真实感书摘模式、多款主题与字体、可自定义背景与颜色。所有数据在本地完成处理，不依赖服务器上传，隐私更有保障。多端适配便于在手机、平板与电脑间顺畅分享。

访问方式

  • 在线地址：https://share.lovejade.cn/
  • 书摘模式：https://share.lovejade.cn/digest
  • 开源仓库：https://github.com/nicejade/markdown2png

核心功能

  • ✨ 一键将文本内容转为高清图片，完整支持 Markdown 语法渲染
  • 📅 可添加日期水印，提升专业感与时效性
  • 🔒 全程本地处理，无需上传，守护内容安全与隐私
  • 🎨 内置多款主题与字体，可自由切换并自定义背景、字体与颜色
  • 📱 输出尺寸可调，适配手机、平板与桌面端展示
  • 📚 真实感书摘模式，读书笔记更有质感
  • ⚡️ 一键复制到剪贴板或下载，快速用于社交平台发布

使用方法

  1. 在 Focus 状态输入内容（支持 Markdown）；
  2. 切换到 Blur 状态查看实时预览；
  3. 点击「保存图片」，即可导出高清长图到本地，或复制后直接用于社交发布。

适用场景

  • 读书笔记与书摘卡片
  • 文章摘要与知识卡片
  • 公众号/博客/社区配图
  • 活动宣发与品牌视觉素材
  • 团队知识沉淀与内外部分享

产品优势

  • 隐私友好：本地渲染与导出，内容不离开设备
  • 视觉统一：主题、字体与背景可配套定制，形成品牌风格
  • 高清可读：长图导出清晰，适合长文与代码片段展示
  • 操作简洁：输入—预览—导出三步完成，全流程高效
  • 多端适配：尺寸灵活，适配主流社交与内容平台

技术栈

基于 Vue3、Vite、Pinia、TailwindCSS、TypeScript 构建，性能轻快、样式灵活，便于二次开发与扩展。
