Urik：隐私优先的开源 Android 键盘（本地处理 + 加密词库），Gboard 替代方案

Published 2025-12-16

Urik介绍

Urik 是一款面向隐私与可用性共同设计的 Android 键盘。它把“输入体验”和“数据边界”放在同一优先级：打字、纠错、学习词库都在设备端完成，数据不离开手机；词库与学习内容保存在本地加密数据库中。项目由社区全额资助并完全开源，定位为 Gboard 的开源替代方案，当前处于公开测试（Beta）阶段。

核心亮点

  • 滑行输入与点按输入，支持手势检测
  • 基于 SymSpell 的本地拼写检查
  • 智能自动纠错：跳过 URL/邮箱，结合标点上下文优化纠错
  • 词库学习：用户词典与学习词使用 SQLCipher 加密数据库存储
  • 多主题与收藏夹，方便快速切换
  • 多语言支持，并提供按语言的字符变体
  • 无障碍优化：WCAG AA 对比度、TalkBack 支持
  • 可配置键盘：按键大小、震动反馈、输入行为等
  • 无遥测、无分析统计、无网络权限

隐私与安全设计

Urik 的隐私策略很直接：处理发生在本地，数据不出设备。用户词典与学习词写入本地加密数据库，避免明文落盘带来的风险。产品理念也很清晰：对用户负责，而非对投资人指标负责。

输入体验与可用性

它提供滑行输入、拼写检查、自动纠错、多语言与主题系统，覆盖日常打字的关键场景；同时在纠错逻辑上对 URL、邮箱等内容做了规避处理，减少“越帮越忙”的误改。对无障碍用户，Urik 提供对比度标准与读屏支持，让键盘更容易被长期使用。

适合人群

  • 注重隐私、希望减少数据暴露的 Android 用户
  • 想要开源可审计、可参与共建的工具爱好者
  • 需要多语言输入与无障碍支持的用户
  • 希望寻找 Gboard 开源替代方案的用户

获取与状态

Urik 处于公开测试（Beta）阶段，可加入 Google Play 的 open beta 进行体验。

网盘：夸克

GitHub地址：https://github.com/urikdev/Urik

官网地址：https://urik.io/

系统要求

  • Android 8.0 或更高版本（API 26+）

从源码构建（面向开发者）

git clone https://github.com/urikdev/Urik.git
cd Urik
./gradlew assembleDebug

开发环境要求：Android Studio Ladybug+、JDK 17+、Android SDK 34+

为什么它值得被关注

键盘是高频输入入口，天然敏感。Urik 把“默认不收集”做成产品能力：不需要网络权限、不做遥测分析，把可用功能尽量放到设备端完成，再用加密数据库守住本地词库。对希望把隐私掌握在自己手里的用户来说，这种取舍很稀缺。
