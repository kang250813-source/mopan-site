Call-Me：基于 WebRTC 的一键一对一视频通话（开源，可嵌入网站）

Published 2025-10-10

Call-Me简介

Call-Me 是一个基于 WebRTC 的开源小工具，支持在浏览器内直接发起一对一视频通话。无需安装应用，输入用户名即可登录，点击对方昵称即可呼叫。通话过程中可实时文字聊天、切换摄像头/麦克风/扬声器、隐藏视频、静音、共享屏幕，并在结束时一键挂断。还提供 REST API，用于获取在线用户或以编程方式发起呼叫。

网站地址：https://cme.mirotalk.com/
源码仓库：https://github.com/miroslavpejic85/call-me

Call-Me核心功能

  • 用户名登录：输入昵称即可进入系统，支持在线用户显示。
  • 一键呼叫：点击对方昵称即可发起视频通话。
  • 设备切换：通话中可随时切换摄像头、麦克风或扬声器。
  • 实时聊天：支持文字聊天窗口，便于补充交流。
  • 屏幕共享：适合在线教学、远程演示或产品展示。
  • API集成：通过 REST API 获取在线用户列表或生成通话链接，方便嵌入企业网站或定制平台。
  • 快速部署：支持 Node.js 启动与 Docker 容器化部署，便于本地或云端部署。

Call-Me应用场景

适用于远程面试、在线咨询、客服沟通、教学演示、网站视频客服等场景。虽功能基础，但因其轻量与可嵌入特性，非常适合开发者将其集成进自有网站或内部系统。

Call-Me使用体验

Call-Me 提供即开即用的体验，无需注册或下载。输入用户名即可进入房间，点击好友昵称即可视频通话。虽然在如今各类社交应用普遍自带视频功能的背景下略显基础，但对于需要快速集成“网页一对一通话模块”的项目，它仍是一款高效的解决方案。
