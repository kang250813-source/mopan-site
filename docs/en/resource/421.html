Teleprompter Online概览

Teleprompter Online是一款完全免费的在线提词器，无需下载或注册，打开网页即可使用。为视频创作者、演讲者与教育工作者设计，支持自动滚动、速度与字体精细调节、颜色主题、镜像翻转、智能指示线与全屏模式，覆盖录制、直播与授课等场景。地址：teleprompteronline.org/zh

核心功能

  • 自动滚动：播放/暂停/重置可控，速度范围 20–300，匹配个人语速。
  • 字体自定义：字号 24–120，远近机位都能清晰阅读。
  • 颜色主题：自定背景与文字颜色，适应不同灯光与布景。
  • 镜像翻转：水平或垂直翻转，兼容单反与提词器硬件。
  • 智能指示线：6 种预设（标准/专业/舒适/醒目/极简/自定义），可调位置、宽度、粗细、透明度与颜色，帮助视线稳定。
  • 全屏模式：一键进入沉浸式提词，录制更专注。

兼容性与使用门槛

在 Chrome、Safari、Firefox、Edge 等主流浏览器可用，支持电脑、平板与手机。无需安装软件，新手也能快速上手。

上手指南

快速开始

  1. 点击 「开始提词」 进入全屏。
  2. 点击 播放 开始滚动；到文末自动停止。

键盘快捷键

  • Space：播放/暂停
  • ↑ / ↓：调整字号
  • ← / →：调整速度
  • ESC：退出全屏

常见场景

  • 视频录制：面对镜头保持顺畅表达，降低 NG 率。
  • 直播带货/主持：节奏稳定，信息点不遗漏。
  • 教学与培训：讲义提词配合指示线，授课更稳。
  • 公开演讲：大字号+高对比主题，提高可读性与镜头感。

隐私与数据

提词文本仅保存在本地浏览器存储，不会上传服务器。清理浏览器缓存即可删除数据，平台不收集、不存储任何内容。
