NCE Flow：新概念英语在线点读与跟读系统（开源 · 四册全收录）

Published 2025-11-22

NCE Flow概览

NCE Flow 将《新概念英语》四册完整数字化，提供句子级点读与自动高亮跟随播放。支持 EN / EN+CN / CN 三种视图，自由调节倍速与连读方式，循环与断点续播配合学习记录与进度追踪，让精听与泛读更省力。界面风格贴近 Apple 设计语言，深浅色主题与响应式布局覆盖多设备场景。项目为纯静态部署形态，解压即可用，亦可通过 Docker 一键启动。
在线体验：https://nce.luzhenhua.cn
源代码与发行版：https://github.com/luzhenhua/NCE-Flow

NCE Flow核心亮点

  • 句子级点读：点到哪一句，播到哪一句，文本自动高亮跟随。
  • 多语言视图：EN / EN+CN / CN 灵活切换，适配不同阶段的学习需求。
  • 播放控制：倍速调节、连读/点读模式、循环播放、断点续播。
  • 全局快捷键：空格播放/暂停，方向键快速定位，音量键直觉调节。
  • 学习管理：课程收藏、历史记录、进度追踪，学习状态一目了然。
  • 现代界面：Apple 风格视觉与交互，支持深浅色主题与移动端自适应。
  • 零依赖：纯静态文件，适合本地、内网与任意静态空间托管。

适用人群

  • 基础巩固与进阶提升的新概念英语学习者
  • 需要高频精听、分句跟读与碎片化复习的自学者
  • 为班级或家庭学习搭建轻量级「点读环境」的老师与家长
  • 偏好开源与可自部署学习工具的开发者与内容组织者

功能清单

  • 逐句点读与自动高亮
  • EN / EN+CN / CN 三种显示模式
  • 倍速、连读/点读切换、循环、断点续播
  • 全局快捷键（播放、导航、音量）
  • 收藏、学习记录、进度追踪
  • 深浅色主题、响应式布局、Apple 风格界面
  • 纯静态发布形态，解压即用

NCE Flow部署与使用

方式一 · Docker 一键启动

docker run -d -p 8080:80 --name nce-flow --restart unless-stopped luzhenhua/nce-flow:latest
# 打开：http://localhost:8080
# 自定义端口：
# docker run -d -p 3000:80 --name nce-flow --restart unless-stopped luzhenhua/nce-flow:latest

方式二 · Docker Compose

git clone https://github.com/luzhenhua/NCE-Flow.git
cd NCE-Flow
docker-compose up -d
# 打开：http://localhost:8080

方式三 · 本地静态服务器

  • Python：
python -m http.server 8000
# 打开：http://localhost:8000
  • Node.js：
npx serve .
# 打开命令行显示的本地地址
  • VS Code Live Server：为 index.html 启动本地服务即可。
    提示：请通过本地服务器访问，避免直接双击 index.html 触发浏览器跨域安全限制。
