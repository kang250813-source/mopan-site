NinjiaTag：开源DIY Airtag替代方案，支持FindMy网络长期轨迹记录

Published 2025-09-24

NinjiaTag概览

NinjiaTag 是一款开源 DIY 定位标签解决方案，兼容 Apple 的 FindMy 网络，可实现长期位置记录与回溯。与市面上只能保存 7 天轨迹的主流产品不同，NinjiaTag 可将轨迹永久保存到服务器，支持查询任意时间段的位置与路径。

名称“NinjiaTag”寓意“敏捷与协作”，不仅是一款防丢工具，更是面向下一代分布式物联网的探索。

NinjiaTag功能特性

  • 长期记录：位置数据通过服务器端定期获取并存储，保存时间不限。
  • 轨迹可视化：支持地图轨迹显示，经纬度与时间点清晰可见，支持缩放。
  • 热图功能：通过热点显示常去与少去的地点，类似 GIS 的人流密度可视化。
  • 前端管理：Web 界面支持密钥管理。
  • 三维地图：基于 Mapbox-GL 引擎，支持三维地形与精美渲染。
  • GPX 导出：支持单/多物品的 GPX 文件导出，方便后续使用。

硬件与软件准备

  • 一台 Linux 服务器（运行 Docker 和 Python 脚本）。
  • 一个支持 2FA 的 Apple ID（仅需免费账户，可用实验号注册）。
  • 支持的蓝牙模块：nRF5x、ST17H66，后续将扩展至更多低成本国产模块。
  • 可通过下载固件并使用脚本进行烧录，支持多密钥机制，实现蓝牙地址轮换，提升位置上传频率与精度。

DIY与成品选择

具备硬件能力的用户可自行刷机与搭建服务，也可通过二手平台购买成品（如圆形 Tag 或 MiniTag），但推荐自建服务器以避免带宽限制。
