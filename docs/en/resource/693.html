闲鱼聊天记录一键导出工具，支持HTML和Markdown格式，保留图片视频样式：xianyu-chat-exporter

Published 2026-01-05

闲鱼聊天记录导出插件：HTML+Markdown一键备份

对于频繁使用闲鱼进行交易或沟通的用户来说，保留聊天记录不仅有助于信息存档，也方便日后追溯。xianyu-chat-exporter 是一款专为闲鱼网页版设计的浏览器插件，支持可视化选择消息并一键导出为 HTML 或 Markdown 格式，完整保留聊天气泡样式、图片、视频与引用关系，适用于电商卖家、维权取证、知识记录等场景。

🔧 插件亮点

可视化操作

用户可预览并勾选需要导出的聊天内容，避免误操作和信息遗漏。

多格式支持

支持导出为带样式的 HTML 文件，或适用于笔记工具的 Markdown 文本格式。

样式还原与多媒体保留

HTML 导出效果保留原有头像、对话气泡样式，图片和视频可直接打开播放；Markdown 格式则以纯文本呈现，图片以链接形式存储，更适合记录整理。

本地运行，安全私密

插件基于 Manifest V3 与 Chrome Scripting API 实现，完全在本地运行，不上传任何聊天数据，保障用户隐私安全。

📦 安装与使用教程

安装方式一：开发者模式（推荐）

  1. 打开 Chrome，进入 chrome://extensions/
  2. 开启右上角“开发者模式”
  3. 点击“加载已解压的扩展程序”，选择插件文件夹
  4. 安装完成后即可使用

安装方式二：生成 crx 安装包

  1. 在扩展页点击“打包扩展程序”
  2. 选择插件目录生成 .crx 文件，双击安装

使用方法

  1. 打开闲鱼网页版并登录账户
  2. 进入与某用户的聊天窗口
  3. 滚动至顶部以加载完整历史记录
  4. 点击浏览器右上角插件图标
  5. 勾选要导出的消息内容
  6. 选择「导出 HTML」或「导出 Markdown」

⚠️ 使用注意事项

  • 当前仅支持闲鱼网页版（goofish.com / xianyu.com）
  • 聊天记录需提前滚动加载完整
  • 所导出图片链接为阿里云 CDN 地址，存在时效性限制
