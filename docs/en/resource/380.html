SyncTV：开源远程一起看电影与直播的神器，支持 Bilibili/Emby/Alist 与直播同步

Published 2025-10-22

SyncTV概览

SyncTV 是一款开源的远程同屏观影程序，让多人跨地域一起看电影与直播。它提供同步播放、聊天与弹幕、影院模式等体验，适合与朋友或家人远程共享观影时刻。通过 SyncTV 的同步播放技术，所有成员都能在同一时间点看到相同画面。当有人暂停、快进、倒退或调整倍速，其他人也会同步更新，保证无延迟、无错位的观影体验。项目提供演示站点与文档，并支持多种安装方式（二进制与 Docker 本地部署），方便快速上手。

SyncTV核心能力

同步播放

  • 保障所有成员停留在同一时间点
  • 支持暂停、快进、快退、倍速等控制，操作会自动同步到所有人

互动体验

  • 实时聊天与弹幕
  • 影院模式营造沉浸式观影氛围

音视频沟通

  • 基于 WebRTC 的在线通话
  • 语音、视频与屏幕共享，便于边看边聊与演示

源与解析

  • 视频解析与直播解析
  • 支持常见视频与媒体源：Alist、Bilibili、Emby
  • 支持 Bilibili 直播源解析

代理与缓存

  • 视频代理与直播代理
  • 代理缓存，优化多端访问体验

安装与访问

  • 二进制文件：下载后即可在本地或服务器运行
  • Docker：通过容器部署，便于升级与迁移
  • 官方资源：GitHub（synctv-org/synctv）、演示站点与在线文档

适用场景

  • 异地情侣、亲友云观影
  • 远程追番、直播赛事同屏观看
  • 小型线上观影会或学习研讨

SyncTV如何使用

GitHub 项目地址：https://github.com/synctv-org/synctv
演示站点：https://demo.synctv.wiki/
文档中心：https://docs.synctv.wiki/
