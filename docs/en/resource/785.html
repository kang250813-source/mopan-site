GKD：基于订阅规则的开源Android自动点击工具 轻松跳过APP启动广告

Published 2025-06-16

📱 什么是 GKD？

GKD 是一款基于 Android 无障碍+选择器+订阅规则的自动点击工具，支持在特定界面、满足条件（如存在指定文字）时，自动点击、执行操作或跳过流程等。适合用于跳过广告、自动同意登录、自动领取弹窗等重复性操作。

核心功能一览

✅ 无障碍 + 高级选择器

  • GKD 利用无障碍 API 结合类 CSS 样式的选择器，精准定位页面节点位置，支持结合上下文进行判断。
  • 示例选择器语法： 
    @[vid="menu"] < [vid="menu_container"] - [vid="dot_text_layout"] > [text^="广告"]

🔔 订阅规则

  • 支持本地规则和通过互联网订阅的规则。官方订阅模板及各类共享订阅规则库可用于快速部署。
  • 可自主编写，亦可使用他人维护的公共订阅集合。

📸 快照审查

  • 捕捉当前 UI 快照，通过审查工具测试选择器是否匹配。
  • 支持分享快照以便他人协助调试与优化规则。

🎯 适用场景

  • 自动跳过广告弹窗、确认按钮、更新提示。
  • 自动领取红包、自动同意权限提示等。
  • 简化重复登录流程或确认按钮点击，无需手动操作。

🔐 安全性与开源

  • 完全开源（GPL‑3.0 协议）：任何人可以查看源码并验证安全性与逻辑。
  • 广泛使用“快照共享+审查”机制，规则明确可控。

✅ 快速开始建议

  1. 安装并授权 GKD。
  2. 从订阅库导入一个通用规则（如跳过登录广告）。
  3. 使用“快照”检验点击效果，优化选择器精确度。
  4. 运行 App，让 GKD 自动处理指定页面行为。
