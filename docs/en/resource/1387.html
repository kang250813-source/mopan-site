AI-PROXY：一站式多厂商AI API代理网关，极简部署，安全高效！（无需注册，替换 URL 即可用）

Published 2025-08-11

推荐理由：如果你需要一个简单好用、支持多家AI厂商的API代理平台，AI-PROXY绝对值得一试！

AI-PROXY简介

AI-PROXY 是一款开箱即用的多厂商AI API代理网关，支持 OpenAI、Claude、Gemini、Grok 等主流AI厂商。无论你是开发者、团队还是企业，都能轻松统一管理和转发各类AI API请求。

AI-PROXY核心功能亮点

  • 多厂商支持：统一代理 OpenAI、Claude、Gemini、Grok 等主流AI厂商API。
  • 极简部署：Go语言开发，二进制可执行文件，支持 Windows/Linux/Mac，几分钟即可上线。
  • 可视化管理后台：前端美观易用，支持API配置的增删改查、状态切换、在线测试。
  • 安全认证：支持管理员令牌登录，保障后台安全。
  • 日志与监控：支持日志多路输出，便于排查和运维。
  • 开源免费：代码完全开源，支持二次开发和自定义扩展。

AI-PROXY使用的技术

  • 后端：Go 语言 + Gin 框架，性能高、易扩展
  • 前端：HTML5 + Bootstrap5，响应式美观
  • 数据库：SQLite（默认），支持扩展
  • 部署：支持 Windows/Linux/Mac，二进制一键运行

AI-PROXY如何使用

1. 普通用户

只需把你平时调用 AI 的 API 地址，换成管理员给你的代理地址即可，无需注册，无需改代码逻辑。

比如，官方的 API 地址：

https://api.openai.com/v1/xxx

只需替换为：

http://你的服务器IP:8080/openai/v1/xxx

其他参数（如 API Key、请求方式等）和官方用法完全一样，无需额外操作。

温馨提示：如需 HTTPS，可配合 Nginx/Caddy 反代实现。

2. 管理员

在浏览器访问：

http://你的服务器IP:8080/admin

输入管理员令牌（token）登录后台。

登录后可以：

  • 添加、编辑、删除API配置
  • 启用/禁用某个API
  • 点击“测试”按钮检测API网络连通性

小结：配置好后，把代理地址发给团队成员或用户即可。
