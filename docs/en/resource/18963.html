OpenDisplay：开源免费的 Mac 副屏工具，将 iPhone / iPad 变成外接显示器

Published 2026-07-12

编辑透明度说明： 本文基于 OpenDisplay 的 GitHub 公开仓库与项目文档整理。该项目目前采用 GPL-3.0 开源许可证。由于涉及 macOS 私有 API 及局域网通信，正文已补充相关的系统兼容性提示与安全边界说明。

只带一台 Mac 出门时，聊天窗口、浏览器资料、代码日志和文档预览很容易全挤在同一块屏幕上。如果手边正好有闲置的 iPhone 或 iPad，OpenDisplay 可以直接把它变成第二块扩展屏。

OpenDisplay 是一款免费开源的 Mac 副屏工具。它不是简单投屏或画面镜像，而是让 macOS 把移动设备识别成真实外接显示器，窗口可以直接拖过去使用。

和苹果自带的随航（Sidecar）相比，它支持 iPhone，也不要求两台设备使用同一个 Apple ID；和 Duet Display、Luna Display 这类商业方案相比，它不需要订阅，也不需要额外硬件。

一句话总结： OpenDisplay 是一款免费开源的 Mac 副屏工具，可通过 USB 或 WiFi 将 iPhone / iPad 变成真实扩展显示器，并支持触控输入。它适合作为 Duet Display、Sidecar 的开源替代方案之一，但 Mac 端依赖私有 API，WiFi 模式也存在未加密传输限制，公共网络下更建议使用 USB 有线连接。

OpenDisplay 和随航、Duet Display 的区别在哪？

OpenDisplay 和普通投屏软件最大的区别，是它不会把 Mac 画面简单复制到 iPhone / iPad 上，而是在 macOS 里直接创建一块虚拟显示器。连接成功后，系统设置里会多出一块屏幕，你可以像使用普通外接显示器一样，把窗口拖过去、调整排列位置，也可以把设备竖起来当小副屏。

大屏 iPhone 适合放聊天窗口、待办列表、音乐播放器或状态监控，iPad 的空间更宽，拿来显示文档、网页资料和开发日志会更舒服。它支持 Retina / HiDPI 显示，文字清晰度也比普通远程投屏更适合长时间阅读。

触控也能正常使用，单击、拖拽和双指滚动都会传回 Mac，相当于临时多了一块小触控屏。Apple Pencil 和压力感应目前还没有加入，官方把这部分放在了后续计划里。

它可以通过 USB 或 WiFi 连接。USB 延迟更低，WiFi 用起来更方便；两台设备不需要登录同一个 Apple ID，也不用另外注册账号。项目还支持同时连接多台 iPhone / iPad，官方测试过三台设备一起使用，不过实际流畅度仍会受到 Mac 性能和连接方式影响。

OpenDisplay 使用前需要注意的限制

OpenDisplay 目前要求 macOS 14 或更高版本，iPhone 需要 iOS 17 以上，iPad 则需要 iPadOS 17 以上。旧设备即使硬件还能正常使用，只要系统版本达不到要求，也没办法直接安装。

Mac 端提供经过签名和苹果公证的 DMG 安装包，下载后可以直接安装。iPhone / iPad 端可以从 App Store 获取，也能加入 TestFlight 使用测试版本；熟悉 Xcode 的用户还可以从 GitHub 源码自行编译。

Mac 端依赖 CGVirtualDisplay 来创建虚拟显示器。这个接口没有对外公开，所以 OpenDisplay 无法通过 Mac App Store 分发，未来遇到 macOS 大版本更新时，也可能需要等待项目重新适配。

WiFi 模式目前没有加密本地网络中的画面传输。在咖啡厅、酒店或公司访客网络这类不完全可信的环境里，用 USB 会更稳妥。USB 连接本身延迟更低，也更适合长时间使用。

首次运行时，Mac 端需要获得屏幕录制和辅助功能权限。屏幕录制权限没开，iPhone / iPad 端可能会黑屏；辅助功能权限没开，触控和滚动就不会生效。菜单栏出现紫色录屏指示灯属于 macOS 的正常提示。

OpenDisplay 目前只传输画面和触控操作，不会把 Mac 的声音同步到 iPhone 或 iPad。需要音频时，还是要用 Mac 扬声器、耳机或其他输出设备。

使用提醒： 公共 WiFi 下更建议使用 USB；升级 macOS 前，也可以先确认项目是否已经适配新版本。

OpenDisplay 适合谁使用？

OpenDisplay 更适合临时副屏和轻量办公场景。比如出差时把聊天窗口、网页资料或开发日志单独放到另一块屏幕上；家里有闲置 iPad / iPhone，也可以继续拿来做小尺寸副屏。

iPad 更适合文档、网页和日志预览，iPhone 则更适合竖着放聊天窗口、待办列表、音乐播放器或状态监控。如果只是偶尔使用，从 USB 模式开始会更省事。

它不适合被当成长期稳定的生产环境依赖。Mac 端使用了私有 API，macOS 大版本更新后可能需要等待项目适配；企业环境如果对屏幕录制权限、第三方软件和局域网通信有严格要求，也更适合使用 Sidecar、实体显示器或成熟商业方案。
