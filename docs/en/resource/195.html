DailyWallpaperHub：支持AI故事生成的多源壁纸聚合平台，自动归档 Bing 与 Unsplash 精选内容

Published 2025-12-28

多源壁纸自动聚合，AI 生成精美故事

DailyWallpaperHub 是一个自动化的开源壁纸平台，通过聚合 Bing 与 Unsplash 等高质量图源，实现每日壁纸归档与展示。不仅如此，它还结合了视觉大模型，为每张图片生成包含地理与文化背景的 AI 故事，让静态画面也能讲述动人故事。

平台亮点

🎨 多源聚合与配置扩展

支持 Bing 与 Unsplash 等主流壁纸源，采用配置化管理方式，方便快速接入更多来源。

🤖 AI 视觉故事生成

每张壁纸自动关联约 500 字的背景故事，内容通过 LLM 视觉大模型生成，兼具信息性与艺术性。

⚡️ 异步处理架构

AI 故事生成采用异步处理，确保图片即时可用，减少等待时间。

🛠 外部提示词管理

AI 提示词存储在独立文件中（prompts/story_prompt.txt），方便开发者灵活优化和微调。

⏰ 每小时自动更新

利用 GitHub Actions 定时运行任务，实时获取最新壁纸内容，保障内容持续更新。

💾 高清壁纸自动归档

自动提交高清原图、缩略图、元数据（JSON）和 AI 故事至仓库，长期可访问、不丢失。

☁️ 腾讯云分发支持（可选）

支持上传至腾讯云 COS，满足大规模图片分发需求，适配企业与商业场景。

🖼 GitHub Pages 在线画廊

内建响应式前端页面，支持暗黑模式，适合在任何设备上流畅浏览壁纸和故事内容。

📱 企业微信自动推送

每日壁纸和故事可通过机器人推送至企业微信群，支持动态源标识，适用于团队灵感分享或品牌内容管理。

🎯 灵活展示与历史抓取

默认展示近 10 天壁纸，可自定义展示范围；支持按日期和数据源批量回溯下载历史资源。

零成本部署，面向开发者与内容爱好者

项目基于 GitHub 免费服务构建，无需额外服务器成本，即可拥有自动化更新、壁纸归档与AI故事生成的完整系统。无论是构建个人壁纸收藏、打造品牌视觉内容库，还是为团队提供每日灵感注入，DailyWallpaperHub 都是一个高效且优雅的解决方案。
