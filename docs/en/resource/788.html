PasteMD：一键将 Markdown 与 AI 对话内容完美粘贴到 Word、WPS 与 Excel 的效率工具

Published 2025-12-13

PasteMD 是什么？

PasteMD 是一款专为 AI 用户和文档工作者设计的效率工具，它让你可以一键将 Markdown 内容和 AI 网页对话（如 ChatGPT、DeepSeek）精准粘贴到 Word、WPS 或 Excel 文档中，彻底解决格式错乱、公式乱码的问题。无论是在撰写报告、准备论文，还是处理数据表格，PasteMD 都能大幅提升你的复制粘贴效率。

核心功能亮点

🔄 一键粘贴 Markdown 到 Word/WPS

从剪贴板读取 Markdown 内容，通过 Pandoc 转换为标准 DOCX，并自动插入到当前 Word 或 WPS 光标位置。内置热键（默认 Ctrl+B），无需手动操作。

📋 Markdown 表格智能粘贴 Excel

自动识别 Markdown 中的表格结构，并将其高保真粘贴到 Excel，适合处理结构化数据与表格笔记。

🌐 支持 AI 网站富文本复制

PasteMD 能智能识别 HTML 富文本，支持将网页中 AI 回答的内容（含公式）一键粘贴进 Word/WPS，保留排版与样式。

🖥 应用智能识别与系统托盘常驻

自动判断你当前使用的是 Word、WPS 还是 Excel，并将内容精准插入。软件托盘提供日志、配置与文件保留功能，运行稳定，不弹黑框、不占前台。

快速开始使用 PasteMD

  1. 下载并安装工具：
    • PasteMD 便携版（（👉获取地址：国内用户）需本地已安装 Pandoc）
    • PasteMD 一体化版本（自带 Pandoc）
  2. 打开 Word/WPS/Excel，将光标移动至插入位置
  3. 复制 Markdown 或网页 AI 回复
  4. 按下 Ctrl+B，PasteMD 自动识别格式并插入内容

右下角将提示成功与否，操作无需切换窗口，真正实现“一键搞定”。
