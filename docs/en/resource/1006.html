Galaxy Downloader：B站/抖音/小红书通用媒体下载器（视频+音频+图文笔记）

Published 2025-12-24

想把喜欢的视频收藏到本地、把音频留作通勤听、把小红书图文笔记打包归档？Galaxy Downloader 提供一个更省事的入口：复制链接、粘贴解析、选择格式即可保存，覆盖 Bilibili、抖音、小红书等常见平台内容，适合内容创作者、运营剪辑、学习资料整理等高频场景。

产品定位：一个更顺手的通用媒体下载器

Galaxy Downloader（访问：downloader.bhwa233.com）专注“链接识别 + 格式选择 + 本地保存”的简单流程，把多平台下载入口整合到一个页面里，减少来回切换工具的麻烦。

适用人群

  • 自媒体/电商内容运营：做素材整理、复盘拆解、剪辑前备份
  • 学习与研究：保存公开视频/公开图文用于笔记与归档
  • 普通用户：离线观看、通勤听音频、长期收藏管理

核心功能一览

  • 🎵 Bilibili 视频/音频下载
  • 🎬 抖音视频下载与音频提取（以平台规则与内容授权为前提）
  • 📷 小红书视频笔记下载、图文笔记下载（支持图片打包）
  • 🔍 自动识别平台链接，减少手动选择步骤
  • 🎨 现代化 UI，输入即用
  • 💾 本地下载历史记录（保存在浏览器中）
  • 🌍 多语言界面：简体中文 / 繁体中文 / English

三步完成下载

Step 1：复制链接

在 B站/抖音/小红书等平台找到目标内容，复制分享链接。

Step 2：粘贴解析

把链接粘贴到输入框，点击解析按钮，系统自动识别平台与可选格式。

Step 3：选择格式并保存

按需选择视频或音频格式开始下载，完成后文件会保存到本地。

免费与使用门槛

  • ✅ 永久免费使用
  • ✅ 无需注册登录
  • ✅ 不限下载次数（受网络与设备性能影响）

隐私保护说明（重点）

  • 服务器不保存用户记录
  • 下载历史记录仅保存在用户浏览器本地

版权与合规提示：请在平台许可、内容创作者授权或法律允许的范围内保存与使用内容，尊重版权与署名，不将下载内容用于侵权传播或违规用途。

  • 抖音：https://www.douyin.com/... / https://v.douyin.com/...

技术栈亮点（适合开发者与部署者）

  • Next.js 16（App Router）、React 19、TypeScript
  • Tailwind CSS、shadcn/ui、Axios
  • FFmpeg.wasm：浏览器端音频提取
  • JSZip：图文图片打包下载

npm run dev
# 或 yarn dev / pnpm dev / bun dev
